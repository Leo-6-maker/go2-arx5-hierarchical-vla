## 2. 就绪队列与回退

默认优先顺序：`R0 → G1 → G2 → G3 → G4 → G5 → G6 → G7 → G8 → FINAL`。不是所有任务都必须等待前一项通过：

状态使用 `PENDING / READY / RUNNING / DONE / PARTIAL / BLOCKED_DEPENDENCY / BLOCKED_RESOURCE / BLOCKED_SAFETY / FAILED_PRESERVED`；DONE表示该工作包的实测或分析交付完整，不等于科研假说成立。任务就绪由证据/资源决定，不凭Markdown中的checkbox。

## 3. 八个后继工作包

### G1 — 数据质量与动力学覆盖审计（零新积分优先）

**输入**：NIGHT1全部新attempt manifest、原始原生日志、Replay/schema/split和checkpoint。先读已保存结果，不重放onceIO。

**实际工作**：按真实父场景／episode统计独立初态、参考方向／幅度、指令与实际运动、夹爪变化、接触建立／保持／释放、失败／partial以及有效连续长度；单列初始化和任务tick。逐项检查动作提出/安装/solver匹配、TTL和mode，控制器最终selected-policy仍未导出时维持DERIVED。核对25tick/50ms、前缀和未来信息、单位、SO(3)/四元数有效性、窗口不跨reset或非法模式边界。检查静止物体是否支配总loss、样本是否仅复制一条轨迹。

**交付**：可复跑的数据审计命令、覆盖矩阵、原件SHA和缺口清单。生产数据合格集合与原失败原件分开；没有事故正例不能训练出“已资格安全分类器”。

**继续判据**：非零有效真实目标序列、清晰split、来源可追溯。发现污染就隔离派生数据并重新构建，不修改原件；不让损坏Replay进入G4。

### G2 — 补齐受支撑接触与夹爪响应（先单环境）

复用N4已经取得的结果。仍缺条件时，最多为4项既定条件各安排2次预登记有界尝试（8次上限，拒绝计入）：合法受支撑接触/闭爪、抓持保持或小幅抬升、支撑后开爪、释放后有限撤离。机器人/桌面净空、BASE hold V2和原安全不改；未通过较早接触条件，不推进依赖它的后续动作。不得通过瞬移物体或伪造夹持reset跳过物理资格。

记录左右接触、真实支撑、夹爪实际位置/命令/内部限速目标可用性、物体位姿/速度、BASE/腿安全及实际参考消费。支撑标签不能用illegal_contact替代。目标夹爪的单位、行程、限速来自目标实现，不能搬用S域0.044m/0.04m/s常量或现有单参数模型冒充目标辨识。

有已知reset与完整因果历史时可实现目标夹爪参考observer；未知内部目标保留区间/缺失，不用未来真值。真实标签仅用于FIT/评价。资格通过后将有效记录加入预先声明TRAIN/DEV，接触阶段单列；失败原样交付。

**交付**：四项条件逐项PASS/FAIL/NOT_RUN、真实事件轨迹与可用接触Replay。至少一次碰到物体不等于完整抓放成功。

### G3 — 独立父场景第二轮（扩总覆盖，不重复原goal）

若NIGHT1仅完成第一组8父6TRAIN/2DEV，预登记再增加不重叠8父6TRAIN/2DEV，每父最多4次，任务段使用当前已资格长度且≤8s：最多32次、5120条；与第一轮合计最多16父12TRAIN/4DEV。若原goal已经达到该规模，则复用成果完成此项，不再采一份同面板。

物理布局/合格初态实际变化才能算新父；只改变EEF命令要标ACTION_CONDITION_PANEL。机器人结构/冻结执行器指纹保持一致，scene资产单独SHA白名单，禁止删去模型一致性检查。不同slot交错执行同一split类型，不能slot0永远TRAIN、slot1永远DEV。

先用冻结旧WM评价新数据再决定入TRAIN；DEV永不回流。不要用DEV模型误差挑“更容易”的场景。若接触仅部分合格，分别记录FREE_SPACE/CONTACT能力，不要求所有任务相同。

**交付**：新增独立父manifest、模型预更新结果、TRAIN/DEV新Replay、有效连续窗口及事件覆盖。父级不确定性与重复窗口依赖单列。

### G4 — 两个目标WM配方的受控对照与恢复

需要G1合格数据，至少存在实际独立父DEV；没有则只做同父工程诊断，不能宣称泛化或进入G5正式模型比较。原NIGHT1的新checkpoint先保留为基线。

新增最多2个固定配方，各200主更新+1独立恢复探针：A为当前目标GRU/因果参考基线的匹配版本；B只改一个由G1/G2定位的机制，例如目标夹爪已知记忆输入、静止物体持恒＋学习残差或更合适的姿态更新。不得同时换数据/架构/loss并声称单因素归因，不复制S域大模型和未验证规则。

固定FIT、初始化、seed、可比较采样暴露、评价代码与checkpoint端点；所有normalizer/线性基线拟合只用TRAIN。支持变长窗口时保留真实H40／时间及未来缺失mask，不把未来实际renewal源龄或achieved TCP喂入想象。

**交付**：冻结配方、两份checkpoint、实际optimizer/RNG/cursor重载、分父DEV指标和适用域。预测能力是开发证据，不是控制收益。

### G5 — 前瞻动作选择试验（不训练Actor）

只有G4得到针对拟执行动作/事件的合格预测、相应物理条件已获资格，且剩余预算足够，才能启动。先在TRAIN/既有DEV做只读敏感性与动作合法性检查；没有条件时标BLOCKED_DEPENDENCY，不以计划宣称真实收益。

预登记最多8个真正未见父条件，每父2种方法（冻结WM选择器、冻结强规则），合计最多16次有界真实尝试，原完整任务上限仍8s。方法顺序预先随机/交叉，不根据先跑的结果重拟合；重复相同布局也不称任意midpoint状态完全相同。每次在真实执行前保存同样合法观察、候选命令、模型预测与选择。仅执行当前安全包络中的动作，先执行一小段再实际观测，保持TTL/续约原语义。

记录实际状态误差、所选动作的原生任务进展、接触/安全与拒绝、模型/规则各自分母。不存在全部候选真实结果时，不能计算或虚构oracle/regret；有已合格反事实恢复时才可增加配对分叉，且额外试验需计共享限额。不能故意把规则改坏，也不能用rule fallback的收益伪装成纯WM收益。

**交付**：前瞻选择→真实后果的数据与视频、模型相对规则结果（允许持平或更差）。正式Actor/PPO更新仍0。
