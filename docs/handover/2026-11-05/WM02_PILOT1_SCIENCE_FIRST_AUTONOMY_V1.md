## 2. 成功标准：先一条小闭环，再扩大能力

`真实TRAIN历史 → 冻结ARX／任务评分 → 小Actor实际优化与checkpoint → 独立真实任务评价 → 真实反馈追加TRAIN → 更新／恢复 → 再评价`

随后交付独立接触线：

`实际稳定可达区域 → 新场景的物理资格 → 接触进入／退出数据 → 接触相关WM小规模训练 → 该微任务的Policy训练与闭环评价`

## 4. A线：局部任务与真实小Actor，优先执行

### A1：将已验证ARX变成可复用的任务教师，不重训其系数

复现原NumPy ARX，保持TRAIN统计与文件身份；等价迁移为Torch张量运算可获得对输入的导数。先验证FP64的H1/H8/H16输出、动作内数值有限差分与autograd一致，再单列FP32误差。容差在旧TRAIN上预登记，不用新TEST调容差。数值求导正确不代表真实物理Jacobian已验证；离散动作支持之外的扰动只算离线诊断，不据此派发新连续动作。

定义首个新任务 `LOCAL_EEF_REACH_PILOT_V1`：从已验证稳定前缀出发，在四个既有动作中选择一次，沿原RAMP8／HOLD与续约协议观察到H16。BASE与夹爪保持，Z／姿态不干预。任务目标在决策前由固定目标生成器给定；生成器依据TRAIN中实际响应范围、合法观察坐标和安全边界预先冻结，不能根据本次未来结果反选目标。

局部评分建议为实际末端目标误差加动作代价，成功容差在TRAIN噪声与任务尺度上预注册。模型评分不等于安全资格；每个实际候选仍经原编译／原生安全检查。

同任务保留三种强比较：几何方向规则、TRAIN平均响应表、冻结ARX选择器。目标不应只有HOLD永远最优，也不能故意削弱规则制造改善空间。若四候选结果在噪声内打平，记录不可区分或保留软标签，不把微小数值差强制解释成最优。

### A2：马上完成第一份真实训练的Actor

在**已有合法TRAIN物理历史**与预登记目标上，用ARX枚举四候选预测，得到任务分数／软标签。可以先做离线小批训练，不等新的抓取数据或教师已经显著胜过规则。输入为当前／历史实际机器人观察、已执行参考历史、任务目标及必要已知时钟；模型候选评分只作教师标签，不喂作学生观察。未来状态、selected-action结果、测试父身份不得进入输入。

建议起点是2层128宽MLP输出四动作logits（这是可修改的pilot配方，不是经过验证的最优架构）。优先分类蒸馏，交叉熵或有温度的软标签；必要时使用同一有限动作集合上的模型期望回报：

`L_actor = -Σ_a πθ(a|history,goal) Q_ARX(history,a,goal) + β KL(πθ || π_reference)`。

该形式只对logits求导，真实执行始终选一个合法离散动作，不把softmax混合向量或未见连续动作交给WBC。教师标签是模型标签，不冒称真实oracle。局部Actor不是视觉Policy或完整操作策略。

小规模训练自主进行：建立可重载checkpoint，记录loss、梯度、动作分布、TRAIN/DEV成绩；200/800/2000可作为预声明记录端点，不是工程上限或自动停止条件。按完整学习曲线、验证平台期和单次既定终点决定后继，不因为刚好训练200步就停整个goal。每次延长/新配方在开工前冻结，不根据TEST结果调整seed或配方。

A2通过只表示 `SMALL_ACTOR_TRAINED_AND_RELOADABLE`，不表示教师／学生已有控制收益。即使ARX不优于规则，这项小Actor拟合和真实评价也可完成；模型质量不够时缩小合法任务范围或记录失败，而不是假通过。

### A3：真实评价及第一轮数据回流

新冻结任务面板建议从8个新物理父条件开始（4 TRAIN、2 DEV、2最终TEST；实际ID先核未使用），每父预先定义多个局部目标，三种基线和Actor使用相同初始条件分布／终止／安全标准，方法顺序预登记。数字是小试设计建议，不是采样预算或对可靠性的承诺；先可用较小TRAIN批打通，不等凑齐大数据集。

在原有scope允许的合格场景中，先保存建议再执行；逐次记录实际TCP误差、目标成功、动作合法率、拒绝/安全失败、延迟、模型误差和所有尝试。独立重启不能声称精确同状态fork；不从不同方法的事后结果拼出一个并不存在的真实oracle。

至少做到一轮真实TRAIN执行、追加TRAIN Replay、Teacher/WM或Actor后继更新、完整恢复和固定DEV评价。DEV/TEST不回流训练；正式TEST在模型和评分冻结后评价。旧P09–P16均已经曝光，不能再作为新盲测；旧DEV不得改TRAIN。

若Actor不及教师，查拟合／观察／标签；若教师不及强规则，查动作后果和选择不确定性；若都不及HOLD，查目标设计与真实动作空间。每种结论都允许闭环实验完成并继续有依据的下一假设。不能按成绩换分母或只报最好视频。

## 5. M线：本地WM训练与稳定残差，不成为A线前置

### M1：保留ARX，先训练它真正需要的残差

初版冻结ARX与其normalizer，增加零输出初始化的小残差头，保持元数据明确的状态/单位/动作接口：

`F_new(history,reference) = F_ARX(history,reference) ⊕ Rθ(history,reference)`。

旋转使用合法切空间或一致的SO3积分，不能直接加旋转矩阵。最先可保持106维接口、对任务相关组单独加权；若紧凑化输出，应明示为局部预测器，不向缺失维度补零冒充完整本体状态。TCP与预测qpos/FK一致性要检查。已有明确限速目标、历史、phase、时间递推显式保留，不重复让网络猜；缺失的MPC隐藏状态仍标历史条件近似。

逐级训练一步及4/8/16步自由展开，独立报告绝对误差、动作差、自然HOLD漂移、有限视野扰动放大和事件。残差均值、动作敏感性、输出非有限或FREE失稳不能由小的一步loss掩盖；不要用简单硬裁剪把失稳伪装成正确动力学，也不要一律强制所有谱半径<1破坏合法积分状态。

可使用 `L_state + λa L_action_effect + λk L_rollout + λe L_event`；各组尺度、权重、拟合数据和端点在TRAIN上确定并版本化。配对效应来自匹配独立重启，有状态差异与噪声，不把它当精确Jacobian标签。无真实接触正例时不训练／不授予接触事件头能力。已有piecewise数据需输入真实轨迹/消费时钟，不许用最终goal标整段动作。

与冻结ARX、窄future-choice-only消融、持恒和合适线性基线比较。小网络不优于ARX就保留ARX为主，不让神经模型获胜成为项目继续条件。训练学习曲线可超过历史200/800/5000数字；无新的研究假设和采样覆盖时，不无休止重复同一失败配方。

### M2：连续动作的可微Actor仅在有对应数据后进入

现阶段四动作Actor不需要真实动力学梯度。若后续需要连续XY、Z、旋转或夹爪动作，应先在新scope中预登记动作范围、通过安全与响应资格、采集对应数据，再验证物理有限差分和模型梯度。

满足局部动态与任务奖励条件后，可自主开展**本地小规模**短视野BPTT／Actor-Critic实验：冻结WM参数但保留输入梯度，从真实Replay起点短展开，奖励由合格真实任务定义，学习后回真实环境检验。模型50ms步、真实上层动作块和350ms续约必须正确区分；不能默认每个模型step都能派发独立Actor动作。先一决策任务，再重新资格多决策闭环。

离散抓放与接触切换不直接用未经验证的straight-through代理当真实力学梯度。新代理与原生成功条件分开，真实状态上报告误报/漏报，任务判定和安全不由WM替代。没有接触资格仅限制对应接触Policy，不能阻断A线自由空间小Actor。

## 6. C线：把新任务建在实际可达区域，不再把原C2修好作为唯一目标

先用现有真实稳定姿态／轨迹建立小范围工作区图，联合检查实际手指pad、腕部/肘部、足端/底盘、物体与支撑面余量。原C2 68mm偏差仅做能改变数据含义的聚焦审计；没有新证据时不原样重跑。可记录它为冻结执行器当前能力限制，继续新场景。

允许对**新的、单独命名的课程场景**调整物体／目标初始位姿、支撑台高度和几何布局，在episode开始前设置并真实settle。机器人本体、WBC、质量/惯量/摩擦/关节参数、物理dt、接触谓词和安全阈值保持；新支撑几何按原类别规则重新检查。不是移动目标来修饰旧任务分数；原任务失败和固定TEST保留。

禁止episode中物体瞬移/跟随TCP、固定浮动底座、焊接物体、夹爪附着作弊、穿透初态、把qpos/qvel复制当完整MPC恢复。模型中解析抓持关系不等于真实仿真可以硬绑物体。

从最短可验证事件开始：**轻触/短推 → 接触后撤离 → 受支撑闭爪 → 保持／松爪**。初始资格单环境；先取得接触进入和退出的真实正例再扩采。夹爪pad与物体相对几何比只看TCP中心更重要。成功/失败/未抓住均可提供有效动力学，但时钟错、数值发散、追踪缺失的片段须隔离，不能把完整原生阶段PASS当物体任务成功。

新场景和动作协议冻结后，按物理父布局划分TRAIN/DEV/TEST。事件驱动采样，覆盖接触建立、保持、退出及失败恢复；日志保存每25个native tick内事件聚合、实际夹爪内部记忆、安装H40/消费索引、真实物体运动及支撑/释放。不能全是无接触0标签却宣布事件模型可用。

得到合法数据后尽早运行小批真实读入、WM更新／恢复和事件验证，不等完整抓放成功或巨量数据。小试配置可从每模式少量独立episode开始，批量按事件覆盖扩充，具体数量由现场预登记，不设工程采样总额。

当新微任务的成功标准、操作范围和执行资格成立，可自主训练该任务的小型状态Actor／Planner蒸馏；仍分别报告单接触微任务与完整抓放。旧C2对齐调查是支线，不允许无限占据A/M/C的全部工作。

- 每个小试先冻结任务、输入／动作、数据分区、目标生成器、任务成功阈值、基线、模型配方和评价节点，再开工。有限worker终点与科学面板尺寸不属于工程预算；它们防止不可复现实验和无界运行，完成后可按当前授权续做新批。
- 推荐记录点200/800/2000，之后以实际曲线决定；这些不是硬更新上限。验证平台期且没有新覆盖时，先换可证伪假设／增加相关TRAIN覆盖，而不是只增步数。训练不需要等所有预测指标超过所有基线才能开始，小策略真实评价需要动作范围和数据合同成立。
- 普通/-O相关回归、checkpoint参数/optimizer/normalizer/RNG/cursor恢复、实际退出与原生安全分开报告；测试通过≠Policy有效。正式TEST不参与选择任何配方。
- 新executor、scene几何、动作时间协议、schema、成功谓词要版本化；共享机器人资产可以引用，私有checkpoint与原件保留。未知实际运行先查owner/Journal，不能重复派发。旧scope记录只读。

## 8. 自主推进机制：以科学里程碑接力，不以预算收尾

建议工作图：

`E0 → A1 → A2 → A3 → 本地闭环重复`；`A1 → M1 → 有条件M2`；`E0 → C0新可达场景 → C1真实接触数据 → C2接触WM/小Actor`。M/C不阻断A2最小训练。

可自主完成：应用代码和数据接口修复、隔离环境安装、必要编译、scene/目标课程设计、TRAIN采样、WM/Actor小试、恢复、真实评价和草稿PR。修复后只跑相关回归与必要原生验证，后续正常阶段不重复所有旧资格。无法复现的失败写UNKNOWN及下一诊断，不虚构根因。

一条线被GPU忙／接触不通过／真实外部权限阻断，立即转其它已经合法的工作；没有新证据的同失败不盲重试。安全异常停止受影响动态分支并保留现场；用户撤回、实际权限/资源不足或到期时停止相应作业，正常结算。项目级授权仍可供后继实际执行者按原机制取得新有限注册，不修改旧lease或自行扩展外部权限。

完成一个小试、200次更新或一个报告不是自动结束任务的原因。完整交付之后，在本地同范围继续下一条有依据的科学任务；到H200/GPU批量物理/分布式扩展需要时，触发唯一的规模审核停点。没有后台执行能力的Chat只发布计划，不声称Codex已经运行。

## 9. 强制 H200／GPU多环境审核门

以下任一项需要时，先安全封存并设置 `AWAITING_H200_SCALE_REVIEW`，**不提交、不申请设备allocation、不启动对应作业**：

- 任何H200设备作业／预热／性能实跑；
- GPU物理多世界后端（MuJoCo Warp/mjlab/Isaac等）的真实环境构造、GPU仿真、接触/控制等价性动态试验或规模训练；
- 新增多GPU/DDP／多节点策略训练、用其他远程大卡规避H200审核；
- 将原生冻结WBC替换／蒸馏为批量GPU控制器，并把它作为等价执行器生产训练数据。

本地单卡神经batch与已有1/2 CPU原生环境不是这一扩展，不因此停止当前小试。可以离线检查依赖、草拟代码和数学/ABI迁移方案，但不能把“兼容性测试”当免审的GPU物理启动。到审核点结束本pilot goal的自动扩展，交回用户；不要等待审核同时私自开启另一等价扩量链。

审核包由同一PR或后继报告交付，至少包含：

1. 当前不可变源码/数据/schema/模型/Actor/执行器SHA；真实小Actor训练、恢复、至少一轮新数据回流与固定评价结果，没完成则明确写缺项。
2. 吞吐瓶颈分解：原生启动/预热、WBC/MPC、物理、记录、Replay、WM、Actor各自时间与CPU/RAM/显存；实测与估计分列。不以“模型差”或“接触没到”为GPU需求证据。
3. 新规模确实要回答的科学问题；预期采样量/环境数/任务覆盖、单卡/多卡方案与成本估计（此时评估，不预先设工程总预算）。
4. 是否保持同一执行器。GPU后端无法运行现有ROS2/OCS2链时，明确是新执行域；静态模型、积分、接触、控制、时钟、reset、场景以及动作响应分布如何做等价性/迁移验收。
5. 一个最小GPU验证方案及逐级扩大节点、失败回滚与停止条件。CPU原生1/2环境基线、Policy/WM和旧数据始终保留。
6. 用户需要批准的具体资源、后端、允许改变的模块和评价定义。未得到明确批准前，状态保持待审；本计划不允许自动创建真实H200任务。

“本地小试成功→准备扩量”与“本地小试仍失败→请求解决特定资源问题”分别报告；后者不能伪称科学就绪。

## 10. 必须交付的终态

在同一真实执行日志中汇总：可运行命令、模型与任务版本、每个trial的假设/变因、真实原生尝试/有效转移/事件分母、WM更新/Actor更新/恢复比较、各基线与策略逐父结果、所有失败、未测项、成本观测和worker/lease状态。

首个最低交付是 **本地小Actor非零更新＋可重载checkpoint＋合法真实评价**，而不仅是更多计划或WM预测指标。接触线可独立PARTIAL，不隐去原任务失败。最后输出 `LOCAL_PILOT_TRAINED`、`LOCAL_POLICY_EVALUATED`、`LOCAL_CONTROL_GAIN`、`CONTACT_DATA_AVAILABLE`、`CONTACT_POLICY_EVALUATED` 等独立字段；增益不成立写false，不妨碍报告真实小试已完成。
