## 2. LoRA梯度检查的精确解释

“白名单梯度非零”指有效训练路径存在且能够更新部署参数，**不是要求每个参数在第一个更新上都有非零梯度**。

标准LoRA若B初始化为0，则第一步A梯度可以合法为0，B梯度可非零；部分bias、mask相关参数也可能在特定样本上为0。执行端应：
- 确认LoRA初始增量为0或符合已固定初始化，密集父模型函数不被随机破坏；
- 检查梯度有限、进入正确参数组；分模块给出norm和实际变化；
- 在第二个及后续更新观察应当生效的A/B路径，确认冻结参数不动；
- 不使用“所有叶子每一步都非零”作为准入门；
- S2空间loss必须对部署保留的VLM LoRA有梯度，不能只有align_projector在更新。

S1/S2共用参数初始化需显式复用同一公共参数树；S2额外projector初始化使用独立RNG，不得因为多创建一个模块改变共同LoRA的随机初始值。

## 3. 日程与预算的精确解释

更新编号j=1…500，实际第j次Adam更新使用：

```python
if j <= 25:
    lr_j = 5e-5 * j / 25
else:
    lr_j = 1e-5 + 0.5 * (5e-5 - 1e-5) * (1 + cos(pi * (j - 25) / 475))
```

step0是无更新起点。记录used_lr/next_lr，保存500项序列与hash；两臂相同。不要用上游默认1000/30000 schedule或旧GR00T 8000日程。

本地只做了计划数学检查（不是SLA模型测试）：
- 500个LR值；第1步2e-6，第25步5e-5，第500步1e-5。
- 500×32=3200×5=16000访问/候选；两个候选共32000访问。
- 连续4＋独立2＋2资格共8更新/256访问；可选完整RGB/cache对照另2更新/64访问。
- 100个随机SO(3)样例验证 `delta=Rk@R0.T` 与 `back=Exp(Log(delta))@R0`，FP64最大测地误差8.25e-16 rad；平移往返最大4.44e-16（输入单位）。这仅验证公式，不替代全部1450真实数据、TCP/frame、夹爪或模型解码检查。
- H40末标签39×0.05=1.95s，40区间消费=2.0s。

## 4. 不能混淆的比较

S1/S2使用相同公共模型范围、输入处理、采样、dropout、优化器与日程，S2仅增加训练用教师/投影器和空间loss。若实现中只能通过改变其他参数或输入使S2运行，需要新版本而不是沿用原消融名称。

SLA与GR00T比较是工程系统选型：架构、内部表示、采样步数和PEFT范围不同。相同500次更新并不保证算力相同，必须另列模型调用、参数数目、教师成本、延迟与显存。

`SLA_base→S1`普通动作适配只证明利用其预训练权重；`S2`采用固定第12层对齐，不等于作者自适应多层门控的完整复现。任何一个模型的TRAIN4成功都不能替代未见DEV/TEST。
