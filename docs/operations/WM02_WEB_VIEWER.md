# WM02 浏览器实时本体场景

浏览器入口已实现为 `scripts.wm02.serve_native_live`，复用 PR #359 的只读 Core 状态通道、实际批次配置和同 SHA 原场景 MJB。无需安装浏览器插件或桌面客户端，不上传模型到第三方网站。页面与服务只在本机运行。

```bash
PYTHONPATH=src:. MUJOCO_GL=egl "$WM02_VIEWER_PYTHON" -B -m scripts.wm02.serve_native_live \
  --config "$WM02_PRIVATE/READY_CONFIG.private.json" \
  --output "$WM02_WEB_PRIVATE/web-session-NEW" \
  --port 8766 --max-wall 3600 --fps 12
```

服务就绪后打开 **http://127.0.0.1:8766/**。同一台电脑上的其他浏览器也可访问；其他电脑/手机不能直接使用这个回环地址。当前任务未部署外网服务或更改 Core 的网络、SSH 和防火墙配置。

新采集批次先按 [实时状态绑定说明](WM02_LIVE_VIEWER.md) 生成它自己的私有配置，再运行上述命令；不追随目录名猜测运行身份，也不复用 CLOSED lease 启动物理。旧封存记录可以只读显示，页面明确标为“已封存”。

## 画面与交互

- 主画面由原 MuJoCo3.2.7 renderer 使用完整原模型及实际状态渲染。拖动旋转、滚轮/按钮缩放，支持正面、侧面、俯视、默认视角和展开场景。
- 页面显示实际 TCP、左右原生 pad 接触、实际阶段、步数、物理时间、源端数据年龄与接收间隔。暂停、封存、断流分别标注；浏览器与本机服务断开时保留最后画面并显示中断。
- 视角操作只改变显示端独立 MjvCamera，所有浏览器共享这个显示视角。没有仿真启动、复位、单步、动作下发或控制器参数入口。
- 数据/相机均未变化时复用已渲染 JPEG；后端只保留最新快照和最新画面。封存末态不会被反复渲染成虚假的运动帧。页面每250ms读取元数据，渲染限速默认12 FPS，不把配置值写成已测运动吞吐。
- 会话ID随服务重启变化。页面清除旧会话画面，JPEG响应的会话ID必须与当前状态一致，避免复用其他批次/旧进程的帧编号。
- 采集侧无新监听端口；本机 HTTP 仅绑定127.0.0.1并检查 Host/Origin，返回同源资源策略。HTTP只提供固定页面、简化状态JSON、最新JPEG和显示相机参数；原始包、私有路径、SSH argv、模型文件没有下载路由。

## 有限结束

每次启动必须有1..86400秒的有限端点。Ctrl+C只停止本机网页和它自己的只读观察通道；源仿真和原owner保持不变。观察通道异常时该次网页进程结束并写入失败收据，浏览器标明连接中断，需检查收据后重启观察入口。旧收据/失败不覆盖。

`READY.private.json`保存本机URL、进程身份与端点，`RESULT.json`保存真实接收/渲染计数、源身份、退出码、计量CPU和0积分/控制/更新计数。模型、配置、JPEG和浏览器截图留在私有目录。活动目标采集中的持续运动仍待下一次合法原生批次验收，本轮封存显示不替代该项资格。
