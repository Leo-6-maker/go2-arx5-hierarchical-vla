# Shared raw-model source evaluation entry

`shared_policy.py` is an entry for the existing registered Core owner. It loads
the original raw parent through the same factory as shared training, verifies
the42 initial M32 tensors, then optionally reconstructs one saved shared delta.
The producer must be completely closed with actual full-state restoration;
a live8192 producer or a native10 training probe cannot supply a policy.
Producer/input checks precede GPU loading. This change does not mount a job.

The entry supports a finite16-window TRAIN inference qualification and a
single-condition DEV worker. Inference qualification is checkpoint- and
device-specific, requires16 real completed predictions and at least1GiB
measured spare memory, and must be CLOSED before admitting DEV. A training
certificate cannot substitute for it. Training's2GiB qualification remains
separate. Raw zero-step evaluation has an explicit original-parent identity;
it never aliases an adapted checkpoint.

## Task and reset protocol

The new source-only protocol is `SHARED4_RAW_RESET_DEV68_V1`: T1/T2 retain
their24 definitions each (12 geometries × both original noise banks), BOOK
retains10, and DOOR retains all10 candidates, including ones with previous
static failures. Definitions are not filtered using outcomes. It is exposed
DEV, not independent TEST, the old E1/E2 comparison, or target-WBC transfer.

Each condition uses a new registered process, original task geometry and
constructor home, five seconds of initialization, and the original32-second
task with H40/Prefix8/four-step generation. Cube initialization retains full
original opening; BOOK/DOOR retain their original source opening. The raw
scorer gets task-elapsed times; initialization is not included in task time.
The owner verifies the prior unit has exited, its cgroups are empty and no
writer remains. A new engine must show clear controller/IK/history state and
pristine native acceleration cache before cameras or model predictions.

The source constructors and joint/finger controller are unchanged. T1/T2 use
the original cube scene and scorer, including the push no-lift/no-sustained-
grasp constraints and the original held-object/release checks. BOOK uses its
original LIBERO goal/support/release audit. DOOR uses the original cabinet
joint/contact auditor and native goal, not the BOOK scorer. The shared code
adds recorder measurements and routing; it does not tune the controller.
The existing capture loop still records actual commands before native ticks
and keeps unexecuted H40 suffixes out of expert labels.

T1/T2 preserve original `namespace/scene_group/task/sequence` seeds, BOOK
preserves `BOOK5_DEV10/id/sequence`, and DOOR receives a fixed new namespace
`SHARED4_CUSTOM_PORT08_DEV_V1/id/sequence`. DOOR is a custom ARX5 port, not an
original RoboCasa benchmark result. The model receives only actual EEF10,
two RGB views and instruction; task/object/Teacher metadata stays outside its
input. Original cube camera/target visibility and source task camera checks
remain required.

Results retain success/valid/engineering-failure/unrun and hard safety counts
per task. Macro and worst-task success rates require all68 valid conditions;
truncated panels do not create a multi-task capability claim. Each condition
is recorded once. Physics/RGB costs and attempted predictions are retained
even if independent auditing fails; unavailable counts are explicit UNKNOWN
with their finite upper bound.

## Actual validation boundary

Initial local validation:95 targeted CPU checks passed, including original
book/cabinet raw audits, reset faults, the raw Trainer, original T1/T2 score
projection, fixed noise and same-device inference certificate rejection.
These are fixtures, not physical success or GPU qualification.

Core constructor/close checks, actual four-task camera/reset fault qualification,
raw-model native10/native16, DEV rollouts and resident successor integration
are still pending. The existing D2→CONTROL→BOUNDARY queue remains unchanged.
No new shared model endpoint, valid DEV condition or success is claimed.
