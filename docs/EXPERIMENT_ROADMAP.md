## 1. 我们要回答什么

总目标：**将预训练GR00T的操作先验，以尽量少的ARX5本体专属学习迁移到可靠的闭环任务，再研究它对冻结Go2＋ARX5执行器的复用边界。**

当前不再将“持续增加Teacher场景、数据量和训练步数”当作默认路线。先用可比较的行为实验判断，只有具体失败证明需要时才补数据。

| 研究问题 | 对应实验 | 能支持什么，不能支持什么 |
|---|---|---|
| 当前新增数据替换是否有收益？ | 已完成A/B4096；待完成C50/D25 | 数据混合方案的开发证据，不是多场景普遍有效或有害 |
| 预训练共享策略冻结后，少量目标类别参数能否适配ARX5？ | E0诊断＋E1/E2匹配对照 | 固定父模型、数据与训练量下的参数范围效应；不是自动证明零样本或遗忘 |
| 新布局／语言条件是否真正被使用？ | 固定独立场景与配对条件测试 | 指定分布的泛化；训练成功或离线误差下降不等于任务泛化 |
| 源域策略能否复用冻结WBC？ | 原DEC1固定CORR/R0对照 | 无目标任务示范训练下的执行域迁移边界 |
| 少量目标整机示范是否值得？ | 独立Go2＋ARX5标定／适配研究 | 少样本目标执行域适配；不能再称该分支训练与目标控制器无关 |

## 4. 核心研究：E0／E1／E2最小本体适配

采用[固定执行V2](protocols/GR00T_ARX5_MINIMAL_ADAPTATION_EXECUTION_V2_20261027.md)。官方模型／数据接口与本项目的目标类别参数隔离算法要分开表述：`NEW_EMBODIMENT`是新本体适配入口，不是ARX5零样本能力证书；E1是基于官方组件的研究扩展，不是官方已经证明最优的唯一配方。

| 模型 | 初始化 | 可训练范围 | 角色 |
|---|---|---|---|
| E0 | 原始 `nvidia/GR00T-N1.7-3B` 固定revision | 无 | 有限离线先验／条件响应诊断，不自动放行物理 |
| E1 | 同一原始权重及目标类别切片 | 目标类别状态编码、动作编码、动作解码中的14个W/b切片 | 最小本体适配 |
| E2 | 与E1完全相同 | E1参数＋指定共享DiT、vlln、VL self-attention | 参数范围匹配对照 |

VLM、其他类别与共享position embedding均冻结；两臂保持一致的模块模式、数据和flow噪声流。E1虽少参数，仍通过任务示范学习，不称纯机械接口转换。冻结权重不等于可以把整段DiT包成no_grad：梯度仍须传回输入适配器。目标切片独立进入optimizer，防止AdamW衰减未选类别。

### 固定实验条件

- 同一原始父模型，不从CORR、C50、D25或GEN1继续。
- 同一12条原TRAIN示范：6个独立几何各T1/T2一条；原选择与逐cursor序列保持，不加入C1、新目标或GEN1数据。
- effective batch32；先各512步，使用同一1024步学习率日程。512是中间端点，不伪装512步完整日程。
- 原R0、EEF10、H40、Prefix8、20Hz参考、2.5Hz重规划、4步推理、原安全与32秒评分不变。
- 每臂完整保存模型、optimizer、scheduler、RNG、sampler和Processor；资格模型不能当正式fresh父模型。
- 固定统计校准信息可能来自更大原库，因此不能声称仅见过12条机器人的全部信息。

### 必须实际验证的接口

原始权重完整身份；E0／包装后E1／E2在第零步同输入同噪声输出一致；真实目标梯度及非零更新；冻结参数不变；完整恢复和官方格式推理包重建前后输出一致。CPU小模型检查不能替代完整GR00T/CUDA资格。

已有有限会话和配额内先做这些验证，不重新建立复杂资格系统。E1/E2正式结果必须来自两条固定512端点，不按先完成臂成绩改变另一臂，不选择各自最佳checkpoint。

## 5. 评价优先级与结果分流

Core先收齐D25与C50匹配结果，再测GEN1；测量链有效后，Vanda可在明确合法独立范围内推进E0/E1/E2，不需要旧模型先达到某个成功率。

E1/E2两臂512端点均完成后，同一Core评估器分别执行原N294101/24。按12几何成组配对，分别报告T1/T2、成功、参考拒绝、S1拒绝、完整任务失败、工程缺失、实际计算和显存。旧DEV已暴露，只是开发比较；独立确认必须采用预先封存的新几何／分区。

| 结果 | 下一动作 |
|---|---|
| E1接近或优于E2且实际成本更低 | 先做独立新布局确认，再判断技能迁移 |
| E1较差且TRAIN也未拟合 | 检查真实优化／梯度与适配容量，不立即否定预训练知识 |
| 两臂能拟合但闭环弱 | 对齐原参考、实际ACK和失败阶段，查可执行性／状态分布，而非只降loss |
| D25比C50更好但仍低于历史A | 报告相对改善，不称能力完全恢复 |
| 差异不确定 | 只有额外测量能改变决策时扩评；不把不显著称为非劣 |
| 工程缺失 | 报工程阻断，不记策略成功率0%，不改变有效失败 |

512结果有价值且取得对应范围后，才让两臂共同恢复自身完整状态续至1024。不得只延长落后臂、重启LR或自动增加seed／LoRA／比例网格。旧正式DEV48和独立发布门保持。

语言与视觉探针分开：固定真实RGB／状态／噪声切换合法指令；共同home下单因素改变物体或目标。动作变化只证明敏感性，任务成功才支持有效条件使用。共同home是独立初态分布，不是当前LEGACY_MATCHED评价的阻断条件。

## 6. 后继Go2＋ARX5适配：先标定，再少量整机示范

独立遵循[目标标定与示范计划](protocols/GO2_ARX5_CALIBRATION_AND_TARGET_DEMONSTRATION_PLAN_20261028.md)，目前是后继提案，不因合入main自动执行。

第一包保持EEF10：双RGB、语言、实际TCP／夹爪 → 末端轨迹与夹爪 → 冻结WBC → 自由机身Go2＋ARX5。四条腿不要求VLA立刻输出腿关节或BASE；移动意图只在执行器能力和任务确实需要时另立版本。

1. 固定10段短标定：相机外参、world→base→arm_mount→flange→TCP、轴／单位、夹爪、时间、参考替换与停止。两段独立验证姿态。标定记录不混成成功任务示范。
2. 独立6个TRAIN几何×T1/T2，共12次首次尝试。站稳后近场操作、共同home不跟随物体、实际WBC执行，不焊死根节点或直接写关节。
3. 保存实际观测、requested／accepted／installed参考及ACK、实际达到状态和特权诊断。标签来自部署接口实际接收命令，不以未来达到值替换；未执行H40后缀不是执行标签，不跨reset／abort拼窗口。
4. 成功＋安全＋完整数据＋正确codec＋分区成立才进成功库；失败保留，不换seed凑满12成功。
5. 当前E1/E2仍保留原R0。新目标包统计是否兼容要独立检验；需要新统计时仅用TRAIN拟合，不能覆盖旧R0或用测试数据校准。
6. 少量目标训练与等量源域继续训练做匹配对照；独立整机测试，不与当前源域参数范围实验混算。

## 7. 两种迁移主张必须分开

[原DEC1](protocols/DEC1_CONTROLLER_DISJOINT_VLA_SCIENCE_GO_20261021.md)固定旧CORR2048/R0，研究不使用目标WBC任务示范训练的执行域复用与进度反馈接口。core64仍待真实运行，不能用新适配赢家偷偷替代。

如果使用目标WBC生成的Go2任务示范更新上层，这个新分支称少样本目标执行域适配。WBC仍可冻结、高低层仍可分离，但不再支持该分支训练数据与目标控制器无关的主张。

柜门首先是后继单一迁移测试环境，机械可达、接触和评分先成立，再测固定模型；不自动生产大量柜门训练数据。书架先保留设计，复杂技能、行走、世界模型与RL不同时展开。
