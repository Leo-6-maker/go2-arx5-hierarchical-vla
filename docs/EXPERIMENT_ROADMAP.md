# 实验路线 · WM01新研究 + V7现役接续

## 下一科学问题

**冻结执行器、相同任务与动作合同下，小型结构化 WM 能否让上层策略比匹配的 model-free 方法更有效地完成操作和恢复？** 先做状态策略机制试验，之后才判断视觉／语言／跨本体收益。

```text
现役V7/PB/M32 → 按原任务自然推进、保存端点与原面板

WM01 源域原生状态/提交命令 → 小WM → 真实分叉验证预测与梯度
                                      ↓
                         BC共同初始化 → PPO 与 PPO+WM配对
                                      ↓
                      原生任务成功/成本/安全/独立留出评价
                                      ↓（有收益才扩展）
                         DOOR → 状态教师 → 视觉/VLA学生
                                      ↓（独立目标资格）
                              同权重冻结WBC迁移
```

详细计划：[WM01 protocol](protocols/WM01_TASKSPACE_WORLD_MODEL_POLICY_V1.md)。执行入口：[Codex交接](handover/2026-11-03/WM01_CODEX_EXECUTE.md)。参数与工作包：[plan.json](../experiments/wm01/plan.json)。

## 分阶段结果而非文档关卡

| 阶段 | 需要产出 |
|---|---|
| W0 接口与数据 | 原生T1源环境、精确状态恢复、真实动作区间；已有数据哪些可用、哪些缺字段 |
| W1 模型 | 单卡小WM，多步预测、接触/失败分层；动作打乱与持恒基线 |
| W2 决策价值 | 同真实初态分叉，模型排序与梯度更新是否真的改善回报 |
| W3 策略 | 相同BC初始权重、状态、奖励、数据额度下，PPO与PPO+短想象BPTT |
| W4 确认 | 固定最终端点、3训练seed、50新布局；总交互／计算及置信区间 |
| W5 后继 | 有效状态教师在原生环境产生视觉监督，独立比较GR00T/小视觉策略 |

工程可自主修复，有限pilot完成就给机制结论，不无限调loss。模型梯度无效则停止将它用于actor更新；不是放宽原生评分。W5、BOOK/PUSH扩展和目标整机验证不与W0–W4混为一项已授权完成工作。

## 旧实验边界
