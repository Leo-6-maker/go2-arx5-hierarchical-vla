## 2. 三层可复用接口

Go2真实RGB/状态/历史 → SEA-O → 冻结官方SLA-PT → 官方inverse → SEA-A物理意图 → SEA-E参考管理 → 冻结WBC → 自身实测反馈。接口只改变本体表达及执行可行性，不替模型决定目标、抓取阶段或开闭。纯几何、目标投影/FSM/Agent是独立对照或HYBRID，不能计为严格SEA。

**SEA-O (Observation Alignment)**：保持官方3 current views＋9 head history（首帧＋过去8秒每秒一帧）、16D双臂状态、官方图像/token次序与时间。Go2两路RGB、虚拟左臂/左腕缺失明确标记；不能生成虚假的真实左腕视角或隐藏物体。DEPLOYABLE只使用实际传感器、机器人关节/基座、相机标定、几何和因果历史；不使用教师目标、物体GT、任务阶段、成功/奖励、未来帧或GT depth。语言仅原样传递，适配器不按任务目标/颜色选择操作。无实测稠密深度时不能假设完整视角重建；不可见或不可靠区域保留未知/弃权。ORACLE_ONLY可用模拟真值离线诊断，类型与运行权限隔离，原生入口强制拒绝。

**SEA-A (Action Retargeting)**：内部50×32→官方逆变换50×16→右臂8D(xyz,wxyz,g)，逆变换只一次。使用同一查询的状态/基座/工具外参，先将源工具变换至共同物理工具坐标，再转换到目标TCP；源0..49/30秒保留。当前已验证link6/零位/TCP不重新拟合。新虚拟源平台须额外验证源/目标物理工具等价，不直接复制源世界绝对目标。若当前技能需要左臂动作，不转嫁给右臂，标UNSUPPORTED_EMBODIMENT。真实slide/44mm、H40×44mm、旧输出2+40g mm分开；真实指尖间距不等于单指slide。先查源URDF、驱动、实机state/action定义，独立核验开度/方向/接触；不能确认则UNKNOWN_SOURCE_GAP，不准入接触。#491 97%标签会被2–42mm截断，保留原标签；0–44与2–42候选必须在同一事件和真实上一消费边界比较，不改G7/接触安全。无接触时固定开爪仅为安全约束，预测事件仍记录。

**SEA-E (Execution Alignment)**：名义物理意图与执行参考分离。世界系 p_cmd=p_consumed+(p_SLA-p_actual_at_query)，R_cmd=R_SLA R_actual^T R_consumed。查询帧和交接时真实消费参考分别绑定，不重复累加偏置；若负载/姿态改变偏置，只用任务无关校准研究有界残差。复用world_offset/PrefixClock，选合法连续短段（候选源前缀≤0.50s，保真误差≤0.50mm/0.25°），保留source phase和grip事件，按真实接缝速度/加速度、净空和安全求时间律。原生41×50ms世界EEF/base、10Hz发布、TTL0.4s、2ms物理；原50mm/s、0.25rad/s、0.25m/s²、1rad/s²、夹爪40mm/s门不变。网格检查不能代替连续几何/物理资格。每次真实源运动产生可测变化后重新观察，有限滚动而非强制只两次查询；lead/brake/hold/source分别计数。已安装、solver echo与实际MRT选中ID分开（后者未知仍UNKNOWN）。物理安全监督只能拒绝/保持/停机，不能注入教师正确动作。
