## 5. P1：候选链接层 BTF-1

完整标识：`BOUNDED_TRANSLATION_FEEDBACK_V1`。这是**尚未原生验证**的外部执行控制 profile，取代前版每提案一次重锚的执行路径；不改写前版 E1 失败。

### 5.1 一次入口锚定，跨查询保存

在每个 episode 的原稳定入口，或 P/H/T 的明确交接点，读取同一 native tick 的实测 TCP `(p_A0,R_A0)` 和最后实际消费参考 `(p_C0,R_C0)`：

```text
b0 = p_C0 - p_A0
D0 = R_A0.T @ R_C0
b  = b0
p_command(s) = p_intent(s) + b
R_command(s) = R_intent(s) @ D0
```

原模型输出经名义 codec 得到 `intent(s)`，保持不变。`b,D0` 跨查询保存；不在每次 query 自动再做一次 world_offset，不重复加初始偏差。夹爪仍严格来自同一源相位的 `g(s)`。这与 #512 的“每提案重新锚定一次”是明确不同的新实验。

### 5.2 有界反馈只纠正已实际消费的固定参考端点

只在无接触、原编译器已形成合法静止端点、参考 ramp 已实际完成后，保持 0.5 s 真实仿真时间。用最后 0.25 s 的实测均值计算：

```text
error = p_intent(s_target) - mean(p_actual_in_last_0.25s)
delta = clip_l2(error, 0.004 m)       # alpha = 1 candidate
b_candidate = b + delta
require ||b_candidate-b0||_2 <= 0.012 m
require ||b_candidate||_2 <= 0.040 m
```

候选步长 4 mm、入口额外补偿 12 mm、绝对偏差 40 mm 都是**新注册的工程限制，不是已识别的稳定性保证**。超过边界不积累隐藏积分、不放宽边界；记录饱和并按第 7 节分流。每个固定目标最多 3 次补偿，每次补偿都经过原速度/加速度/可达/接缝门和完整 ramp，之后再作真实 dwell。若固定评分窗已经通过，额外补偿为零；仅姿态失败不触发平移积分。只纠正世界平移；姿态保留 `D0`，不增加姿态积分。这里要求参考已消费完，不要求实际 TCP 预先到达意图，否则会把要纠正的残差排除在外。

不得逐 2 ms 或逐 50 ms 将滞后误差直接积进参考，不用 `1/0.73` 做通用逆增益，不按桌高或果实坐标加 Z 偏置。

可用端点为初始 ALIGN 末点、实际完整提案末点；中途 P10 边界只有经过现有编译器明确制动到登记源相位后才可补偿。每提案最多一个额外中途补偿停点。若现有编译器无法形成该停点，本轮直接跳过它，以已资格的固定 `b` 继续，不为此先建新规划器。

### 5.3 接触、源时钟与查询

所有末端/夹爪仍按同一源相位推进。补偿 dwell 是显式、有限的联合时间拉伸，不重复闭爪事件、不倒放源相位、不把保持段计作正 SOURCE 消费。初始 ALIGN 的 ramp、dwell、3 次修正合计最多 6 s native time；超时是执行结果，不能不断重启 ALIGN。第一候选不新增 ALIGN-only 模型重查询救援。

原允许的指垫—目标接触出现时，立即冻结偏差更新，不再累计或安排新的偏差修正；**正常 SOURCE 中的模型轨迹、夹爪和自反馈查询继续**，不能要求松开物体才能抬升。接触时不进行任务目标投影或力控制。补偿 ramp 中途发生允许接触的取消接缝，执行清单另作明确约束；不能假定已安装 ramp 会瞬间消失。解除接触后也不释放积压误差，必须重新取得无接触端点和 dwell 才能补偿。

### 5.4 两张短时资格卡，按布局解锁

每布局一张 `Q00/G00`、`Q01/G01`，不调用 SLA。固定 BASE、原开爪、原稳定入口。预注册的无接触已知目标由入口实测 TCP 定义：Z `+4,+8,+12,+20,+4,0 mm`；G01 在 +20 mm 平台增加世界 X 轴 +2°/返回以及 +4 mm X/+4 mm Z 的混合段/返回。进入、返回与全过程必须通过原门；不主动靠近桌面。每卡含初始化最多 30,000 tick，给真实 ramp/dwell 与至多三次修正留下空间；不是要求用满。

每个目标以最后一次已完成 ramp 后的 0.5 s dwell 为评分窗，末 0.25 s 的位置峰值 ≤4 mm、姿态峰值 ≤2°；实际运动方向正确、没有补偿发散/饱和、没有原安全 STOP，真实净空与终态合法。同时报告**全部过渡段**峰值/RMS和最低净空。未达到时不能改选更好看的窗口；该目标失败，保留结果。

这是新注册的收敛后工程资格，不等同于旧 E1 全评分窗口峰值标准。通过只支持当前布局、负载和无接触范围；真实抓持载荷仍在任务中检验。单布局通过即运行该布局 F/P/H/T；无需等待另一布局。旧已知卡和教师任务均不能计入学生成功。

前缀使用原教师和原安全实际执行或完整、可验证的既有仿真快照机制；不能只写 qpos 并丢掉接触、动力学、控制器/owner 状态。教师到交接后完全退出。模型使用本回合真实因果历史，前缀存在与长度在报告披露；不塞入源视频或未来帧，也不把过去教师动作作为学生输出。

H/T 的意义在于要求模型产生**新的物体运动**。继承一个抓持状态后保持不动、TCP 跟踪成功或空中摆动，不作为本夜主要操作成功。其来源动机是已有 after-grasp 输出更常闭合，但这仍不是 H/T 已具备闭环能力的证据。[T2 归档](https://github.com/Leo-6-maker/go2-arx5-hierarchical-vla/blob/719882e9fd154ffbe995484e7a766ada3b3ecd02/reports/SLA_GO2_V193/TARGET_T2/ACTUAL.md)。

T 是预注册的探索性条件任务，不宣称该 checkpoint 已被官方证明支持这条指令。评分用交接时果实→蓝物体的世界 XY 方向固定计算，所有阈值须在连续 1 s 窗口同时满足；蓝物体 GT 只进入评分/安全，不能生成学生动作。保留完整模型 3D 位姿与夹爪输出，不把动作投影到水平面、不锁住 Z、不强制保握。T 不要求交接后额外抬升，但要保持相对原reset物体高度≥20mm的原合格离桌条件、实际抓持、接触和站姿安全；教师取得的高度明确属于初始化。若既有资格未覆盖该水平方向，先用共享工程后继做最小已知运动检查，再重新初始化 T；资格时已发生的物体位移不能算作学生成功。T 可在210 min分流点根据证据直接选择，无须等 P/H 全部跑完。

每卡最多 120 次新查询、50,000 native tick（含初始化/教师前缀/反馈 dwell）、1,800 s 墙钟，原 STOP 优先。原50行全部保存，未消费后缀明确标识。每次模型刷新必须在合法 P10 边界且已实际消费10个正SOURCE atom，或已实际消费源尾；夹爪运动/静止保持不要求 TCP 移动 ≥1 mm。无离线闭爪通过门，不按输出好坏筛掉有效失败。

### 成功归因的附加证据

至少取得两次模型返回，后一次来自前次实际消费后的真实观测，并实际消费后次输出。若物理任务在第一段就成功，保留原成功事件；后续真实消费至合法终末时任务仍满足、没有随后发生的原安全 STOP，才标 `closed_loop_qualified_success`，不能通过额外脚本保握维持成功。若后续松手或 STOP，保留首次事件和闭环失败，不把“曾成功＋后来查询过”相加成合格闭环。任务原分数和闭环证据字段分别报告。

每个成功必须能够从“官方原始输出 → 名义物理意图 → 链接层参考/时间拉伸 → 实际消费 → 物体事件”追溯。评价/安全可读 GT，行动生成不可读目标 GT。教师前缀取得的抓持或高度不进入学生分子。

### 首次成功后的 C 确认任务

立即冻结成功候选的代码与配置；预登记 C00/C01/C10/C11 为同任务 G00/G01 ×新 seed 2/3。从首次成功布局先跑，然后另一布局；不挑最好视频替换前面的失败。同一任务同一 profile 的新种子只增强存在性与可重复性证据，四格小样本不证明可靠成功率。若另一布局尚无资格，保留其未启动状态。

## 7. 失败分流与自主修复

| 首个被证实的失败层 | 下一动作 | 禁止的替代 |
| --- | --- | --- |
| 序列化、浮点端点、错误时间戳、索引、路径或生命周期 | 自主修实现，检查受影响接缝，以新 attempt 接续；保留中断和耗用 | 将技术启动当有效模型失败，或把实际启动删掉 |
| 实际偏离原意图；参考安全而实际触桌 | 读同相位误差；修链接层连续性/有限反馈；短卡通过后立即回任务 | 调 WBC、放宽触桌门、复用未知未来参考 |
| 原物理意图本身危险/不可达，接口已验证 | 保留原预测拒绝；按预登记转 P/H/T，必要时核验确定性工具映射 | 将目标投影到物体/桌面上，重新规划一个教师轨迹 |
| 已到近抓取区域仍无闭爪 | 直接运行 P；核对实测夹爪编码、官方状态与真历史；P 同类失败后转 H/T | 计时强制闭爪、提高闭爪阈值来“产生成功” |
| 模型闭爪但没有抓持 | 区分对象对准、工具点、物理开度与实际接触；有证据才修改固定几何接口 | 单凭 g 低于阈值判抓住 |
| 已抓持但抬升不足/释放过早 | H 检验；保留所有后续模型松手事件 | 教师抬升、自动保握 clamp |
| 补偿不收敛/达到边界 | 保留 profile 失败；根据固定端点延迟证据调整 dwell/更新节奏，另立 profile；或转已资格任务 | 无限增加补偿、每 query 重置积分、按成功率搜索增益 |
| 接触后负载使执行偏差变大 | 使用已存实际轨迹定位；正常 SOURCE 保持模型主导，冻结误差积分；必要时登记后继链接层研究 | 把未验证接触力控制混入第一候选 |

第一候选只改一次入口锚与有界平移反馈；如果证据要求后继，优先单因素变化：真实时延对应的 dwell/更新节奏，其次确定的几何/编码修复。最多先规划 BTF-1、BTF-2、BTF-3 三个有明确因果预测的行为候选；这不是普通工程 bug 的三次额度。额外有价值的候选可在同授权下写明新有限批次继续，不重置旧失败、不按回合结果同时搜索多参数。

对任一共享原安全异常，先停止该活动作业并定位共因；同样会暴露于该缺陷的后续卡暂停。已独立证明不受影响的布局/任务可继续。一个有效科学失败不通过技术重试换成成功；开发后继必须有实质修复或预登记条件差异。

## 10. 后续长程路线：保持两端冻结

日期以达成前一里程碑后计；以下是推进顺序，不是保证按天取得成功。

| 阶段 | 工作 | 进入下一阶段所需证据 |
| --- | --- | --- |
| **M0：今晚，首个任务成功** | Q→F；必要时 P/H/T；成功后 C | 至少一个模型导致的新物体事件，真实闭环和冻结身份可追溯；或清楚的未成功边界 |
| **M1：D+1–2，复现与固定接口** | 同成功 profile，先完成未运行 C；从独立 reset 检查历史、缓存、补偿和教师交接依赖 | 同任务独立成功；全部尝试保留；链接层无场景专用分支 |
| **M2：D+2–4，补齐完整起点** | P 成功则解决接近段；H 成功则解决形成抓持；同模型从原稳定入口继续闭环，不能用教师拼接 | 至少两个布局上实际完整 F 成功；阶段切换仍来自模型动作和真观测 |

| **M4：之后 1–2 周，第二项完整任务** | 从该 checkpoint 的实际支持证据及现有合法资产中选一个目标；先固定指令/初态/完成条件，再完成本体闭环 | 两个独立任务各有真实成功；同一通用链接层，不能每任务嵌入手写轨迹 |
| **M5：之后，连续任务与可复用交付** | 单初始指令下抓取→保持/搬运→合法放置的连续闭环；控制记忆与源相位跨阶段一致；记录恢复失败 | 完整连续任务成功，阶段无教师接管/隐藏重置；推理包与复现说明完整 |

M3 的新布局从已有合法紧凑工作空间确定，在预测前固定；如需新增 scene/layout，先做原机器人、接触与可达检查，不修改质量、摩擦或夹爪力让任务变容易。一个模型采样种子不是一个全新的独立场景；统计时同时报告布局数量与初始化谱系。

M4 不预设冻结 checkpoint 会推物、开门或放书。先核对该 checkpoint 的官方训练/评测说明或可复用真实源任务证据；选择已有资产和原安全合同可以承接的任务。受控释放、放置或推物若被现役接触规则阻断，不能通过取消该规则伪装为链接层修复；保留该任务的实现边界，继续已合法的任务。无需开启 GR00T 训练或更换 SLA checkpoint 来满足本计划。

M5 的长程成功不能由各个局部成功视频拼接。完整回合只允许一次实际初始化，任务中使用自己的观测与历史；分段指令或外部阶段调度若另行研究，应明确为组合系统，不冒充原单指令策略。

### 冻结路线的止损与结论

若实际执行已合格，F/P/H/T 及可信输入中仍重复缺少所需动作，则可判定“当前 checkpoint＋已测试接口＋这些任务条件下没有成功证据”。冻结权重不意味着可以通过任意工程适配得到所有技能。保留失败的几何/视觉/状态/动作层定位；后续是否研究新的非学习适配可以自主按有限新批次推进，**微调、LoRA、学习式 residual 或 WBC 调参不属于本计划的成功路线**。

## 11. 相机与标定的安排
