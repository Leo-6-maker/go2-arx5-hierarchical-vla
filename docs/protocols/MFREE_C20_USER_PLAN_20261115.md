1. 核心决定
主线转为：限定 M_FREE 的正式采集 → 新数据/时间合同下的一个 SLA 候选 → 原生抓持成功与失败归因。不是继续重复专家资格，也不是立即扩大到所有移动任务。
- 只使用已通过且未隔离的 F1/M_FREE 和带 +8 mm 高层抓点版本的 F2/M_FREE。
- M_ASSIST 保持整个模式隔离。其 F1 成功保留，但不继续该模式采集、学生评价或训练。
- WBC/MPC/腿策略/臂PD/solver/物理/夹爪与真实安全门不变；旧固定-root IK继续依移动协议仅作shadow。
- 不增加BASE head，不使用JOIN10，不把专家轨迹滤波器或任务真值暗接到学生后面。
- F1/F2是同一抓持技能的两种移动/几何条件，不是两个独立操作技能；C20不改名为旧D100，也不证明导航或跨本体泛化。
2. 已证明与未证明
V3四条件中3条完整专家资格通过、1条原生碰桌停止，新增模型调用/更新/访问均0。F1/M_FREE与F2/M_FREE实际底座运动约9.90 cm和8.74 cm。F1两模式在约34.0/33.5秒完成；原V2在30秒截止时分别只抬升7.65/4.94 mm。

这证明冻结WBC存在可完成移动抓持的任务参考，不证明稳定成功率或SLA已学会。F2/M_FREE同时改变了预算和抓点高度，不能混成纯预算消融，也不能用非匹配F2结果宣称M_FREE优于M_ASSIST。

旧F2下坠16.479 mm中，安装平面平移9.689 mm、转动5.015 mm、臂相对运动1.775 mm是精确运动学分解，不是独立因果贡献。+8 mm增加名义净空，不是动态安全证明。内部控制根因保持未知，隔离分支可继续只读分析，不阻塞M_FREE生产。
3. W0：冻结可用操作范围，不新增一轮全套资格
复用已完成的19文件冻结核验、V3 native、时间单调、抓持判据和安全结果。只验证新增加的RGB采集、训练导出与学生时间边界。

绑定范围：
- F1沿成功几何；F2明确记录 BUDGET_AND_F2_FREE_PAD_CLEARANCE、`grasp_goal_raise_m=0.008`。
- 首轮不随机化桌高、物体尺寸、摩擦或危险靠桌动作；只在原安全布局附近预登记小范围xy变化。可提出±5 mm局部扰动作为首批设计，但需静态无初始碰撞，不据学生结果改目标。
- 同一个采集版本不在失败后悄悄调整抓点、滤波参数、速度或预算；需要调整时建立新版本。
- 真实接触/失稳事件立即停止并隔离受影响单元，不为了凑20条自动重试相同危险条件。
4. W1：C4到C20的正式数据生产
4.1 数量、范围与划分
目标 MFREE_C20_FINAL_PLAN_V1：F1 10条、F2 10条完整成功episode。建议每族5个预先定义的安全布局/微扰层×2个独立reset；不是20份重复视频。

首4条（每族2条）属于C20的子集，用于真实RGB/命令/时钟/标签导出联调；不另开重复资格池。首波最多40次预登记尝试，全部失败和成本保留。20条是目标，不是已完成结果；不足时按实际N命名。已证明可用的首个数据快照可以支持有限pilot，不等待D100。

TRAIN/DEV按scene lineage、采集session和episode预先分组，不随机切窗。另冻结移动DEV16：2族×4个未训练布局×2 reset。所有历史验证布局继续作为开发人口，不冒称盲测。

V3现有成功轨迹仅在同步RGB、完整标签来源与时间证据确实齐备时才可纳入；否则只作专家种子，不从状态重渲染伪装原始观察。当前报告尚无正式训练导出。
4.2 必须记录的数据
1. 学生可用观察：同步body/wrist RGB、实际EEF/夹爪、语言、真实时间；episode固定任务frame与标定。
2. 当前query最终专家H40：名义目标、安装参考、抓手命令、任务时间、重规划epoch；原始proposal与最终计划分开。
3. 历史边界：最近已消费参考、t+0.5s连续参考端点、控制器接受的参考identity。命令发布点k9在0.45s，不能自动等同下一query的0.5s边界。
4. 消费证据：query/command/interval身份、supervision_mask、consumed_mask、部分P10的真实tick。未来query不能回填旧suffix消费。
5. 实际运动：base完整SE(3)/速度、关节、EEF、夹爪、对象与接触、原生安全及阶段审计。特权对象位姿和专家阶段仅用于专家/评分/采样，不输入学生。
6. 专家内存：速度、内层滤波速度、角速度、夹爪关闭开始时间、commit时刻。用于审计与后续可观测性研究，不默认变成SLA输入。
0.05s动作时钟与0.5s观测query必须显式绑定。专家采集不加载SLA；相机/writer常驻、有界缓冲，模型训练读取封存版本，不在线热追加。
4.3 监督定义与统计
主候选学习“当前query经连续规划完成的最终H40”，不把未来多个query的P10前缀拼回一个新标签。EXECUTED_REF视图可以保留用于分析，但不立即重新展开两种标签的全部训练网格。

经过规定规划/EEF检查的未消费后缀，可以标为计划监督；不能称实际执行或成功后果。normal query的计划监督与消费分别约40/10，partial prefix按真实证据记录。失败轨迹保留在诊断库，首轮不直接作正常成功BC。

完整处理顺序：物理语义与split → 相对EEF/SO(3)/gripper latent变换 → TRAIN统计 → 冻结 → FP32编码/解码和共同部署入口验收。H40每个点的锚点一致，夹爪反归一化后仅一次sigmoid，state夹爪与action含义独立。

新统计不能直接挂到旧PD4 checkpoint，冒充未修改基线。旧端点保留原统计。若新的统计确需原生验证，每族最多1条前瞻性专家部署链验证（合计2），与历史RP8恢复无关，单独计量。
5. W2：先完成公平的冻结学生基线
现有PD4 EXEC500与FINAL500都保留；新协议每模型×2族×2 fresh reset，共8个学生条件，0新训练。最大任务时间60秒/120query，并报告30秒截面。模型、统计、10步采样、H40/P10与当前raw部署保持身份。

旧30秒负结果不回填。新的60秒实验是显式预算/接口版本，不从中间checkpoint挑选成功。

V3专家的20/20/6/10/3秒阶段预算继续约束专家。学生仅由自己的动作推进，不能用专家内部阶段自动切换夹爪、目标或base。阶段可以离线评分；学生统一60秒上限，不使用特权阶段隐式限制或指导。

F2的8 mm是专家产生标签的几何变体，不在学生动作后自动加8 mm，也不以family ID替模型选抓点。

必须确认teacher/student的0.5s参考锚点一致。若当前学生consumer仍使用上一0.45s行作为新的参考，应修公共时间语义并单列新系统身份；不是把teacher滤波状态注入学生，不能修改旧PD4结果。真实边界按安装参考/solver时钟核对，不仅通过数组下标推断。

这8条可以与C20采集在独立资源上并行，不成为采集或新训练的全局前置。
6. W3：先训练一个新移动策略，不自动叠加所有变量
主候选 MFREE_C20_FINAL_FM1000：
- 固定同一个SLA_base和公共adapter初始化，使用已经验证的VLM/action LoRA与接口更新范围。
- 新C20 TRAIN统计；RGB、有效动作定义、GRIP_LOGIT、H40/P10保留。
- 1000更新，batch32=micro8×4，共32000优化访问；固定1000端点，500只作预登记TRAIN诊断。
- 峰值lr5e-5、warmup50，随后cosine到1e-5；与既有实现兼容性预检，不改WBC。
- FM-only；原state-token dropout0.25，既有阶段均衡采样继续使用，并审计实际曝光。不要重复“阶段均衡”消融。
- 不加空间loss、BASE head、参考误差输入、JOIN10或新平滑器。
从新基础初始化是为了形成可解释的新数据配方；旧PD4作为系统基线，不将两者差异宣称纯数据的单因素效应。若研究继续旧checkpoint则另立recipe，明确统计变换，不静默替换。

完成普通RGB恢复后做固定TRAIN8，再做DEV16。单条预测不合法由原门拒绝并计为策略结果；不能要求离线32/32才允许任何受保护的原生评价。技术依赖与安全profile必须先正确。原生诊断和测试均不插入expert/任务阶段兜底。

若1000步仍持续优化，可在新预算中比较更长训练；若全程几何拒绝或停滞，先定位，不自动延长到20K。
7. W4：按失败类型只选择一个后继变量
- 标签/时钟/适配错误：先修数据/接口，旧结果不改，不用训练掩盖。
- EEF曲率或夹爪速度拒绝：比较FM与一种物理时间连续性监督/结构化输出。匹配臂从相同起点和同C20训练1000步，控制数据、统计、采样、模型参数范围。导数目标需在正确物理时间和姿态表示下计算，不把flow生成向量场叫机械速度。
- 合法但阶段停滞：先检查视觉/目标条件化与gripper事件，再考虑允许的历史输入；不要自动给学生专家阶段。
- 相同RGB/实际状态对应不同历史动作目标：检验跨query历史依赖。后继可用已执行参考/实际状态历史，不能使用专家内层滤波状态、目标真值或未来base状态。此变化独立于loss变更。
- 已能接近/抓持，但偏离后失败：首波至多100个TRAIN专家纠正片段；成功动作与错误前缀分开，安排相同预算普通续训对照。
- 更广视角/物体下失败：C20→C60→C100扩大真实覆盖，再做匹配空间监督；不同scene/episode划分不变。
当前最多预留1个匹配1000步后继，不自动启动。主候选32K访问，加一个匹配臂时合计64K；旧500/3K等训练不重复累计。
8. 并行安全分析：M_ASSIST隔离不解除
仅对保存日志核对84ms事件：完整base姿态/速度、MPC目标和策略年龄、leg输入与实际执行、足接触/支撑、arm目标/反馈、参考更新时刻及最早差异。优先已有信号；缺少数据就报告缺口，不推断唯一内部原因。

比较V3成功F2/M_FREE中相同接近阶段的垂直瞬态、pad净空和跟踪误差，但不得宣称不同fresh runs构成因果配对。+8mm条件不能被自动外推到新桌高、物体或M_ASSIST。

不把微小接触穿入解释为误报；原STOP和隔离保留。未来恢复M_ASSIST需明确机制与独立修改协议，本计划不自动恢复该模式。
9. C20后的技能路线
第一目标是一个SLA模型在M_FREE F1/F2新布局上完成移动接近/抓取/抬升/保持。专家成功不是学生成功。

仅在此后，复用完整真实抓持初态重启F4子技能；子技能成绩仍不算学生自主抓取。先少量合法持物短移，随后F5完整链，最后F6释放/撤离。历史F4学生执行分母0不变。

M_ASSIST_AFTER_GRASP若以后重新研究，触发前整个预览都必须无外部移动路线（不能cursor=0却发送未来移动preview）；路线触发依据实际抓持事件，当前不进入这条分支。
