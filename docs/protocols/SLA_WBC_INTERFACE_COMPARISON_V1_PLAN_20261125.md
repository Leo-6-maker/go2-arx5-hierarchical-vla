## 1. 本轮要回答的三个问题

1. **接口收益：**同一个历史权重，在相同场景、WBC、输入合同、查询规则和安全门下，仅改链接层，能否跨过原来的接缝失败，并取得新的物体操作结果？
2. **模型能力：**共用经资格验证的新执行内核，各模型保留原生输入和动作语义，原始 base、目标训练权重和官方 PT 哪个更能在 Go2＋ARX5 上工作？
3. **完整目标：**当已知完整物理路径能够通过冻结 WBC 时，哪个冻结系统能自行抓取、搬运、放置、释放并撤离？

问题 1 是链接层干预；问题 2 是可部署模型栈比较，包含训练经历和输入／动作表示差异。BASE0 与同编码的 S1_500 另提供较干净的目标训练前后对照。不能用跨架构排名单独断言“官方后训练降低了能力”。

本轮新增训练更新为零。既有权重曾使用多少 Go2 数据独立列出。“本轮冻结”不等于“历史零目标训练”。

## 4. “同一接口”的实现边界

共用的是**一个确定性执行内核及相同 WBC／安全系统**，不是让所有模型使用 PT 的同一套数值解码。

| 部分 | 必须保持的合同 | 本轮允许改变 |
| --- | --- | --- |
| 真实观测 | 相同物理 world；各自原生相机路由、mask、历史、状态编码和统计。B0/S1 严格共用编码 | 修复有证据的 RGB、时间戳、路由、读写错误；修复前后输入身份可追溯 |
| 输出含义 | 历史目标模型解释为 WBC command/reference；PT 按已声明的源 future-achieved／名义物理目标解释 | 通过显式、带单位／frame／tool／time 的确定性转换进入统一执行层 |
| 接续 | 从上一真正消费到的参考命令及其边界状态续接，不把观测指宽当上一命令 | 有限、保持目标几何和事件次序的接续／重定时候选 |
| 位姿反馈 | COMMAND 类型默认不叠加 PT BTF；原 command 可能已含教师补偿 | 只有独立证据显示需要时，另设反馈副实验，不能夹入主比较 |
| 夹爪 | 旧 command 使用自己的解码。PT 的 GRA 是源语义转换 profile，需读回其实现与适用范围 | 不给旧 command 再加一层预紧；所有模型保留自行张开／松手 |
| 安全与退出 | 原完整预测预览、速度／加速度／碰撞／站姿门、2 ms physics | 修复 STOP/CANCEL 生命周期；L0/L1 两臂共用该修复 |

新执行层不能使用物体 GT、教师阶段、目标位置、成功评分去决定抓持、保持或释放。物体真值只供评分和离线物理资格。冻结模型的输入槽不擅自增添“上一命令”；上一命令可供执行层使用，但其是否被模型编码要如实记录。

**L0：**在同一冻结 WBC 上恢复历史编译／接缝行为，保留原 decoder、时钟和安全门；共用必要生命周期修复。先用归档输出证明与原行为相符。

**L1：**保留各模型原生物理意图，使用修正后的确定性执行内核。首先只引入已证实的 frame／锚点修正及有界连续接续候选；完整保留原始预测、编译后路径、延迟及失真。已经合法的轨迹应尽量不改动。越界或非有限输出仍拒绝，重定时不能使非法开度变合法。

若 WBC、solver、PD、动力学 hash 不能在两臂保持一致，该组不能解释为接口单因素效果；先修复装配，或明确标成系统复现而非因果配对。

### E0：让历史资产真正可运行

先读封存 manifest，再做最小真实加载。B0 优先从干净父权重构造独立零更新推理包，核对未混入 S1/SHIFT7/MAIN 学过的投影。历史 exporter 只支持 4、250、500 步，不能把 4 步资格包冒充 step 0；若存在真实 step-0 包则按实际证据复用。[S8] 可复用相同版本下 dense 与 zero-B 的已封存一致性结果；若重建编译环境发生变化，执行必要的真实数值复验，不能只凭 B=0 口头认定相同。

归档重编译优先覆盖：

- M38 原全部 353 份预测与六个首失败；不只挑三个已抓持片段。
- S7 三个成功回合的所有已消费预测及三份 H40 边界拒绝。
- PT 两份最新正常入口完整 H50，以及可访问的 V1.9.6 条件抬升包。

先复现 L0 的原接受／拒绝，再统计 L1 的合法接续、完整后缀、最大延迟、夹爪事件顺序和目标误差。不能以离线可编译率当物体成功率。

五模型每个最多两次加载冒烟，另在六种真实封存状态（接近、闭合前、真实抓持后的首查询、抬升、搬运、释放）各两份噪声下诊断，共 10+60=70 次前向容量。缺少真实输入历史的窗应记不可构造，不拼接伪造观测。离线是否闭爪不作为进入合法原生任务的先决条件。

### A：M38 六对接口实验

固定红 HOLD、蓝 HOLD、红左放、红右放、蓝左放、蓝右放六条件，使用原 F1-G00 场景和任务 spec。每一条件各有 L0/L1 一张，顺序交错。旧报告只作历史参照，不能直接替代新的 L0 以宣称严格配对。

保持相同权重、噪声序列、初态配置、图像处理、P10 查询规则、原生时钟及任务截止。L1 改变轨迹后，后续真实观测自然会变化；不能用固定图像替代反馈。报告入口 qpos/qvel/ctrl、TCP 和 RGB hash 的残差，不把 fresh reset 称为完整控制器状态逐位一致。

主要看四个递进事件：正确抓持 → 抓持后下一份预测真实消费 → 物体抬升至少 20 mm → 连续持有至少 1 s。PLACE 条件继续评分正确放置、释放和撤离。原 40 mm/s 夹爪门照旧。

### B：跨模型共同站姿任务

采用两类固定真实场景：

- **D_TARGET：**历史目标训练域块体布局，优先使用 A 的 F1-G00、原红物 HOLD 任务及未抓持初态。
- **D_SOURCE：**官方水果任务近源布局，优先当前已归档配置；执行目标先明确为绿色水果 Pick & Hold。

同一场景内五模型共享实体、材质、碰撞几何、初态、任务文本语义、站姿 WBC、安全与评分。各模型从真实状态获得自己的原生图像和状态编码。旧模型不被强塞九帧历史，PT 不被压成两路输入。PT 当前首轮查询合同绑定 #515 的 P10；H50 30 Hz 原时轴不改。S7 进入 B 时需通过站姿装配资格，其原移动任务成功不自动授予该资格。

B0/S1 的输入、统计、目标 decoder 和采样配置一致，因此这一对子结果可以较好隔离既有目标训练；其余比较是完整模型栈。不同动作形状不能强称“跨模型同一个噪声张量”，同模型的 L0/L1 才要求 exact noise。seed 0/1 是配对编号，实际 PRNG/key/张量 hash 单列。

当 D_SOURCE 的完整搬运尚不合格时，仍可运行已具备抓取／抬升资格的 Pick & Hold。它有独立任务指令和分母，不计为完整 Pick & Place；不能将中途改任务当同一回合成功。

### C：S7 原 M_FREE 阳性回归

从原封存人口选 F1、F2 各两条完整条件，选择规则与 ID 在看新输出前绑定：F1 包含历史成功条件，F2 包含接触和 H40 拒绝两种机制。四对保持原 M_FREE／SIM_PAUSED_NATIVE、H40/P10 和原综合评分。

这里报告抓持／抬升／保持以及底座位移至少 80 mm。它不能与 B 的站姿成功率合并。若 L0 原阳性未复现，先查环境和包；若 L0 能复现而 L1 退化，先查重定时、补偿叠加和 frame，不能直接换权重掩盖问题。

### QP／D：回到完整自主 Pick & Place

当前近源完整已知路径仍未通过，不能用这一布局给所有模型打上“不会 Pick & Place”的结论。先按完整包络选择近源布局，统一检查启动、接近、抓握、搬运姿态、碗沿、释放和撤离；来源可复用已筛查的官方示范，但不是只抽取可行的中段。场景调整必须先于所有模型输出冻结，原失败保留。

QP 的教师用于证明物理可达，不在 D 接管。D 从正常未抓持初态、单初始完整任务指令开始，阶段由物体结果评分而不进入策略。必须由模型发出闭合、抬升、搬运和张开动作。保留原实测接触／承托判据。闭环声明要求至少两份返回被正量消费，其中至少一份来自自身运动后的新观测重查询：total_model_returns_consumed≥2 且 fresh_observation_requeries_consumed≥1。物体任务结果与闭环资格分列；纯一次开环轨迹即使完成动作，也保留其物体结果并另标开环。

S7 特殊夹爪编码若只能表达有限事件，仍保留其真实能力边界；不能在接近释放时替换 decoder 或手工开爪。

### E：独立确认和下一步路线

根据 B/D 的开发结果选择一个完整冻结系统，参照固定为 PT；若 PT 本身胜出，则参照 M38。候选必须完成共同已启用人口，不能以缺失条件获益。按以下顺序排序：完整任务成功数 → Pick & Hold 成功数 → 抓持后新查询消费数 → 自主正确抓持数 → 非法接触次数较少；仍并列按 B0、S1、M38、S7、PT 的登记顺序。仅用共同覆盖、同任务和同版本的结果，不靠离线损失挑赢家。若固定参照没有可评估合同则报告阻断，不临时挑弱参照。

使用五个未用于本轮调参的新布局、每布局两 seed；保持两个系统完全相同的物理条件。布局输入清单在候选选择前封存，候选与链接参数冻结后才执行 QE/E。每个布局需有相同冻结版本的真实任务物理资格；可精确复用，缺口由 QE 的最多五张零模型卡补齐。资格失败的布局记 BLOCKED_NO_PHYSICAL_PATH，保留其封存身份，不按学生表现换成更容易布局。确认后同时报告精确 n/N、每布局表现、配对胜负及区间；不把 2/2、3/3 或 6 对 pilot 当作普适可靠性。

优先确认完整 Pick & Place。若完整物理资格仍未成立，E 只能作为明确命名的 Pick & Hold 确认，不能宣传为最终目标完成。待一套完整系统确认，再逐项改变位置、物体、视角、语言和任务类型，使用同一冻结版本测试泛化；本轮不自动启动新微调。

## 6. 如何判断接口修正有没有帮助

| 新结果 | 支持的结论 | 下一动作 |
| --- | --- | --- |
| M38 接缝拒绝下降，抓持后有新增消费，但无抬升 | 执行连续性改善；完整技能尚未证明 | 查原始抬升意图和实际消费，区分预测没有抬升与执行没有跟上 |
| M38/S7 新层下任务成功，PT 仍不闭爪 | 当前任务的目标训练模型栈更有效，接口不足以解释 PT 的全部失败 | 保留 PT 的源阳性及输入／阶段差异；不立刻追加大训练 |
| B0 与 S1 明显分化 | 在同 codec 下目标训练有作用 | 报告零梯度基线已用目标统计；不给后训练净效应泛化结论 |
| S7 原 L0 成功、新 L1 退化 | 新层有副作用 | 检查重定时、command/achieved 误用、双重补偿；修复后新版本 |
| 五模型和已知轨迹都在同工作区触门 | 共同执行／物理包络仍受限 | 优先查包络和参考实际残差，停止反复换权重 |
| PT 抓持和后续操作也改善 | 接口曾限制可迁移能力 | 固定该版本，进入同条件完整任务和独立确认 |
| 某模型缺资产或输出合同 | 目前无法评估 | 记 ASSET_UNAVAILABLE / CONTRACT_NOT_QUALIFIED，不算 0% 科学成功率 |
| 合同完整但输出越界或原安全门拒绝 | 有效策略／系统失败 | 保留分母，不 clipping、不删后缀，不称为缺资产 |

“拒绝少了”不是唯一验收。必须同时看非法接触、抓持丢失、时序延迟、参考跟踪、物体结果和 STOP 后活动。若更长的平滑过渡把有效任务推过时间预算，仍按原上限失败。

## 7. 评分、分母和终止

每面板分别报告：预登记条件、启用条件、全启动、有效科学终态、技术中断、未启动／阻断。成功率同时给成功／有效与成功／全启动；技术问题不从已发生启动中消失。重复修复用新 attempt/version，原失败保留。

阶段结果包括：自主正确抓持、抓持后新查询消费、20 mm 抬升、连续 1 s 保持、搬运、真实释放、目标区域承托、撤离、完整任务。不能用夹爪码跨阈值替代接触与物体结果。0.55 仅是 PT 旧诊断码，不适用于所有模型。

安全门触发立即结束该卡。相同未修复工程错误再次出现时暂停对应版本查原因；普通科学失败按封存面板保留，不按结果挑着补跑。接口修复可自主完成，写明缺陷、变化、受影响验证和新版本即可，无新增逐项人工批准。

共享的新执行层发生生命周期或身份问题时暂停使用它的所有面板；只属于某模型资产的问题不冻结其他模型。已健康运行的自有作业不被热替换，单 world 保持一个物理 owner。
