## 1. 系统契约：从“发送参考”变成“执行-观察-重新决策”

保持现役原生 ABI：官方经逆变换50×16（两臂各8D），取右臂并以**查询时**臂基座和工具外参转换世界TCP；内部50×32采样器与14个物理动作通道不得混同。上层完整TaskSpaceIntent持有source clock、绝对MPC执行时钟、source knots/gripper events、query_id、epoch/revision和输入hash。实际消费参考及夹爪命令的最新接缝状态由独立账本提供；绝不以查询时旧夹爪命令或实测开度冒充上一条实际消费命令。底座在前期保持站立和已登记参考；原生接收器仍使用41个50ms世界EEF＋base点、10Hz发布、0.4s TTL；2ms物理、原H40/G7、有效期、控制权、碰撞及STOP不变。

**新的事务执行器（不更改SLA网络和低层WBC）**：
1. STUDENT_RESET → 独立owner、无接触、姿态稳定、有效参考及已消费ACK。不要从教师正在抓取的时钟或教师持物切换；初态筛除计入独立reset分母。
2. OBSERVE → 用真实body/right wrist、真实timestamp的1s头部历史、实测EEF和双指状态、原语言；固定虚拟左输入与版本，模型返回须匹配query时刻坐标和哈希。
3. PROPOSE → SLA产生源50点及真实gripper提议；编译器保留原几何/事件、区分lead-in和源进度；任何有界几何修改记录偏差与事件，不代替模型选抓取目标。
4. ADMIT → 原动力学、场景几何、接缝、owner、停止资格全部通过。将旧参考的未来可修改段和平滑接续分开；不能用“已安装”或“求解器回显”冒充实际关节应用的完整policy ID。当前MRT选中策略ID缺失须显式UNKNOWN。实际观测的新鲜度应在**源运动真正开始前**复核，超出注册容差/时限的源意图取消并重新查询，不能让排队的过时提议控制机器人。
5. EXECUTE → 只消费合法的执行段；底层独立10Hz更新，不需要等待GPU；记录source time、execution phase、实际TCP/开度/接触、各自参考身份。源轨迹进入和lead-in位移分别统计。原无接触阶段不得进入物体接触；独立安全控制器随时veto/HOLD/STOP。
6. VERIFY → 只有实际沿源路径达到预登记进展、或到达任务相关的允许终点，才完成此事务；绝不因50点已经发布、P10走完或距离容差包含静止就完成。超时、无进展、错方向、过期、owner丢失或接触违规按预登记停止。
7. REOBSERVE → 在学生自身的真实执行后获取新图像与实测状态，生成下一次SLA forward；不必硬性0.5秒不断推翻前一动作。旧窗口可以保留原P10更新为对照；以实际闭环吞吐、动作年龄、源进展和安全为主指标。

保护前缀2.05s是上层策略，不是WBC物理不可撤回时域。#452已证明某些原生参考可改写50ms后的未来点，同时新安装后4–10ms仍可能出现旧求解器命令。**若要改前缀、改入口姿态、改执行时序或缩短源轨迹，均需独立对照；不要再试图在固定#467端点约束内通过调参赢回78ms。** 初期优先使用稳定预接近起点、事务式阶段执行及真正自主的任务时间线。

### D1：固定时钟动态评估（不能靠静止通过）

在运动段2001个同步点用#471原评分，不优化时延、不截掉失败段。位置和旋转分别取去均值的实际变化 y 与目标变化 r：
Q = 1 - Σ||y-r||²/Σ||r||²；g = Σ<y,r>/Σ||r||²。
同时报绝对误差RMS、max、完整4mm/2° tube、各轴投影方向、终点和1s dwell、真实发出参考与名义目标差以及实际TCP与发出参考差、延迟诊断、持有或无进展时间。比较四条真实保持对照和解析park/reverse/ideal。正分可由微漂移产生；不能只凭Q>0或一个综合分。任何未完成的运动段都不能拼接或用未来数据补成通过。

#472每个条件只有1张，是**机制探索**，不报告泛化成功率/A1显著优越性，也不由单卡自动解锁学生。结果后的分叉：

- 若某速度/条件既有原绝对精度又有明显正确的动态运动，锁定该速度与控制版本，申请小批独立重复D2。在达到相同跟踪性能时优先更简单的A0；不能因为A1曾静态成功就先验选择A1。
- 若慢速可跟踪、源速度不可跟踪，第一版只在慢速已验证适用域内推进，不放松H40/G7；后续单列加速研究。
- 若绝对误差小却Q接近保持/方向增益低，明确 HOLD_FALSE_PASS；若形状好但绝对偏置大，明确 OFFSET_OR_SERVO_GAP；若持续过期/振荡/接触，停止排查，不进入学生动态任务。
- 若两档都无法执行，先诊断是否把名义任务运动与外环纠偏混用。以原A1为对照，独立候选 A2_FEEDFORWARD_RESIDUAL：名义世界任务轨迹前馈＋进入时已验证参考偏移＋有界反馈残差。位置形式 r_cmd = r_task + b_entry + b_residual(t)，旋转使用一致的SO(3)群组合，入口与上一真实消费参考连续，残差限速与总参考硬门分别检查。不得把已有34mm静态补偿重复累加；不得全局直接用1/g或把当前0.40mm/100ms上限直接加到任意运动。若现有A1已分离名义运动和残差，则仅诊断，不重复开发。新控制器必须CPU预演、已知动态独立实验及新安全资格；冻结低层二进制不变。如仍无法达到任务需要，再独立研究WBC/第3、4轴负载控制，不在冻结主线隐式修改。

## 6. 长程 L：Skill Library + Agent（离线可先设计，执行有门）

层级固定为：Agent (language goals / scene belief / plan / recovery) → Skill Executive (typed tool calls / allowed capabilities / completion receipts) → SLA local manipulation (task-space EEF + gripper proposals) → continuous reference + feedback + safety → frozen WBC。原SLA只有50步局部动作，没有原生独立skill_id或Go2导航输出；不能把外部Agent的计划归因于原始SLA。学习型phase/subgoal head可作为独立变体，与纯SLA、固定FSM和Agent对照。

离线即可定义工具合同：
- `observe_scene` 返回由真实感知维护的目标ID、可见性/不确定性、当前持有物、完成状态、时刻；GT仅评分。
- `request_skill(skill_id, object_id, target_region, constraints, timeout, revision)` 只调用已经注册/通过资格的技能；不输出任意电机力矩、ROS包、原始夹爪权限或安全阈值。每次执行均走SLA和Governor。
- `check_skill_result` 返回 SUCCESS / BLOCKED / FAIL / UNKNOWN / STOP 与actual state、证据来源、资源；不以模型语言自述代替物理完成。
- `cancel_skill` 必须走已验证STOP/撤回语义；在途动作与重复调用作废；Agent只能计划，不得自动修改冻结控制器、绕过安全或自行增加科学预算。

长程组合顺序：单物体可靠抓放→两物体按不同顺序/区域整理→换指令/移动物体后的局部恢复→多物体整理/模拟书架放置。与固定FSM/纯SLA在同一技能库和控制器下对照，用任务完成、顺序约束、错误恢复、无效调用、时间和安全拒绝评价Agent增量。**书架插入需额外可达/夹持/接触技能；开门是带持续接触力和移动底座协调的独立任务，不是现有方块抓取的简单语言改写。** 门与移动底座只在独立基座导航、支撑、接触/动力学安全和技能资格后注册；不属于#472或本计划自动授权。
