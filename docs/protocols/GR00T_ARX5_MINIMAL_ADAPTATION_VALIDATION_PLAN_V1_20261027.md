## 1. 判断与必须修正的前提

建议验证“少量 ARX5 数据和少量本体参数，能否复用预训练操作先验”，优先级高于无条件扩充红方块 Teacher 数据。但尚不能断言仅改接口就足够，也不能把已有 B 臂下降归因于灾难性遗忘。

本地代码已核实：

- 现用上游已经是 N1.7，固定 `51d4c89f72fda44cbf77285c6a8114b52676b8a1`，无需为本研究升级到 mutable main。
- `scripts/pi0292/train_adapter.py::build_processor` 已使用 `NEW_EMBODIMENT`、路由 id10、双 RGB、相对 EEF `XYZ_ROT6D` 和绝对夹爪；原始导出保留实际提交的绝对 EEF10，再由原 processor 转换。相对 EEF 并不是本次尚未实现的创新。
- 当前 R0 为 `fb5f5bc6969fae47f51b8a6acefdd7312ed948a0fad4b9f9a79e1fbb9aa325c7`。P0 state 数值/曝光审计已经结束；不重开全量 state 诊断或重拟合旧统计。
- 当前 `scripts/pi0294/e1/model.py::load` 冻结 LLM/visual backbone，但训练 projector、DiT 及 `vlln`/视觉语言 self-attention 路径。这比“只改机器人接口”更广。
- C50、D25、GEN1 从已做任务适配的共同 CORR2048 出发，不是原始预训练权重。它们可作现有路线参照，不能充当同父模型、同数据、同曝光的轻量适配因果对照。
- A/B 原首 N294101 面板为 A11/24、B6/24，T1为7/12对5/12、T2为4/12对1/12。只是该开发面板上的描述性退化；历史报告还保留“完整运行环境尚未完全证明一致”的限制，更不能据此定位单一原因或断言遗忘。

官方资料支持可行性而非效果保证：官方新本体指南要求机器人示范和模态配置；预训练 tag 与 NEW_EMBODIMENT 有明确区分。[新本体指南](https://github.com/NVIDIA/Isaac-GR00T/blob/51d4c89f72fda44cbf77285c6a8114b52676b8a1/getting_started/finetune_new_embodiment.md)、[tag定义](https://github.com/NVIDIA/Isaac-GR00T/blob/51d4c89f72fda44cbf77285c6a8114b52676b8a1/gr00t/data/embodiment_tags.py)。N1.5 的 GR-1 零样本结果也说明该本体在预训练中出现，不能推成新 ARX5 已有可靠零样本执行能力。[官方研究页](https://research.nvidia.com/labs/gear/gr00t-n1_5/)

## 2. 科学问题与结论边界

主问题：**固定父模型、目标数据、R0、样本消费顺序、更新数及执行器，仅改变可训练参数范围，ARX5 的闭环任务能力和迁移表现有何差别？**

另列三个可检验假说，不预先当成事实：

1. 目标本体编码/解码参数足以支持基础操作，共享 DiT 可以保留。
2. LEGACY_MATCHED 初始末端与物体关联，使策略有使用状态捷径的机会；共同 home 下应直接测量而非推断。
3. 广泛任务微调可能损害预训练行为保留，但也可能只是训练曝光或优化时程不同。

“只用少量参数”不等于“纯本体、无任务学习”：这些参数仍通过 T1/T2 任务示范训练。要声称任务迁移，必须另外测试未在本项目适配集出现的任务家族。

共享权重不变也不保证旧行为不退化；新适配器仍可能改变动作分布。只有模型参数审计与真实保留/迁移行为同时支持时，才可判断能力保留。轻量适配失败、充分微调成功，同样是有效且有用的结果。

## 3. 对照模型：先两臂，后条件扩展

| 标识 | 初始化与训练 | 作用与解释 |
|---|---|---|
| E0-raw | 固定原始预训练 checkpoint；不优化任务参数 | 离线接口/条件响应诊断，不默认是合格 ARX5 零样本策略 |
| E1-adapter | 同一原始预训练 checkpoint；只训练目标 ARX5 类别的 state/action encoder、action decoder 参数 | 最小本体适配主臂 |
| E2-matched | 同一原始预训练 checkpoint；相同目标类别适配参数，加现有范围的共享 DiT、vlln/视觉语言 self-attention | 同条件充分动作头微调对照；冻结 VLM |
| E3-conditional | E1加少量、名单固定的 DiT LoRA | 仅 E1 确有适配不足且 E2 更好时才考虑，不自动启动 |
| Historical | CORR、A/B、C50/D25、GEN1 | 工程与行为参照；不混入 E1/E2 的因果估计 |

E0 必须披露：实际 checkpoint 的 embodiment mapping、ARX5 目标类别切片来源、是否未适配、任何新增参数的初始化、processor/R0 信息。仅把 tag 注册成 NEW_EMBODIMENT 不会赋予可用行为。未核验的类别输出失败不能用来反驳预训练策略先验。不得把 ARX5 假标为 DROID 来宣称跨本体零样本成功；若后续研究 donor 初始化，必须作为另一个预注册变量，两臂同样使用。

E1 可复用官方现有三个 embodiment-conditioned 模块；这是源码层面的可实现性判断。[模型及冻结开关](https://github.com/NVIDIA/Isaac-GR00T/blob/51d4c89f72fda44cbf77285c6a8114b52676b8a1/gr00t/model/gr00t_n1d7/gr00t_n1d7.py)、[按本体类别选择权重的实现](https://github.com/NVIDIA/Isaac-GR00T/blob/51d4c89f72fda44cbf77285c6a8114b52676b8a1/gr00t/model/modules/embodiment_conditioned_mlp.py)。不据此承诺它能开门或整理书架。

## 4. 阶段 A：最小工程契约审计，不重开旧 P0

预计工程工作量：半天至一天，不含未知环境修复；估算不是新的有效窗口。

1. 只读核对原始预训练 checkpoint、processor/config、类别映射、目标类别切片、实际 horizon/维度、R0 和源版本；和 CORR2048 身份分开。缺少的 provenance 记 UNKNOWN。
2. 确认原始模型向本项目 H40、Prefix8、4步推理配置对齐时哪些只是配置、哪些改变权重形状。任何必须初始化的参数列出名字、形状、seed，E1/E2 完全相同，不静默接受 missing/unexpected keys。
3. 产出参数白名单：E1仅目标类别的三个编码/解码组件，冻结共享 position embedding、DiT、vlln/self-attention、VLM及其他本体类别；E2只在此基础增加预声明的共享动作头组件。不能只依据命令行 `tune_projector` 推断冻结边界，该开关还涉及共享参数。
4. 类别参数是真正独立可优化的切片/参数，而非给整张类别 tensor 简单加 gradient mask。当前 AdamW 有 weight decay，零梯度行也可能变化；优化器 state/衰减范围必须匹配白名单。保存所有冻结类别的前后 hash。[AdamW定义](https://docs.pytorch.org/docs/stable/generated/torch.optim.AdamW.html)
5. 冻结 DiT 的权重不等于给整个 DiT 前向加 no_grad；仍须允许梯度回传至输入适配器。冻结 VLM 的特征可按契约复用。精确计算 trainable numel/总参数占比与显存，不预称“只需1%参数/显存”。
6. CPU 小型可控模型验证冻结、梯度、AdamW、保存/恢复、原 processor round trip；真实模型和 CUDA 资格在合法 allocation 内另验。

交付：`BASE_MODEL_AND_SLOT_PROVENANCE.json`、`ADAPTER_PARAMETER_MAP.json`、`FREEZE_AND_RESTORE_CONTRACT.json`、显式的新 recipe/profile/parent 身份。复用原入口但不冒充旧 GEN1/C/D 请求，不修改其固定源码。

## 5. 阶段 B：冻结数据与共同 home 诊断分区

首轮拟用 **12条原有合格 TRAIN 父示范：T1六条、T2六条**，尽量覆盖至少六个独立几何组；具体名单以真实库可支持的完整谱系为准，未冻结前不称已满足。任务、父轨迹/几何、衍生外观和重叠窗口一起分组，旧 DEV 不回流 TRAIN。

- E1/E2 使用逐 cursor 相同父轨迹、anchor 和批次消费序列，不能只说“数据集相同”。
- 目标上界每臂1024更新、有效batch32；首轮先在预注册512端点交付（每臂16384次访问），条件续到1024则每臂总32768次访问。窗口不是独立示范，报告每个父轨迹、事件和窗口的实际曝光。
- 首轮保留 R0、原 loss/采样/夹爪语义、4步推理、H40/Prefix8，不同时改 dropout、相机、归一化或动作表示。
- **R0 含原训练库统计信息**：这轮是固定统计的参数范围研究，不声称只获得12条机器人数据的严格 few-shot。正式数据效率曲线另设 TRAIN子集统计或事先声明的校准信息条件，作为独立版本，绝不修改旧 R0。
- 后续6/12/24父示范采用预先冻结的嵌套谱系子集；仅主对照有结论后扩，不同时铺开多seed、多LR、多数据量网格。

共同 home 从既有三个候选做独立版本，先选定一个不随物体位置移动的姿态。固定六个 TRAIN-only 诊断布局，预定义只改物体/只改目标的配对变化；验证可达、相机可见和完整初态安全。如果一个共同 home 覆盖不足，按预先规则报告缺口或有限分组，不为每个物体偷偷调 home。

CPU离线合同测试可先做；实际 reset/构造/零积分渲染仍须计 constructor、进入合法隔离运行，不因“CPU/零积分”就免除原生资格。legacy 与 common-home 数据和结果分表。共同 home 是检验捷径的新干预，不是已有视觉泛化证明。

## 6. 阶段 C：有限、配对的离线探针

先做 E0 的输入输出可解释性，E1/E2 后做相同面板。不得在登录节点运行模型。匹配每对初始噪声、checkpoint、precision、输入时刻和相机来源；保留 normalized 与 decoded H40、首Prefix8及生成耗时。

| 面板 | 最大规模/模型 | 检查 |
|---|---:|---|
| V：视觉/初态解耦 | 六布局×legacy/common-home×两指令×三噪声=72次 | 固定home移动物体或目标时，动作在正确坐标系中的响应；与 legacy 对照 |
| L：语言条件 | 十二个合法已采集 TRAIN 状态×两任务指令×三噪声=72次 | 同RGB/状态交换指令，覆盖接近和接触前等可合理分化时刻 |
| 总上界 | ≤144次/模型；E0/E1/E2共≤432次 | 不含另列的原资格、加载和固定TRAIN probes；不得把432当整个工作包的query上限 |

原始状态直接来自真实同步记录，不能把物体移走却保留旧图像/状态。语言反事实没有对应正确 Teacher 标签，不进入训练。图像遮挡/状态置零若做，属于额外 OOD 诊断，不能取代主面板。

指标：finite与格式有效、原尺度/参考系、参考门/S1拒绝；首Prefix8与H40的物体接近方向、目标方向、旋转/夹爪、路径/速度；物体/目标位移与解码动作变化的方向及幅度；跨噪声响应稳定性。均按几何/父轨迹聚合，不把432个相关生成当432个独立场景。

**动作不同不是理解语言的证明，t0动作相似也不是不理解的证明。** 抓放与推物前期可能共享接近动作。只有方向/动作语义一致且后续真实行为支持，才谈条件使用。离线误差、loss或漂亮轨迹不是闭环任务成功。

## 7. 阶段 D：同父模型、同数据的两臂训练，先512再条件1024

固定原始预训练父权重，E1/E2 各自 fresh optimizer/RNG/sampler；不得从 CORR/C50/D25/GEN1 接续来代替该主对照。当前原始父、同数据量、同初始化和同曝光对比必须先成立。

统一计划的 scheduler horizon1024、effective_batch32、seed20261019、LR1e-5至1e-6、warmup64及现有数值/优化器设置，仅可训练参数名单不同。**首轮事先固定在512步暂停，交完整模型/processor/stats/optimizer/scheduler/RNG/sampler；这是新研究的pilot端点，不冒称旧GEN1024完成。** 如条件续接至1024，两个模型各从自己的512完整状态继续，不重置scheduler、optimizer或样本cursor，不继承另一臂。原Trainer固定1024端点的检查需在新scope冷适配，不能通过伪造旧GEN身份绕过。继承这些优化值是受控首测，不声称它们对轻量适配最优。保存256/512/1024学习证据需事先完整算入空间；不能看DEV临时挑checkpoint。

若 E1 连 TRAIN 几何/离线动作都未拟合，阴性结果只针对这一冻结范围和优化时程，不能否定所有轻量适配。再考虑预定义的训练侧LR/容量诊断，不基于已看过的DEV逐项追分。E3-LoRA拟从r8、固定层名单起步，必须先有前向等价、保存/恢复、未选层冻结证明；这是候选设计，不是本地已核验可直接运行的 N1.7 LoRA 功能。

每臂都用原完整状态保存、模型/processor/stats/optimizer/scheduler/RNG/sampler审计、冻结参数hash和实际曝光。实际CPU/GPU/query/PBS/输出按原账本累积；普通工程修复不混成科学recipe变化。

## 8. 阶段 E：闭环优先，三种证据分开

1. **小规模开发诊断**：复用成熟 N294101 原24条件/模型，E1/E2成对共48条件。原raw/因果时钟/实际ACK/STOP/600s80cycles/S1/物体评分与所有有效失败保留。不为了更小样本临时改原人口。这个面板以前看过，不是新的盲确认集。
2. **完整DEV**：仅在首批结果支持时，补齐第二噪声面板到原48/模型，按事先冻结的规则比较与选模；同一模型跨任务回退必须报告。
3. **独立确认**：另冻未用于选模的谱系几何/噪声或任务家族，候选固定后只跑预定次数。不能把第二次看同一DEV或换个噪声直接称独立泛化。

主行为指标：T1/T2分别成功率、E1−E2配对差、原参考拒绝/S1拒绝/完整任务失败阶段、原生安全、延迟及成本。按几何组做区间/配对重采样，T1/T2同几何及噪声重复不独立。24/模型首面板用于筛查，区间宽就记不确定；不据小样本宣称全面优越。

预注册实用差异参考值可取10个百分点，但只是本计划建议，须在执行前锁定；正式非劣/优势样本量依据成对差异方差和确认目标核算，不靠12几何的一次运行作强统计结论。

现有 C50、D25、GEN1 三份模型的原24行为评估依旧有价值，旧 escrow 不挪作新对照。它们的行为缺口应先或与本研究有限离线准备交错解决；不默认把所有历史模型和新模型一口气跑完大矩阵。

## 10. 新任务作为迁移检验环境，而非自动大规模Teacher工厂

先单一桌面柜门，后单本书，再多步整理；均为条件阶段，不是本文件新采集许可。

- 柜门：固定基座可达、无遮挡把手、真实hinge joint与碰撞/摩擦；无隐藏脚本直接转门。预定义门角（例如45°）与保持2s、松手/分离和安全，数值在新任务冻结前可修改，冻结后不得看结果调阈值。任务特定允许接触对和旧S1接口须明确版本化，不直接删除旧拒绝规则。
- 首测仅E1/E2两个固定候选，各六个未参与其适配训练的合法初态，描述为“本项目适配阶段未训练该任务”的小规模迁移诊断，不当成正式泛化证明。
- 若能接近/抓把手但沿铰链失败，先确认执行/评分接口，再设计≤6条针对性、独立TRAIN父轨迹；另留全新评估初态，不能用失败DEV真值生成其训练标签。
- 单本书先宽间隙放入单格；直立姿态、书籍碰撞/摩擦、释放与保持先有任务规格。多本书排序、遮挡、窄间隙插入和长程规划不随一个“整理书架”标签自动获得能力或Teacher。
- 原Teacher只具已验证T1/T2能力，不能把开门/书架写成已有生产功能。新任务先评估/诊断，证明确有学习缺口再有限补监督。
