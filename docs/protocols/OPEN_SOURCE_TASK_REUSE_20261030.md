# 开源任务复用：柜门、单书与共享策略数据阶梯

2026-10-30。采纳用户最新方法选择：优先移植已有任务、资产和可解释的示范，接入当前MuJoCo源执行器；源域数据不等待目标WBC任务成功。共享四技能、原始GR00T父模型、EEF10/H40/Prefix8、实际观测和已提交动作规则承接[四任务协议](SHARED_MULTITASK_SOURCE_POLICY_20261029.md)。目标域仍为自由机身、真实腿部接触和冻结WBC的Go2＋ARX5。

本次已核对上游固定源码，完成三个真实LIBERO任务文件的静态解析。尚无新机器人执行、合格示范或技能效果。完整来源、文件hash、解析语义与待办见[机读证据](../../reports/PI0294/design/parallel-science-20261022/OPEN_SOURCE_TASK_REUSE_PINNED_CANDIDATES_AND_DATA_LADDER_ACTUAL_20261030.json)。

首批单书任务是放入收纳架的指定格。窄间隙竖直插入和多书连续整理另有接触、顺序和状态要求，不能用此任务成绩替代。现有自制门/书场景和Teacher保留为诊断基线及补充种子来源；其矩形插槽/角度规则不自动覆盖上述原任务。迁移后分别报告原始成功谓词和项目附加完成指标，不能把更改后的判据仍标为原基准成绩。最终容差、保持时间及实现应在首次任务运行前固定。

复用方式首先是把选定场景/任务接入现有MuJoCo源ARX5环境。robot XML、驱动、相机和时钟必须明确绑定；随后同一任务可独立进入目标冻结WBC评价。上游[Go2Arx5组合定义](https://github.com/ARISE-Initiative/robosuite_models/blob/2d63a6b4319bda772420daf10594ce0de5bd793d/robosuite_models/robots/compositional.py)可参考装配，但不证明我们的执行器已接入。`Go2Arx5Floating`移除了腿部驱动/自由关节并加入替代移动关节，不满足目标域定义。

## 从公开示范到有效EEF监督

1. 固定原示范子集、机器人、环境、控制器配置、动作归一化、TCP、帧约定、夹爪单位、采样与保持时间。原`qpos/qvel`只用于对应原模型的恢复，不能直接恢复到ARX5或Go2。
2. 用原控制器语义恢复当时提交的EEF目标，并做正反转换的数值验证；包含旋转组合顺序、尺度、clip、插值/累计模式及夹爪。不能用下一帧达到的TCP替代专家命令，也不能把7维补零改成10维。
3. 根据物体和工具关系重定向，在所选源执行器重新执行。重新记录该执行的双RGB、实际状态、提交/接受命令、物体状态和接触；不把原机器人的RGB拼到新动作上。MimicGen式生成需要实际子任务反馈，几何变换本身不是成功证据。
4. 复用项目规范的EEF10行旋转编码和原relative Processor。H40后缀只保留为未执行参考；监督只来自实际完成、时钟/数据完整的已提交前缀。通过独立任务评分、安全、标签和split审计后，才能准入成功示范。
5. 生成器、特权状态和Teacher阶段留在数据旁路。共享学生输入保持双RGB、测得EEF/夹爪和语言。目标WBC轨迹若用于训练，明确计为目标执行域适配，不混入无目标示范DEC1。

先以每技能5–10条完整种子验证任务、转换、重执行和训练链，再进入300条pilot。两列是嵌套累计规模；合约相容的已有示范可计入。300条与1,300条都是候选投入，不能承诺成功率。恢复数据来自学生实际访问的失败状态，候选每技能50–100段、合计200–400段，另计短片段数量和时长，不冒充完整episode。

同时记录完整episode数、独立场景配置数、物体/家具实例数、关键事件/恢复数和源示范谱系。门变化把手/门几何、开向、初始角度与工作位；书变化厚度、姿态、抓握偏移及目标位置。先按布局、实例和生成谱系划分，再切H40窗口。训练成功筛选必须保留全部生成失败及覆盖缺口；测试一次失败不得换seed重做。

另设每技能20–30个独立DEV配置与50个完整TEST episode，均不计入TRAIN。左/右格使用相同初态分布和配对seed；后继选书变体也要在相同/相近场景改变正确行为，防止背景泄漏任务答案。未能排除公开任务进入预训练时，只声称本项目留出条件上的泛化。

开门/单书采用嵌套`N=50,100,250,500`，固定DEV、动作语义和明确优化预算，记录实际更新/样本曝光。TRAIN与DEV都差先查标签、观测、转换与优化；DEV随新增覆盖改善才扩量；偏离后失败则补实际恢复；源好而目标差则定位域差异。原始候选10000更新不自动为每个规模重复分配。最终成绩在所声称的执行域实测，源域结果不能替代Go2＋WBC结果。

## 当前证据和下一执行边界

`scripts/pi0294/multitask/open_source_tasks.py`仅解析有限大小、固定hash的BDDL，保留原语言、objects/fixtures、regions/init和单书`In`谓词，不导入或启动第三方模拟器。10项CPU检查通过，含三个真实上游文件和左右格配对；首次发现的多名称同类型声明解析错误已修复并保留记录。它不是资产导入器、动作转换器或示范准入器。
