## 0. 目标、优先级与这次实际改动

长期目标：用共享的视觉／语言条件 EEF 策略承接抓持、放置、柜门、书架任务；WBC 负责本体相关执行。先在 Go2＋ARX5 得到可重复、可独立评价的策略，再证明新增技能不重训 WBC，并单独检验同一高层权重能否跨执行器／本体迁移。

本次是在 PR #383 上追加长程路线，保留 V4/V4.1 及机读文件的历史内容，不创建新实验主分支、不合并执行栈、不改服务器作业。V5 调整的是**未启动工作的顺序、源数据现实数量以及机制验证**；已启动作业、固定评价人口、负结果、冻结权重和原生安全不变。

核心路线：

```text
完成当前候选与原生执行 → 合格目标数据分波生产
      → 同起点 FM / FM＋空间对齐 → 条件化诊断 → 专家纠正
      → 精选源数据对照 → 一个共享多技能策略
      → 新站位 → 导航后操作 → 连续移动／跨执行器
可选支线：历史观测 → 动作条件后果模型 → 有证据的蒸馏／接触传感／RL
```

后三类可选方法都不是前半段交付的前置条件。不要重做万小时预训练、先全量解冻 VLM、把空间特征当物理力场，或因为没有 RL 就将失败归因于模仿学习上限。

## 2. 证据原则：将论文启发变成实验，而非预设答案

SLA 支持“动作学习＋训练期冻结几何教师”，但不证明每个项目必须再做 CPT，也不证明全部 VLA 失败都是几何遗忘。公开配置采用固定第12层、`vla_adapt_layers_align=False`；本项目先复用此配方，不声称已复现自适应多层门控。[R1][R2]

State-token dropout 的动机是减少状态捷径；实际 TCP 仍是动作编码／解码锚点，不能因 dropout 被置零。空间对齐是否提升我们任务，需要同起点匹配对照。恢复数据来自学生实际状态的专家监督；它不自动成为 RL。[R3]

本体动力学预测应显式依赖动作和执行历史，不能把静态视觉特征对齐当作反事实物理模型。RECAP 是示范、纠正、价值与自主经验的组合先例，不是“丢掉示范便得到工业可靠性”的证据。[R4]

EEF 分层已有 UMI on Legs 等先例；我们的贡献需来自数据效率、跨任务复用、恢复与跨执行器结果，而不是仅换上层模型名称。[R5]

源仿真生成：记录源desired命令、实际状态、tick/相机、活动臂/另一臂接触、工具和成功，建立S_GEN_CMD100（每任务20 TRAIN）及另留25源DEV；有收益再扩S_GEN_CMD1000（每任务200 TRAIN、源DEV累计100）。数据版本嵌套但不把公共下载和再生成悄悄混池。源真值只用于专家/验证，不伪造目标WBC消费。

S_aux可另做future-achieved预适配或纯空间辅助，但这是不同目标的独立实验；既不宣称它毫无价值，也不偷偷塞入首轮同语义动作混合。

### P3.2 先小池验证，后扩量

源reader在100条合格命令可用时就测试。正式首对可以固定D300＋实际S_cmd池（N=100、200或1000），名称带真实Ns；无需等Ns=1000。不同Ns不能共享为同一个端点，扩大Ns时保持T固定并分别训练比较。

主对照：T_ONLY_3K每步32T；M75_3K每步24T＋8S；均3K/B32、共同初始权重与目标TRAIN normalizer。M75为72K目标＋24K源，T_ONLY为96K目标。若存在完全同身份目标端点，复用不重训。

依V4按问题增加M50、SEQ或两臂追加1K。SEQ750源步＋2250目标步，保持optimizer与全程schedule，匹配M75的源/目标visit bank。T_ONLY_3K vs M75_4K匹配96K目标曝光但不等计算；T_ONLY_4K vs M75_4K补充等总更新比较。不得用不同decoder、目标DEV统计或隐式clip创造收益。

S_ONLY仍是固定3K、source-only统计的独立迁移探索，不在目标DEV上挑checkpoint；若基模预训练重叠未知，只能称“无新增目标任务微调”。

## 8. 第五阶段 P4：闭环纠正和共享四技能

### P4.1 先有可执行行为，再采学生状态

首波至多400 TRAIN rollout、200有效纠正片段。接管标签来自当前真实状态并被实际消费；学生错误前缀不作BC。没有可信纠正的失败留作诊断/后果建模，不自动整段丢弃也不自动作专家。

同父checkpoint两臂各1K/B32、相同新optimizer及固定统计：NOMINAL100 vs NOMINAL80＋CORRECTION20。源混合已采用时另登记三桶比例，不能将“20%source”误作“20%correction”。纠正收益必须比同预算普通续训更好，而不只是比续训前好。

下一波采什么由失败类型决定：目标/语言错→条件化；接近位姿错→标签/感知；夹爪事件错→事件覆盖；正常可做但偏离失败→恢复；参考正确而执行偏离→执行合同/可行性。不把所有失败都变成更多同分布训练。

### P4.2 新技能不等待抓放100%

固定目标四技能：PICK_HOLD、PICK_PLACE、OPEN_CABINET_NO_LATCH、BOOK_FROM_TABLE_TO_SLOT。后两项每技能10–30完整种子即做500步首版；接着100–300条按失败覆盖扩展。已有持书插入可先作为明确子技能，但不能当作完整桌面取书任务。

柜门需保留弧线路径和接触/松手过程；书需转姿、避障、插入、释放、撤离及卡住退回。必须使用有实际路径消费证据的consumer；只保留末点的basis不能验证曲线任务。旧P10分段expert成功还不证明学生消费完整曲线，需要学生raw/installed对照。

共享训练起步用实际合格数据，例如300抓放＋150柜门＋150取书=600条（不是必须等待600才开始）。一个权重、一套EEF语义、一套joint TRAIN统计、语言选择任务，按四任务均衡采样。起步5K/B32、250warmup、共同LoRA配方，冻结视觉/WBC；保留动作/空间loss选择，不为每任务切head。

使用已选两任务checkpoint作共享续训起点并明确其来源；这是多任务扩展，不与fresh-base数据曲线混比。若旧任务退化，再做同5K的新任务only与均衡replay对照；不自动并列所有候选。至少16 TRAIN、96 DEV（每技能24），最终固定策略再开新四技能TEST160（每技能24常规＋16挑战），三seed合计480。

语言不同但正确首动作相同的任务按全程事件评分。加入新技能后的旧TEST只能叫回归/保持检查，不能反复选模后仍称盲测；最终四技能TEST采用新冻结条件。

## 9. 第六阶段 P5：移动与跨执行器，维持解耦主张

### P5.1 复用V4移动分层

M0：16离线frame/时间测试＋24原生专家能力条件，复用已有相同身份结果。验证实际控制器接收世界/任务还是当前机身frame，BASE字段和模式到底是什么。需要迈步却不能执行时，报告控制能力缺口，不归因上层数据不足、不擅自重训WBC。

M1：B100=5站位层×2任务×10对象/布局组合，先评价冻结策略，再做匹配适配；这是新站位静止操作，不是导航。

M2：先使用验证过的导航后端实现NAVIGATE→SETTLE→MANIPULATE→VERIFY，NAV100=10路线族×2任务×5布局/重启。空载先行，持物运输随后。导航规划器若用仿真oracle则标为oracle导航基线，不能称端到端RGB语言自主导航。

M3：只有真实行走、持物稳定及曲线消费已成立，才做连续推拉/边移动边操作，50种子→300条件性扩展。优先EEF-only与EEF＋独立SE(2)站位子目标，不直接输出腿关节；缺base标签的固定臂来源mask，不补零。

任务参考固定在F：T_W_E_des=T_W_F T_F_E_des。执行端需机身frame时，用**当前实测**T_W_B(t)求逆，持续重表达；不读取T_W_B(t+k)未来真值，不二次变换原生世界参考。相机随base移动、里程计误差与重定位跳变单独测试。

### P5.2 真正的跨执行器／本体实验

先独立测同一WBC的合法参考能力：保持、纯旋转、曲线、在线重规划、接触、机身协同；模型输出不正确不能计作WBC能力不足。正确专家参考也失败时，保留该条件，检查独立可行性，不把失败从分母删除。

同一机器人换控制器只能叫执行器迁移。跨本体必须选择第二个具有不同运动学的实际仿真本体/执行器，固定高层权重、任务数据、input/codec与normalizer；允许本体标定/低层，但不借目标任务微调高层后仍称零目标适配。

首轮2个任务×20共同可行条件×2执行器=80次冻结policy测试；另用相同专家参考作20条件/执行器的跟踪基线，共40。固定接口、相机可用性及视觉域区别；两执行器闭环观测不同，输出不必逐bit一致。第二本体未就绪则明确未验证，不影响先交付Go2策略。

UMI等现有分层方法是相关先例，不以“换成SLA”单独声称新贡献。[R5]

### P5.3 实时性与仿真到现实另行验收

原生仿真暂停等待神经推理，只能证明暂停仿真闭环，不能宣称真实2Hz实时控制。部署前独立测采集→推理→安装的端到端P50/P95与最坏超时；0.5s节拍必须有可实现的延迟预算、有效旧参考与状态新鲜度策略。推理慢时不能把暂停时间从成本中抹掉，也不通过延长安全TTL掩盖。可研究明确的延迟训练/异步重规划，但与当前同步consumer单列。

真实机器人不在此次执行范围。后续只能在仿真任务可靠、标定和时钟闭合、观测/接触/延迟域差距可测且获得独立实机许可后，设计小规模真机验证。先做TCP/相机/命令/夹爪核对和有保护的单技能；必要时采少量真实纠正，清楚区分零样本迁移与真机适配。不开“直接上线95%”承诺，不将仿真通过视为硬件安全证明。

## 10. 条件性研究 R：后果模型、传感和RL

### R0：先保留可用经验，不新建大型世界模型前置

持续记录(o_t, raw/installed_H40, 实际消费prefix, dt, o_next, done/timeout,接触/奖励原始事件,控制版本)。未执行后缀不是状态转移标签；WBC预览可能读取后缀，因此后果模型输入应包含实际安装的完整预览与控制模式，不能假设后缀无作用。

成功与失败转移都可用于后果学习，专家标签只取正确来源。训练/验证按episode分，不能将同次试验的近邻状态跨split。先复用已有授权的WM模块和日志，不凭方法名字重建一套系统。

### R1：动作条件后果预测，只有明确接触/迟滞瓶颈才进入

起步最多取200条已有TRAIN交互episode（成功/失败都保留，数量不足报告实际N），按episode固定160/40内部TRAIN/DEV；不得使用原正式DEV/TEST训练。预测0.1/0.5/1.0秒实际未来的抓持、滑移、插入进展或可观测任务latent。

用冻结教师或结构化仿真结果作训练目标，学生部署不读真值。模型形式：
`z_next_hat = f(history_RGB_state, installed_action_preview, consumed_prefix, dt, executor_context)`。
executor_context只允许本体后果模型用，不自动塞进共享高层。与持值预测、无动作模型比较，报告Brier/校准、分类和位姿误差，不能只报告latent MSE。

真正反事实需要同完整状态、控制历史和随机种子下两动作的实际执行。最多32个安全TRAIN源状态×2候选=64条分支试验；无法可靠恢复WBC hidden state时用完整前缀重放并验证状态匹配，否则不能称因果配对。排名正确率目标≥75%只是继续投入标准，区间和绝对成功仍报告。

### R2：有用之后才考虑Dynamics Forcing

只有R1能区分动作后果，再给同一可执行策略做两臂各2K/B32：普通监督续训 vs 监督＋动作条件未来预测辅助。共享父checkpoint/新optimizer/访问/统计；lambda在TRAIN固定并报告梯度贡献，不用DEV试遍权重。

未来真值只作loss目标，不能作为当前动作生成输入；训练期的未来预测头若移除，不改变动作ABI。若是在线ranker则单独记部署开销，不能与“训练期蒸馏零教师开销”混称。持续检查旧任务和跨执行器，避免将某个WBC的固定偏差蒸馏成通用任务规律。

### R3：传感与RL不是必然终点

若当前RGB/状态/允许历史仍无法辨识接触，先在仿真做RGB-history vs额外传感的可观测性上界；真值力的oracle收益不等于已有力传感器可部署。真实传感需验证方向、单位、频率、延迟和缺失处理，硬件采集不由本计划启动。

RL只有在已有可执行策略、可靠reward/reset、明确接触优化问题以及有界行为探索下另立运行协议。先离线评估价值校准/奖励欺骗，再选择适配flow策略的保守方法；不能默认PPO可直接使用未经定义的动作概率。保留BC prior和安全控制，按真实episode/transition/控制时间匹配数据成本，技术故障不作任务负reward。RECAP仅为方法依据，本项目未实现其完整算法。[R4]

该阶段不预填“95%工业可靠性”、不自动开真机RL或低层重训；若监督＋纠正已经满足目标，允许不做RL。

## 11. 工作量、评价与长程排程

### 11.1 不把不同研究预算相加成必须执行的大队列

| 模块 | 设计工作量 | 与已有计划关系 |
|---|---:|---|
| 当前dense FM pilot | 3K/B32，快照已513 | 现役job继续，实际剩余量现场读；不是新增3K |
| 匹配dense spatial pilot | 3K/B32，96K访问 | 可选有限拟合/实现对照，不能替代D100泛化 |
| D100 FM/SF | 2×3K/B32，192K访问 | 复用现役监督优先计划，不重复累计 |
| D300四配方 | 4×3K/B32，384K访问 | 继承V2，先LoRA两臂 |
| 源混合 | 核心两臂6K/B32；完整V4分支最多33K/1,056K访问 | 共享目标基线按identity去重；新Ns端点单列 |
| 纠正对照 | 2×1K/B32，64K访问 | 继承V3；只统计实际运行波 |
| 可选dropout／adaptive | 各额外1×3K/B32 | 共最多6K/192K；不同时展开所有配方 |
| 可选history | 2×2K/B32 | 4K/128K，部署成本另计 |
| 共享四技能首run | 5K/B32 | 160K；两个确认seed再10K/320K |
| 可选dynamics辅助 | 2×2K/B32 | 4K/128K；后果模型训练单独计量 |
| 移动M1/M2 | 各最多4K/B32与V4评价 | 原V4身份复用，不能重复报新增 |
| RL／真机 | 当前0运行预算 | 需独立具体协议，不自动启动 |

新增dropout/adaptive/history/首个shared/dynamics所有条件分支合计19K/B32=608K访问，不含确认seed、空间pilot、继承V2–V4或后果模型训练。它是增量算术，不是本项目总预算或自动任务队列。

数据与优化量分开研究。只有选中recipe在正确标签下仍持续改善时使用既定3K→6K→12K→20K曲线；同一固定LR尾段，确认seed训练到相同选定U。扩大数据不同时修改loss和接口。新source Ns或history/传感变化单独命名。

测试避免预算乘法爆炸：先seed0/DEV选一对关键方法，再各加两seed、TEST80；四技能最终再用新TEST160。C24、对照恢复、移动和反事实各有独立分母。评估过的TEST只作回归，不重复驱动选择。

### 11.2 以里程碑而非固定日期承诺推进

| 工作窗口（资源就绪后的建议安排） | 主线 | 可并行的工作 |
|---|---|---|
| 第一轮实际执行 | 收尾dense FM和R1原生桥，空间梯度/匹配臂 | 目标专家/分层生产，源剩余语义问题 |
| 约第1–2周 | D100→D300、FM/SF、C24、稳定1/2/4actor | 源仿真命令小池，门/书专家种子 |
| 约第3–4周 | 源混合关键一对、纠正、独立两任务评价 | 新站位能力/坐标、两个复杂技能首学生 |
| 约第5–8周 | 共享四技能、导航接管、负载运输 | 条件性history／后果模型 |
| 约第9–12周 | 三seed独立结论、跨执行器／第二本体 | 只有证据支持才蒸馏/传感/RL |

这些是排程建议，不是预计完成承诺。源不合格继续T-only；完整两任务未齐先交付具名小任务；移动后端不足先交付站立共享技能。反之，已经ready的分支可提前，不人为等待周次或某基线100%。

### 11.3 下一次执行必须产出的结果

不是再输出一份计划。优先报告：当前job真实终态/完整checkpoint；至少一份候选原生固定诊断的完整终态或确切首失败；空间梯度/匹配训练实际进展；新增合格完整示范与缺失层；源数据明确可用或限定用途；真实采集/GPU/传输成本。

连续两次相同症状且没有新增机制证据时，停止该故障的重复启动，换诊断或推进独立分支。不要重复资格、取消健康任务、用其他场景重跑正式失败条件，或以更多提交替代策略结果。

## 12. 发布与可复核性

保留每个run的最小科学身份：source/parent/data/normalizer/codec/consumer/seed/schedule、实际更新/访问、GPU小时、完整评价分母与首次失败。复用现有记录机制，不新增多层审核系统。

本次仅新增本V5、JSON及启动prompt，并更新现有根入口。V4/V4.1原文件、现役代码和AGENTS不改；prompt明确读取后续授权避免旧入口限制。正常追加到PR #383，不force、不merge、不启动仿真或训练。发布后核对远端blob和范围；JSON算术/引用检查与原生/CUDA结果分开报告。
