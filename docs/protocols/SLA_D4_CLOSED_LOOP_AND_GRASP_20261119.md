### 5.1 原评分与新增诊断

完整成功继续使用原 Score：

- HOLD：正确目标实际抓持且抬升至少20mm，连续保持至少1秒；
- PLACE：历史上曾正确抓持并抬升至少20mm（ever_lift），最终物体完整进入区域、有实际桌面接触支撑、释放、夹爪打开、至少50mm撤离及原低速稳定条件持续至少1秒。PLACE不额外要求曾带物悬空保持1秒；
- 两类任务均在最终成功判定时满足原方向底座位移至少80mm，不拼接历史不同时刻的两个最大值；
- 错物体、接触STOP、安全状态与2ms状态连续性按原规则。

每个条件输出同一条证据链：

当前RGB/state/前命令 → 未加工H40 → 编译H40和首次拒绝 → 安装ACK → 实际P10/部分原子 → 实测夹爪/TCP → 接触与原评分。

记录名义/提交/accepted/selected/实际五层。现有 controller_selected_reference=UNKNOWN 保留，只有已有consumer证据能建立身份时才补值，不能从ACK推成最终选择。诊断和落盘优先使用现有journal，避免改变控制链时序。

STOP中途异常可能绕过现有score_through。终态应使用同一个原Score顺序回读完整2ms journal至最后真实tick，包含不足25tick的部分原子；同时保留原缓存进度与终态回读差异。未完成原子不是完整消费标签。

### 5.2 如何根据失败分布选修复

| 闭环证据 | 首要下一动作 |
|---|---|
| 原始H40漏闭合、闭合一直落在尾30点，下一查询又推后 | W/T物理轨迹监督；记录连续预测闭合绝对时刻 |
| 指令要求闭合，实际消费/选择证据缺失或实测宽度未响应 | 修执行身份、时钟、驱动映射接缝；冻结WBC参数 |
| 实测夹爪闭合但没夹中、碰桌或碰非目标 | 增加新TRAIN几何覆盖与纠偏示范；诊断手腕、指垫、持物全路径 |
| 抓到后提升/移动中丢失 | 检查原接触、相对位姿及移动/保持同时性，补对应段数据 |
| HOLD成功而PLACE失败 | 增加完整抓取—搬运—支撑—释放—撤离目标数据；不先上长程planner |

语言变化对应的目标/区域响应与运动执行分开报告；错目标不能只归因于夹爪速度。D4的PLACE是零目标PLACE示范测试，失败不等于已训练的放置能力退化。

$$L_w=\frac1{40}\sum_{k=0}^{39}\left(\frac{w_k-w_k^*}{0.040}\right)^2$$

$$L_\Delta=\frac1{40}\sum_{k=0}^{39}\left(\frac{(w_k-w_{k-1})-(w_k^*-w_{k-1}^*)}{0.002}\right)^2$$
