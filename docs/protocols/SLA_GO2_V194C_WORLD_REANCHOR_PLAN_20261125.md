## 2. 唯一主动改变：REFERENCE_WORLD_REANCHOR_V1

继续使用 V1.9.4b 的 FLANGE_EQUIVALENT_NOMINAL、真实三相机V1、九帧因果头部历史、官方processor/inverse和固定A1左臂。SLA输出的右臂50行经名义codec得到世界系物理意图 T_I(s)。在每次实际暂停的合法查询/编译接缝，绑定同一 native tick 的实测TCP T_A 和最后**实际消费**的EEF参考 T_C。不是最新收到的ACK、未来knot或GT物体位置。沿用 [world_offset](https://github.com/Leo-6-maker/go2-arx5-hierarchical-vla/blob/719882e9fd154ffbe995484e7a766ada3b3ecd02/scripts/sla_go2_v18/world_intent_clock.py) 原精确公式：

```
p_ref(s) = p_C + (p_I(s) - p_A)
R_ref(s) = R_I(s) @ R_A.T @ R_C
```

平移为世界轴增量，旋转为该已验证实现的右乘修正；不要自行换成一般 SE(3) 左乘。T_I=T_A 时得到 T_C；同段任意两点的世界位移和相对旋转（R_j R_i^T）保留。每提案只应用一次，下一提案从自身新的同tick实测/消费对重新计算，不累加上次offset，不改模型输入或原始输出。保留50行及连续插值、首点接续的制动/对齐、现役编译器和保护约束；绝不把新变换偷换为旧15-interval固定开爪SEAStandingStudent。夹爪独立保持原双向名义映射、MODEL_FIRST_KNOT、真实ACK与接缝限速；不对夹爪做位置偏移、强制闭爪或保握。

本变换属于非学习式、任务无关执行适配（R1），不再称与 V1.9.4 原绝对参考完全相同；物理意图始终保留原值。禁止按桌高、水果位置、成功率或当前任务添加Z偏置、目标投影、逐tick追偏或调WBC。实际动态偏差可能改变符号、大小和旋转，不能认为净空必然改善；接触状态下同一规则仅在既有合法边界重新绑定，不修改原接触门、也不声称SEA2已资格接触。实际碰撞、拒绝、意图不合理等保留为结果。

## 3. E0 · 归档误差分解（P0，0前向/0积分）
