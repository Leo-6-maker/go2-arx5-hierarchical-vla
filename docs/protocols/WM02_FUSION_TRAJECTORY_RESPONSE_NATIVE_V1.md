# Single-cell trajectory response collection

This future entry collects one predeclared native restart through the original
AUTO1/P1 owner. It creates no scheduler, registry, lease or permission. Native
fixtures, source geometry, and a published panel are not dynamic qualification.
The collection role is `NON_VLA_CALIBRATION`; it uses archived query geometry,
not online RGB inference, and makes no WM benefit or task-transfer claim.

The pure `WM02_TRAJECTORY_RESPONSE_PANEL_V1` and
`WM02_TRAJECTORY_RESPONSE_EPISODE_V1` contracts are implemented in
`fusion_trajectory_response_contract.py`. The panel fixes four TRAIN and two
DEV physical parents, contexts C0/C1, theta−1/0/+1 and restart indices0/1:
72 cells, with48 TRAIN and24 DEV. The first pilot is one predeclared TRAIN
parent's12 cells. Reuse those12 by exact parent/context/theta/restart identity
when assembling the complete cohort; they do not require repeated execution.

C0 holds original INIT2503 TCP. C1 uses a quintic X+0.5mm ramp over atoms0–8,
holds, then returns over atoms40–48 (3503→3703). Both planned reference
endpoints at3703 equal original INIT. Actual decision TCP is measured
separately. The original stable-prefix screen remains unchanged; a failed
screen is retained rather than relaxed. Actual context separation and
state×theta response require pilot measurements, not context labels.

The reference-only correction is target-world X, amplitude theta×0.5mm.
It starts at probe0 at3703, rises over8 atoms, holds until16, and returns to
zero by24. Theta does not enter any predecision reference. Desired outcome
remains the nominal desired trajectory. All theta levels use the same raw40
knots and the same integer clock, including theta0; no theta-specific timing,
clipping or future achieved-state relabeling occurs.

The nominal compiler is explicitly the new two-times time law:
`FULL_H40_RIGID_RELOCATE_SCALE_WORKING_GRIP_INTEGER_RETIME_2X_V2` with
`time_stretch_factor:2`. The new collector refuses a smaller-scale result,
old fast-V1 result, incomplete result, open lease or failed stage as its
predecessor. It requires actual full geometry1.0 slow-V2 native PASS,
CLOSED0/worker0, all four clean process exits, complete original trace/safety
and every consumed pose/gripper atom. Such a predecessor is not created by
the check command. Other panel scenes still require their exact original
catalogue/model/split hashes and every new complete native preview certificate.

The response spec retains the original `wm02-auto1-target` profile and
`WM02_AUTO1_TARGET_COMMISSION_V1` domain, actual P1 binding and original
registry/Journal/owner/physical locks. Additional fields are:

- `trajectory_response_panel` and `trajectory_response_panel_sha256` pin the
  panel file; the panel also carries its canonical hash in each episode.
- `trajectory_response_collection` is `PILOT12` or `PANEL72`. `PILOT12` also
  names `trajectory_response_pilot_parent` and accepts only that TRAIN parent.
- `trajectory_query_root` identifies the same byte-pinned, closed target
  shadow query. Its full sidecar is verified with the unchanged reader.
- `trajectory_trace_capacity_build` and its SHA pin the262144-capacity
  trace-only build, unchanged native/observer hashes and honest source hashes.

All members in the native contract's `SOURCE_MEMBERS` must be present in the
new source seal. The exact endpoint is
`3703+25*(planned_end_atom+8)`, at most33000 ticks. It must match the actual
compiled program. Only the new slow/response phases admit at most1200 wall
seconds and use the original already-supported quota bucket64. The original

with `--spec PATH --check-only`. It reads the real recipe and predecessor,
reports a finite endpoint, and grants no native execution. `--execute` alone
delegates to the existing P1 worker and independent current admission.

Collection reuses the d699 helper implementations for actual trace mapping,

Private decision records bind raw NPZ identity/dtype, nominal, corrected and
desired paths, pre-install theta assignment and actual9×106/8×17 history.
Every atom retains both full40 previews, the actually installed preview,
