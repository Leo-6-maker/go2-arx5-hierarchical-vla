## 0. 任务目标、执行范围与完成标准

本 Goal 承接用户“深入分析目前进度，制定自主长程任务，跑通多数据集后训练”的请求。执行者自主完成项目用户空间中的实现、定向验证、资源内排队、冷态接续、数据准入、独立评价和结果发布；不为每个普通工程修复再请求 GO。复用现有 PBS / 用户级 systemd、owner、Journal/onceIO 和发布器，不再建立第二套调度平台。对话或 SSH 退出后由站点队列推进，训练不依赖 Codex 实时观察，也不依赖 GitHub 发布成功。

三个验收层次分别记录，禁止互相代替：

1. **PIPELINE_COMPLETE**：MIX20K、TGT5K、ADAPT5K 的名义科学端点与完整可恢复状态完成；三域固定评价、SCALE原96条及ADAPT原96条学生原生条件取得真实终态；CLOCK科学触发已判定，未触发或已触发范围实际完成。触发后仍blocked不算流程完成。低成功也能构成流程完成，但不能称本体适配成功。
2. **HOLD_REPRODUCED_ADAPT / HOLD_REPRODUCED_CLOCK**：分别在原ADAPT5k确认24与固定CLOCK-B确认24中独立计算，不能事后挑过门的一组代替另一组，也不能合并分母。各自8条HOLD至少4条完整成功，F1/F2各至少2条，成功覆盖至少2个不同布局。每次成功仍要求原正确目标抓持、底座定向移动至少80mm、抬升至少20mm、保持至少1s及全部原安全条件。该阈值是本Goal的新pilot里程碑，不更改旧单回合评分，不代表统计显著性或广泛泛化；CLOCK未触发则相应指标为NOT_APPLICABLE。
3. **PLACE_REPRODUCED_ADAPT / PLACE_REPRODUCED_CLOCK**：同样逐谱系独立计算，各确认人口的16条PLACE中至少2条完整成功，左右目标区各至少1条；抓持、搬运、释放、撤离均按原评分，不把HOLD替代PLACE。原SCALE各端点另按其原合同报告。

若有限科学计划走完仍未达能力标准，终态为 `COMPLETED_WITH_SCIENTIFIC_FAILURE`。未解决的技术缺陷记 `COMPLETED_WITH_TECHNICAL_BLOCKER`；真实外部凭证/资源长期不可用则为 `BLOCKED_EXTERNAL`，两者不假称流程完成。保留所有失败、未派发原因和下一版本假设。研究任务最长到实际部署 T0+14天；每个站点作业仍必须有自己的真实 allocation、walltime 和退出期限，14天不构成站点配额。到期封存状态，不自动延长。没有额外资源时先完成已有健康主线，附属工程可标 `NOT_RUN_RESOURCE_LIMIT`。

本版仍为离线后训练与隔离 MuJoCo 仿真。真机通信、WBC/腿策略/增益/动力学修改、输出裁剪平滑或改 decoder 掩盖预测、H40/P10/接缝/STOP/评分放宽、旧 TEST 使用均不在范围。现有暂停时钟仿真结果不构成连续实时或真机资格。
