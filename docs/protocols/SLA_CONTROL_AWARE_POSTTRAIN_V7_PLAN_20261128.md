## **1.3 如果 Frozen Expert 仍然失败**

不能再简单认为是“Expert必须全部解冻”或者“继续提高保持系数”。

建议按以下顺序研究：

| 候选                    | 目的                                         |
| --------------------- | ------------------------------------------ |
| IO分区反事实               | 区分action input、output和time conditioning的影响 |
| Output-head-only      | 检查更小范围接口适配是否足够                             |
| Expert LoRA           | 以低秩更新提供有限的新能力学习                            |
| Function Preservation | 直接限制安全动作函数漂移                               |
| Layer-wise LR         | 对不同Expert层施加不同更新强度                         |

其中功能保持应进一步分成两种不同的监督：

**真实消费行为保持**使用已通过直接消费证据审计的安全成功P10；目前正式准入锚点仍不足。

**父函数保持**则可单独使用固定真实TRAIN观测、相同noise下的R4原始输出作为函数目标，但必须明确它是教师模型蒸馏，而不是实际消费专家标签，也不得无差别保持R4失败的后半程行为。

例如：

\\[ L=L\_{\mathrm{FM}}+\lambda\_{\mathrm{aux}}L\_{\mathrm{aux}} +\lambda\_{\mathrm{keep}}L\_{\mathrm{keep}}. \\]

保持项主要覆盖已验证的安全接近、正确抓持、抬升与HOLD，并对真实物理位置、SO(3)及夹爪宽度分别归约。

不能把R4不会释放的行为一起固定下来。

## **3.1 输入定义**

增加六维连续参考跟踪残差：

\\[ c_t= \begin{bmatrix} p_t^{ref}-p_t^{actual}\\\ \log(R_t^{ref}(R_t^{actual})^{-1}) \end{bmatrix}. \\]

其中：

- 平移单位为m；
- 旋转单位为rad；
- 使用原episode-fixed mount坐标；
- reference为当拍因果可得的 Accepted Reference；
- 不使用未来H40、教师物体真值或事后选中参考推断。

原8031窗与新增214窗均已具备该数据；8245×6数组与C1索引、native tick及上一实际宽度已逐项对齐。模型投影、完整组合训练reader和CUDA资格仍未完成。

**恢复连续状态的物理分辨率，同时保持原状态文本的既有语义。**

建议保留：

\\[ s_t^{\mathrm{token}}= \operatorname{Tokenize}(s_t) \\]

并新增：

\\[ s_t^{\mathrm{cont}} = [p_x,p_y,p_z,r_x,r_y,r_z,w]. \\]

新支路使用固定TRAIN物理尺度、无裁剪连续映射，通过零初始化投影进入动作生成路径。

与A2不同，S2并不增加此前完全缺失的新控制变量，它主要恢复原变量的表达精度。
