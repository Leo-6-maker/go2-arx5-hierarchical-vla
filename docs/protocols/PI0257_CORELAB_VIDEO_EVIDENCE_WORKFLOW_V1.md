## 1. Evidence classes: names must match what actually happened

Every video and manifest has one mandatory class:

1. `ARCHIVED_PHYSICS_RECORDING`: original recorded camera frames from an actual earlier execution; no new physics. Include its original scope and verdict.
2. `OFFLINE_PREDICTION_ON_RECORDED_OBSERVATIONS`: predictions on archived observations, overlaid on the corresponding original recording or a static input. The underlying robot motion was NOT generated by the newly displayed prediction.
3. `KINEMATIC_STATE_REPLAY`: optional rendering of recorded root/joint poses with no dynamics integration. This is a reconstructed view, not a newly captured camera or a physical replay result.
4. `ONE_CHUNK_POLICY_EXECUTION`: one GR00T query followed by WBC feedback tracking. This is closed-loop at the low-level controller, but open-loop at the high-level VLA after the first query.
5. `RECEDING_POLICY_EXECUTION`: repeated fresh observation -> inference -> gate -> reference handoff -> WBC steps, with actual query count, reference continuity and timing recorded.

Modes 4/5 describe external experiment records and the future runner interface. THIS GO DOES NOT START NEW PHYSICS OR LEARNED-POLICY EPISODES. PI0256 explicitly forbids learned-policy physics; a showcase is not a loophole. A future per-episode execution authorization can use this workflow without rewriting the renderer.

A complete video means the complete recorded execution interval, including preparation, failure and termination; it does not mean successful task completion. A filename containing `receding` is not evidence of multiple policy queries. Check actual request/response and handoff counts.

## 7. Metrics and coordinate integrity

The user-provided review correctly separates SafetyGate from target distance, and reference quality from achieved motion. Preserve that separation in every plot.

Given verified matching world coordinates and same-time samples:

- reference target error: norm(p_ref_world(t)-p_target_world);
- actual target error: norm(p_tcp_world(t)-p_target_world);
- tracking error: norm(p_tcp_world(t)-p_ref_world(t));
- SO3 tracking: geodesic rotation distance with verified quaternion convention;
- max linear/angular reference speeds from real point timestamps;
- first-point jump, gate issues, termination and controller cleanliness.

A target minimum from one curve minus a target minimum from another is NOT tracking error. Never subtract native-relative predictions from world targets. Use the complete verified SE(3), link6-to-TCP offset and per-frame camera projection/view when projecting a curve. If camera matrices or transforms are absent, prefer a labelled 3D native plot and omit a misleading RGB overlay/world metric.

Historical scalar metrics remain HISTORICAL_AS_RECORDED. The PI0256 cache finding requires an impact/provenance caveat when reading shared legacy paths. A newly derived independent TCP metric requires raw link pose, offset and clocks; preserve it as a separate column, not a silent corrected history. Missing raw evidence means UNAVAILABLE, not zero. Post-autoreset poses must not be plotted as pre-reset failure poses.

Archive re-rendering must not rerank checkpoints, change group denominators or convert an old task/window criterion. Global stats and selected clip stats appear separately. A visualization cohort is not a representative success-rate study.
