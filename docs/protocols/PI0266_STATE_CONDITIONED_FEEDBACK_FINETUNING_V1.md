0. Decision and immutable starting evidence
Do not repeat PI0265's dependency all long-horizon controller tasks qualify → any feedback data → any fine-tuning. Replace it with source/observation integrity + safe initial state → valid state-conditioned local reference windows → matched fine-tuning, while scoring complete physical tasks separately. A safe failed task can contain valid local supervision; a colliding state, wrong label or unobservable privileged phase cannot.
This is not a waiver of safety or an assertion that full-task failure is success. It is a new admission rule for supervised data. Physical execution remains conditional on valid states and the pinned PI0265 safety mechanisms, including forbidden-pair checks and hard-penetration stops above 1e-3 rad for angular joints or 1e-5 m for prismatic joints. Soft-limit penalties remain per-joint diagnostics, and the gripper retains its documented active fixed-zero drives; neither is silently relabeled or disabled. WBC weights, gains, dynamics, action scaling/clipping and native observation features remain frozen. No WBC-training project, old-language score hunt or synthetic playback disguised as dynamics is authorized.

4. One new expert: observable state-conditioned local correction
The new expert is a data-generation mechanism, not the learned policy and not a WBC weight update. It must not advance its desired task phase solely because wall or simulator time advanced while the robot lagged behind.
Bind the task's initial pose and target-orientation markers once from the validated post-initialization measured reset state, before task motion. Keep robot state/history untouched; any target-marker initialization must be deterministic and completed before the first observation. Both diagnostic experts use this same binding. In model episodes this creates the scene/scoring specification, never an expert future buffer.
Retain each task's original analytic geometry and orientation semantics. Let C(s) be its nominal world SE3 curve without repeated terminal-hold samples, with source phase s in [0,6] for M1 or [0,16] for M3. The M3 curve still contains its approach and instructed 270-degree arc. Store the fixed actual-reset anchor used to define it.
Implement OBSERVABLE_CORRECTION_V1 as follows:
1. At each .4-second replan, read actual root/DOFs, independently reconstructed TCP, and fresh body/wrist RGB. Select a curve phase from the current physical pose, command and scene geometry, not elapsed episode time or an inaccessible teacher phase history.
2. Project to C by minimizing ||p-Cp(s)||^2 + (0.05*SO3(R,CR(s)))^2 on a fixed .01-source-second grid, with deterministic local refinement and a documented stable tie rule. Use the full approach-plus-arc curve. The algorithm must give identical labels for identical admissible inputs regardless of timestamp or recording ID.
3. Evaluate C(s+h) for the H40 offsets. At h=0, anchor position and attitude to the measured current pose; smoothly remove that current-to-curve residual over the first 1.0 second with the quintic blend w=10u^3-15u^4+6u^5. For position use Cp(s+h)+(1-w)*(p-Cp(s)). In world-matrix notation, use Rref(h)=Exp((1-w)*Log(Ractual*CR(s)^T))*CR(s+h); convert at the named boundaries and independently test the multiplication order and h=0 identity. This use of SO3 for geometric labels does not change the frozen native actor's quaternion-vector error feature. Hold the task endpoint beyond its nominal end.
4. Generate exactly one candidate. Check the original raw gate, finite SE3, current-frame alignment, original speed/rotation limits and source-bound geometric feasibility. There is no best-of-speed search, nearest expert-output retrieval or gate-driven trajectory repair. A rejected teacher candidate is not installed. Any fixed time parameterization is common and sealed before the first diagnostic outcome; the nominal C(s+h) rule above is the default, not an invitation to search schedules.

5. G1 — actual feedback collection and window-level admission
Execute all 24 TRAIN families × two behaviors × two commands = 96 expert episodes, using the fixed observable expert and admitted native runtime. Each is at most 40 task seconds plus <=1 second normal initialization. Capture fresh RGB/StateV1 and its proposed H40 every .4 second, plus native-tick actual state/actions/reference/termination. The simulator may pause for computation; report this as lockstep simulation.
Keep three distinct objects: current observation, desired future reference, and later achieved trajectory. A robot that did not reach its target does not thereby invalidate every preceding, correctly labeled safe window. Conversely, later achieved motion is not substituted as the intended expert label.
A training window is admitted only when:
- its current measured state and observation are valid, finite, collision-free and before a safety termination;
- fresh RGB and StateV1 share the actual acquisition time/root/physical TCP contract;
- its single state-conditioned future reference is semantically correct for that task/command, passes original raw gate/codec checks and has a valid complete H40;
- no forbidden geometry or known hard-limit violation is present in its independently checked local reference realization; using a fixed-root IK witness is only a conservative local kinematic witness, never a claim that WBC dynamics are guaranteed;
- the label is not chosen using an unavailable privileged phase or an evaluation result.
Do not require the entire 40-second episode or all four episodes of a family to succeed. Do not label these records “successful full-task demonstrations”; use WINDOW_VALID_REFERENCE and retain the parent's task outcome. An admitted desired-reference window may come from a safe task-criterion failure. No window starting at/after an unsafe state is admitted. Do not automatically label a preceding safe desired reference as unsafe solely because a controller later fails; retain and disclose that outcome, and exclude the window if its actual proposed reference itself fails the geometric/semantic tests.

M1
Achieved correct-target XYZ <=.035 m and SO3 <=.10 rad continuously for .25 seconds; no safety failure. Report time-to-success, requested/installed/achieved errors and all command groups.
M3
- Correct directed entry: actual position within .015 m of the requested entry, attitude within .10 rad, and absolute directed arc displacement from that entry <=.005 m, held for .10 seconds. This prevents a broad entry ball from admitting the robot only after it has skipped the first required arc segment.
- After entry, compute continuous signed unwrapped angular progress, anchored at the entry, not an independently modulo-reduced [0,2*pi) angle at each tick. Preserve raw positions and raw signed angles.

- A 1-mm arc-length deadband is the fixed prospective measurement tolerance for small backward jitter and entry-boundary angle signs. It is not a control modification. Record total negative variation and maximum backward excursion without deadband as well. Drawdown from greatest achieved progress exceeding .001 m flags meaningful reverse motion. Crossing the unrequested sector beyond this tolerance flags a gap. A direct endpoint shortcut must fail.
