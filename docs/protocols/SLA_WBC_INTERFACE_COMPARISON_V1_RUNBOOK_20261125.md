| 字段 | 要求 |

| model_id / parent_revision | 使用 B0、S1、M38、S7、PT；不可用目录名代替谱系 |
| package_manifest / weight_hashes | 区分完整训练状态、推理包、统计、tokenizer、图像处理和 decoder |
| historical_training | 已用 Go2 数据、更新、适配器和投影层；本次 new_updates=0 |
| observation_contract | 实测状态字段、frame、时间戳、图像路由、mask、历史顺序与 prompt 编码 |

| execution_profile | L0 或 L1、语义转换配置、反馈与夹爪映射是否启用及理由 |

### B0 和 S1 的专门核对

B0 = 原始密集父权重加原目标 codec，或函数等价的 zero-B LoRA 构造。所有预训练 action/time IO 恢复，不能从 S1 或 MAIN 复制这些已训练权重。优先从固定父构造独立零更新推理包，不训练新头。历史 provider_v1.export 仅支持 step 4/250/500；4 步资格包不是 BASE0，不能篡改 COMPLETE 步数来绕过。真实 step-0 包如存在则先核实身份。

B0 与 S1 使用同一份既有 TRAIN100 统计；不能为 B0 新拟合 TEST 统计，也不能使用 SHIFT7/G7 的不同编码代替原 step-0。报告名称必须保留 TARGET_CODEC。若神经输出有限但夹爪越界，属于真实模型失败；若连统计／动作解释都无法恢复，则是 CONTRACT_NOT_QUALIFIED。

两者均保留原 H40_CURRENT_STATE_PREDICTED_GOAL_QUINTIC_REPRESENTATION_V3_01 endpoint basis：raw H40 的 shape/finite 和全部夹爪范围先检查，再以当前 EEF／最后已消费指宽与模型末点重建 40 点曲线，交原生预览。原链没有把 raw 全部中间位姿的速度／加速度资格作为 basis 前硬门，本轮不能新增这个门来冒充原行为。raw、basis 后 declared intent、L1 编译参考分别保存；raw_H40_consumed=false。这是显式原有组合策略，并非 L1 新增补救。将来若另测 RAW_H40，必须独立 profile，不能混入 B0/S1 本轮对照。

### 原生时间与表示

- B0/S1/M38/S7 按各自封存 H40 合同执行。历史常用 50 ms 节点，40 点首末跨度为 1.95 s；不能把“40 点”自动算作 2.00 s 的首末间隔。真实查询边界及插值终点从原 spec 读取。
- PT 当前 ARX 源 H50 为 30 Hz，首末跨度 49/30 s。不要把 50 行当成 50 个 50 ms 原子；实际 ALIGN、SOURCE 与 native 时间分别记录。
- 原 P10 的精确定义从对应 runner 绑定，不能把数组前十行直接称为 P10。旧模型不自动改成 SOURCE-END；PT 主表采用最新正常入口的 P10 合同，SOURCE-END 如需研究另设时钟单因子副表。
- 冻结采样步数、精度、dropout/eval、RNG 及编译路径。不要为了速度同时改变这些因素。
- 同模型 L0/L1 使用同一个按 query 序号封存的噪声银行；前向次数不同时，不把未调用噪声算为生成。跨模型 shape 不同只共享配对编号，不宣称同一张量。

## 3. 确定性执行内核的合同

### 3.1 类型化物理意图

每份 decoded intent 至少包含：

| 字段 | 示例或约束 |
| --- | --- |
| pose_semantics | COMMAND_REFERENCE 或 NOMINAL_FUTURE_ACHIEVED；不靠模型名隐式推断 |
| gripper_semantics | TARGET_COMMAND 或 SOURCE_LOGGED_GRIPPER_CODE_NOMINAL；源物理测量方式／单位未知，不能冒称已标定 measured width |
| frame_id / frame_epoch | world、当前 body、episode-fixed arm-base 分清；记录变换基准时刻 |
| tool_transform | flange 到 TCP 与碰撞指垫的实际变换、版本；四元数顺序显式声明 |
| knots / source_times | 全部 raw H40/H50 与声明 decoder 后的完整意图及时间；B0/S1 的既有 endpoint basis 显式记账，不声称其 raw 全曲线被消费 |
| previous_consumed_reference | 最近真正消费到的命令及位置／速度边界、query/packet/atom 身份 |
| source_observation_tick | 模型看到的真实世界时刻与生成、接纳时刻分开 |

COMMAND 类型保持既有物理命令含义。PT 的 BTF/GRA 只在其声明的类型转换中使用；源数据 action[t]=state[t+1] 的已审计事实不意味着已完成源夹爪物理标定。禁止把旧 command 再解释成 achieved target 并默认加偏置或预紧。

### 3.2 连续接续候选

优先复用现有完整轨迹编译与滚动发送能力，避免另建控制器。候选行为为：

1. 在真实消费边界计算新旧参考位置、速度、姿态、夹爪差。不能用“已发送但未消费”的点作锚，也不能在接触时把实测指宽冒充命令。
2. 原来完整合法且接缝合法的轨迹走恒等路径；不得无理由改变它们。
3. 对可通过确定性接续解决的速度／加速度问题，构造有限过渡，保留原目标曲线几何和闭开事件次序。同步记录位姿／夹爪的源相位，不做只拖夹爪而无证据改变抓取时序的处理。
4. L0 按历史 decoder／原编译链判定。L1 保存完整 raw 诊断、声明 decoder 后的完整物理意图及原拒绝原因，以完整接续／重定时后曲线在相同原数值限值下通过作为接纳条件。可恢复的时序超限不应在重定时前一概拒绝，否则无法检验本次干预；重定时通过不能改写成原曲线通过。原范围／有限值／frame/tool 硬检查保持。B0/S1 先做既有 basis，L1 不额外筛掉其原来仅用于审计的 raw 中间位姿。
5. 如果有限重定时需要多个传输包，保留完整原曲线到所有包的映射，不能删除未执行后缀以使 full-preview 通过。正常 receding-horizon 对尚未消费后缀的替换按原查询策略记录，不冒充已完整消费。
6. 查询触发保持原合同。若接续改变了查询触发、前缀长度或等待 SOURCE-END，必须登记成独立调度 profile，不能混回仅改变执行层的 A。

执行端在 E0 前绑定最大过渡时间、最大重定时伸缩、最大相位滞后与追赶失败出口。这些数值优先沿用已有合格编译器；缺少时在已知参考开发资格上确定，随后在所有候选间冻结。未绑定这些有限参数不能部署，但不需要新人工批准。不得在看了某模型正式结果后单独为它放宽。

L1 的连续化是待验证的干预，不写成“现有接口已经修好”。记录实际修改类别：生命周期、frame/锚点、接续、时钟；不同改动包不混成同一个版本的成功率。若需要定位各项贡献，先离线单项开关，只有具体剩余问题才增加对应原生副实验。

### 3.3 不能引入的隐含策略

- 不自动闭爪、不按目标距离触发夹爪、不在接触后锁定“保持握力直到放置”。
- 不将模型真实张开判为噪声并吞掉，不由教师补后半段。
- 不通过高度抬底、目标投影、固定成功姿态、阶段切换或物体 GT 修正策略。
- 不改变 WBC 权重／增益／代价／求解器、腿控制、摩擦、质量、执行器强度或原安全阈值。
- 不新增 endpoint-only、截断后缀或事后挑选动作来挽救模型。B0/S1 原有 basis 必须显式标为组合策略；其他完整轨迹模型不继承该例外。

## 4. STOP 和跟踪记录先补齐

### STOP 最小验证

已有真实缺陷是 wire 先接纳，STOP 后 planner 仍从它生成新 rolling target；已有报告未显示 STOP 后实际积分。

复用当前生命周期状态，处理过期候选、取消与提交边界的原子性，不另建审批状态机。确定性工程回归覆盖三个交错：

1. 模型返回与 STOP 同时到达。
2. wire 已接纳，rolling target 尚未发布时 STOP。
3. 原子部分消费时 STOP。

要求 STOP 后新 planner publish、新 reference install、新积分授权、实际积分均为零。已经接纳但未消费的目标显式失效；晚到 receipt 可以作为审计消息，但不能被标成新 installed/consumed。原生终止过程按既有安全流程结束。

同一修复同时应用于 L0/L1。以一张安全已知参考短卡检查实际生命周期，不需要策略前向。原 seed 1 不改写为“完全合格”，也不改写为“STOP 后机器人继续运动”。

### 四层轨迹及净空

同一个 native tick、同一 world frame 对齐：

1. raw output；
2. decoded physical intent；
3. accepted / consumed reference；
4. measured TCP、姿态、两指滑块与指垫碰撞几何。

同时记录位置向量残差、位置范数与 Z 分量、姿态 SO(3) 测地角、实际／参考指宽、左右 pad clearance。四元数正负等价先正确处理。不要用两个净空之差代替 TCP Z 误差。

对 #515 两个最后完整回执边界优先读归档补算，STOP 落在部分原子时仅报告该时刻确有的值，不跨时刻拼接 reference。离线以位置／姿态／指宽逐项替换可描述几何敏感性，交叉项和非真实轨迹性质要注明，不能充当真实物理因果。

E 的五个新布局在候选选择前封存输入清单，独立性按实际训练／开发场景哈希及几何核查，不把换 seed 当新场景。候选算法、统计、语义映射、参数和代码冻结后执行 QE/E。QE 每布局最多一张零模型卡，50,000 tick、1,800 s，确认完整任务的全路径资格；仅可精确复用同版本、同布局、同负载、同任务的已有资格。不能由 NS_A/NS_B 自动外推。失败布局保持封存、标记阻断，不按模型成绩替换；E 若只确认 Pick & Hold，QE 对应这一真实任务。

## 8. 工作窗口与阶段决策

建议按事件推进，时间只是排程估计：

- 首个工作块：绑定资产／合同、读归档、修 STOP 与记录；并行恢复旧模型。期望约 1–2 小时，若主要是资产缺失则优先运行已就绪模型。
- 第二工作块：必要 Q 加 A 的六对，期望约 1–2 小时，实际取决于加载、生成和安全终止。
- 第三工作块：B 的 20 卡，期望约 2–3 小时。按区块给出阶段结果，不能用时间压力替代真实完成。
- C 的移动回归可独立排入；QP/D 在物理包络通过后推进。完整搬运仍失败时，不把剩余时间用于所有权重重复撞同一门。

每一块结束优先回答“实际新增了哪种物体能力、哪个变量得到识别、下一步被什么具体证据决定”。不以 PR 数、离线合法率或用例数量替代能力交付。

本计划不发起新微调。若实验表明只有目标训练权重能稳定工作，先用其同一冻结包完成任务并保留 PT 比较；是否继续官方 PT 的适配学习作为后继单独议题，不在执行期间偷偷改变目标。
