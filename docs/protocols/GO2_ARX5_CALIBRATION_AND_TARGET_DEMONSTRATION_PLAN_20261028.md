# Go2 ARX5 接口标定与少样本目标执行域适配计划

日期：2026-10-28。状态：`PROPOSED_SEPARATE_TARGET_ADAPTATION_SCOPE`。
本次交付是现有代码与历史原件核对后的实施方案。新目标采集、训练、硬件动作与预算采用均未发生。

首要问题是：在接口正确、WBC冻结的条件下，少量真实整机示范能否改善Go2＋ARX5任务能力。当前固定基座E1/E2仍研究参数训练范围，两项实验的数据、模型身份与结论分别保存。原C50→D25→GEN1评价和E0/E1/E2首轮512步执行不被本计划替换。

## 1 采用的技术路线

双RGB、语言、实际TCP和夹爪状态 → GR00T目标本体适配 → EEF位姿轨迹与夹爪命令 → 原参考安装与安全入口 → 冻结WBC → 自由机身Go2＋ARX5。

首包保持EEF10、20Hz、H40、Prefix8、2.5Hz重规划，工作方式为站稳后近场操作。四条腿不要求上层自动增加12个腿关节输出。是否需要BASE意图由冻结执行器的能力和任务决定；本包不通过补零制造BASE监督，不调WBC权重、增益、代价、solver或步态。

UMI-on-Legs使用任务坐标系的末端轨迹连接操作策略和WBC，支持这一架构的可行性；其成功不代表本项目执行器已取得相同资格。[论文](https://proceedings.mlr.press/v270/ha25a.html)。NVIDIA现行G1 SONIC流程使用另一种latent动作接口，不能直接移植其动作维度、50Hz低层时序或本体标签。[官方流程](https://nvlabs.github.io/GR00T-WholeBodyControl/tutorials/vla_workflow.html)。本项目继续使用锁定版本的GR00T和原数据管线。

## 3 接口标定包

计划固定10段短记录，各段在执行前固定幅值、持续时间、起态和原安全上界。默认每段10秒主动记录；启动、稳定站立、复位、终止和实际原生积分另计，不能藏在10秒之外。两段独立姿态仅用于验证，不能反向调标定参数。

| 记录 | 内容 | 主要验证 |
| --- | --- | --- |
| 1 | 名义home下保持 | 实际TCP、双相机和完整时钟链 |
| 2–4 | 分别沿任务系XYZ小幅往返 | 坐标轴、单位、安装变换与实际方向 |
| 5–6 | 两个预定小角度往返 | SO(3)、TCP偏移及row/column rot6d转换 |
| 7 | 空载夹爪开合和保持 | 命令极性、实际开度、闭合与释放时序 |
| 8 | 低速连续参考替换和停留 | H40/Prefix8安装、替换、ACK、STOP与延迟 |
| 9–10 | 两个未用于拟合的验证姿态 | FK与投影一致、可复用的几何和时序配置 |

这10段不计入任务示范、不进入成功行为克隆。允许修正经独立测量证实的相机/TCP/时钟配置错误；不允许依据WBC跟踪残差学习固定反偏置或重调控制器。

原始记录使用绝对任务系位姿与完整变换链：`world→base→arm_mount→flange→TCP`。腕相机外参绑定实际末端，机身相机绑定实际机身。任务参考系必须由部署可取得的标定或定位定义，不能用物体真值偷偷建立学生参考系。

若策略表达使用观察时刻机身坐标，一个chunk固定使用该时刻的变换；不能引入未来机身姿态。旋转经已核验的SE(3)/Processor处理，不直接相减rot6d。保存image/state/issue/accepted/installed/executed时间、时钟来源及同步误差。仿真冻结等待与真实机器人延迟分别报告。UMI的延迟匹配证据支持检查这些对应关系，但不要求本项目换成UMI采集系统。[UMI](https://umi-gripper.github.io/)。

标定出口是版本化配置、独立验证残差、原生安全与时间一致性证据。沿用原安全阈值；新的投影/测量误差阈值必须在拟合前依据现有几何契约固定，不按任务成功率调阈值。历史保持质量FAIL原样保留，按[任务数据优先决定](GR00T_TASK_DATA_FIRST_FROZEN_WBC_SCOPE_V1.md)不作全局采集否决。

## 4 首批整机任务数据

新建独立数据版本，建议标识`GO2_ARX5_TARGET_EEF10_PILOT_V1`。预先封存6个新TRAIN几何，每个相同物体/目标/初态分别运行T1和T2，共12次首次尝试。布局覆盖左右、近远和目标方向；选择基于既有机械可达范围，不依据新模型结果。数值坐标、seed和home须在采集前封存。

采用与物体位置独立的共同home；如需要多个home，将home作为显式版本和实验因素，不能逐布局把夹爪放到物体上方。共同home的任务难度变化和视觉作用分别解释。

Teacher可读取物体真值规划和评分，只通过学生将来使用的同一EEF与夹爪入口执行。学生输入仅含双RGB、语言、实际TCP/夹爪；物体真值、任务阶段、成功标签与规划器内部状态仅入诊断旁路。完整机身/IMU/关节/接触反馈保存，但不自动增加模型输入维度。

12次是尝试数，不保证12条合格成功。任务、安全、完整记录、动作语义、分区全部成立才收入成功库；所有失败原样保留。某任务零合格示范时报告支持缺口，不自动补seed、改变评分或采到凑满。只做已有T1抓放和T2推物；柜门、书架、行走操作与纠正学习留作后继条件研究。

## 5 命令标签和数据准入

每个样本保留五条互相关联的记录：实际观察；专家requested参考；accepted/installed参考及ACK；实际执行反馈；特权诊断。用episode、sequence、ref_id、源时间和字节摘要关联。标签来自部署接口那一层实际接收/安装的专家命令，不用稍后达到的TCP代替。

H40提案只执行Prefix8时，剩余32步是未执行提案。训练窗口从随后真实提交的20Hz命令时间序列构造，不能把被替换suffix记作已执行，也不能跨reset、abort、takeover或时钟断裂。受拒绝命令不进成功监督；发生固定重定时/投影时保留转换前后两份，并明确学生应学习的接口层。

原32秒完整任务一般对应641观察、640个20Hz动作区间和80次正常高层H40决策；动作区间不等于640次独立H40安装。每区间保存所属已安装计划及正确时间片、夹爪目标、实际反馈和消费证据的可用状态；仅ACK不宣称selected-policy消费已证。当640区间全部有效且H40不跨边界时才最多有601合法窗口。窗口不是独立场景；失败、截断或缺帧不能补零凑数。导出先检查raw命令→Processor→反变换与原接收命令的一致性，再检查图像/时间/控制器身份和成功谓词。

当前固定基座E1/E2继续R0。目标EEF10若坐标、范围与模态一致，先报告复用R0的覆盖和重建误差；若不兼容，单独建立TRAIN限定的统计版本，两条比较臂使用同一统计条件。DEV/TEST不参与拟合。不能把目标适配的新统计覆盖现有R0或其历史端点。

## 6 后继学习与评价

首先完成当前源域E1/E2固定512比较。目标适配研究再预先固定一个参数范围与同一父模型，做两条匹配分支：一条消费源域示范，一条消费新目标示范；新增更新量、batch、LR日程、种子流和评价人口一致。训练步数与父模型在看目标评价结果前冻结；本计划不自动追加512或1024更新。

两个分支均在独立整机布局上评价。建议后继范围为12个未训练几何×T1/T2，每臂24条件，共48条件；这是新范围设计，不占用当前原N294101面板或DEC1 core64格。每个几何的两任务、外观变体、窗口和噪声派生保持同分区。报告成功、参考拒绝、原生安全拒绝、完整任务失败及跟踪/身体稳定诊断，按几何成组配对，不用训练loss代替行为。

目标示范一旦用于优化，这个分支称“少样本目标执行域适配”。原无目标任务示范的DEC1分支仍单独保留。数据由冻结目标WBC执行，不再支持该分支的“训练数据与目标控制器无关”主张。

## 7 排程与完整资源范围

当前优先Core原D25→GEN1和Vanda E0/E1/E2；新整机阶段只做不会改变当前capsule或占用其执行角色的离线接线。任务成功率不是启动新参数范围研究的门槛；测量链和输入身份必须成立。

原后继硬截止与最后24小时停新训练不变。若完整新包无法在原资源/时窗内成立，交付实际T0接线与一份统一缺口；不给每个普通工程修复单独申请GO，不借旧已闭合lease运行。仿真工作也不构成真机电机授权。

首个有价值的新结果应是一条经实际WBC安装与执行、完整评分且标签可重建的整机T1/T2记录。此前只声明接口准备和历史证据；此后仍按全部12尝试报告，不以首条成功宣布泛化。
