首个目标：证实一个冻结的组合 Teacher 在原 Go2+ARX5、原 M_FREE 动作接口及评分下，能够完成 F1/F2 × 红/蓝 HOLD、红/蓝左/右 PLACE 的全部12格；再用独立48回合建立最低训练覆盖，最后比较同数据的 M2-BASE 与 M2-SRC。

- 继承原 WBC/legs/MPC/solver/weights/gains、MuJoCo3.2.7、2ms积分、50ms动作、40×10 EEF/夹爪 H40、P10消费、TTL、全H40约束、接触STOP、评分和G7。无真机、RL、训练输出clip/smooth/retime或模拟器替换。

输出`D3_MECHANISM_AUDIT.md/json`和一个已固定规则/阈值/场景生成器的manifest。离线工作以一个有限作业结束；建议先完成最小证据集和下列必要回归，不建立新调度器或多层审批系统。

### 3.2 六项修复及验收预测

| 机制 | 允许改动 | 新证据必须回答 |
|---|---|---|
| 内部腕/持物 | 按相对变换、手指运动与抓持滑移计算不确定性；共同底座刚体运动不重复加入 | 原外障余量不变时，内部误拒减少；真实相对滑移仍触发风险 |
| F2红接近 | 有限接近方向/抓姿、先退让再对齐/下降；用实际安装座6D状态及扰动包络 | 在原60/90秒及H40门内存在腕部不碰蓝块的实际抓取路径 |
| F2蓝搬运 | 先离障后转移/转腕等路径拓扑，完整持物+机械臂扫掠检查 | 同一外障余量下可避开红块，非单纯放宽拒绝 |
| 支撑到释放 | LOWER→SUPPORTED→OPEN→RELEASED→WITHDRAW；持续支撑确认、有界重新落座 | 实际负载交给桌面，夹爪实际释放，原撤离/稳定判据成立 |

| 移动与保持同时成立 | 仅在现有EEF/夹爪通道选择路径/时序，观察冻结WBC的底座响应 | 原80mm与原持续保持在相同时钟满足；不可通过则说明动作可控性缺口 |

支撑确认时间、低速/姿态窗口、最多重新落座次数和总时长，必须由现有正/负轨迹的原单位数据确定并写入manifest后才能运行；不能在新结果出来后调整。建议最多一次重新落座；所有动作仍受原H40及剩余任务时间约束。支撑丢失不再使用“物体固定桌面”假设，若无可行保持/落座动作就终止该回合。

内部误差公式同样先登记：保留采样项，列出相对平移/旋转、滑移和标定项；不得选一个事后通过数字。抓持关系失效或超出已检验域时不按刚性附件处理。外障阈值不缩小。

### 3.3 必要、有限的回归

1. 对内部配对施加相同全局SE(3)变换，距离和相对误差保持；改变相对抓持/手指状态时风险应改变。
2. 旧13成功LOWER片段及蓝HOLD安全片段不应被无依据误拒；旧15/18及两条F2红HOLD的真实接触前片段必须继续被识别为风险。这里是分类回归，不声称动态拦截已经证明。
3. 同一查询的预检阶段、实际stage、过滤后将消费P10一致，不能未完成竖直段就横移。
4. 实测支撑消失时切换影子模型；命令、实测指位、接触力、物体速度和安装座运动同钟，不能用命令开度替代实际释放。
5. HOLD指标沿原2ms时钟重算，移动峰值与保持不同时成立仍判失败。

不要求全历史大测试，不写只复刻实现的测试，不新增积分/模型生成来通过这些回归。修改的几何或参考公式无法解释已有正负例时，先收口为机制未解决，不抢发完整矩阵。
