# Frozen SLA V1.3 offline replay

The CPU runner reads the sealed V1.2 experiment root and checks the previous command and exact original H40/G7 implementation. Run on the host that owns those assets. Keep outputs in a fresh private directory. The source data, V1.2 model inference outputs, V1.2 commissioned replay helpers and installed native Python runtime are dependencies of the replay.

The frozen registration describes both time laws, the command ownership requirement and the progress/event criteria. C1 retimes the flange path before applying the target TCP transform. C2/C3 have no issued candidate when the corpus lacks a student ownership receipt. No controller process is started by this runner.

From this directory, set the shell variables `TRANSFER_ROOT`, `OUTPUT`, `CPU_TORCH_PYTHON` and `HANDOFF_MODULE` to the sealed data root, a new private output directory, a CPU-capable Python with PyTorch/SciPy, and the repository's pinned `reports/PI0282/wbc_handoff/metadata/8386841b29b5-trajectory.py`, respectively.

```sh
umask 077
export CUDA_VISIBLE_DEVICES="" PYTHONDONTWRITEBYTECODE=1
python3 -m unittest -v test_retime
python3 launch.py --root "$TRANSFER_ROOT" --output "$OUTPUT"
"$CPU_TORCH_PYTHON" canonical.py "$OUTPUT" "$HANDOFF_MODULE"
python3 launch.py --stage canonical_gate --root "$TRANSFER_ROOT" --output "$OUTPUT"
python3 summarize.py "$OUTPUT"
```

For a reproducibility audit, invoke the first analysis again with a new private output directory and pass both output directories to `reproduce.py`. The comparison excludes elapsed wall time and verifies every saved action package by SHA256. This requires no model calls or physical integrations.

`S0_ACTUAL.json` binds original reports, arrays, native hashes, thresholds and command identities. `S1_ACTUAL.json` retains the 30 Hz and 50 ms differences, entry twist and achieved motion. `S2_ACTUAL.json` records the distinction between historical teacher acceptance and student command ownership. `S3_ACTUAL.json` links the private arrays and registered progress, dynamics and event checks. The canonical receipts and S4/S5 results are generated by the remaining commands. The redacted numerical summary is `V13_READOUT.json`.
