# 冻结 SLA 到 Go2＋ARX5 的阶段结果

**本轮决定：保留已验证的学生夹爪通道，暂缓启动 SLA 自主抓取。** 16 个真实模型输出中，3 个同时满足编译动态、夹爪接缝及离散场景几何，1 个符合对应任务阶段的运动与事件条件。逐窗核对原始预测哈希后，两组没有交集。唯一符合抬升意图的 T11 来自教师已持物状态，首个夹爪命令接缝达 339.2 mm/s，原上限为 40 mm/s。

V2 的 6,503 个积分步来自**已知的技术卡命令**。接收器 STOP 后 0 tick，整机运动中故障 STOP 和接触抓持尚无资格。V1.6 本轮新增模型前向、训练更新和 SLA 自主任务尝试均为 0，任务成功率无定义。

下一个可区分原因的执行实验是 V3 已知曲线 A0/A1 对照。已固定两种启动状态、两档速度、主动俯仰与原门离线预检。SLA 路径转入接触执行之前，还需同窗同时满足任务意图与执行条件，并验证运动中整机停机。

四份稳定后的真实消费记录表明，直接切回名义目标引入 34.01–34.17 mm 接缝。继承最后消费参考后，8/8 个接缝和 568/568 个块内预览通过。原接收器在两项块内故障回放中均停止继续交付。整机运动中停机与新曲线的实测跟踪仍待验证。[后续测量、接续与停机预检](V3_DYNAMIC_ADMISSION_ACTUAL.md)

V4 新增 10 对同回合不同 SLA 输出的离线修订。新源路径在新观测后 3.65–5.60 s 才开始移动，两个修订接缝产生了源提议中没有的 CLOSE。完整调度的 G7 通过数为 0/10。[连续提议、接缝与时延](H1_REVISION_ACTUAL.md)

V3 的两项块内故障在信号处理返回、再次尝试调用 14 次时仍交付 0 个新状态。新增记录后，冻结 WM02 记录器各捕获到一次 STOP。首张独立原生停机卡的运动条件已在 8/8 条适用历史曲线上复核。[停机信号与整机卡条件](V3_STOP_TRACE_ACTUAL.md)

首张 V3 整机停机卡已有执行回调和关闭租约后的独立评分。现场预检验证了 158 条新卡指令字节、160 条此前 V2 原生指令及 60 个真实参考的回读。[执行入口及预检](V3_STOP_CARD_RUNNER.md)

对 8 条先前原生轨迹的回读发现，120/232 次安装在新起点后 50 ms 改变了已发布的未来参考。255 个随后发出的机械臂请求仍与旧参考的求解结果唯一匹配。[原生替换范围与低层命令归因](NATIVE_REVISION_ACTUAL.md)
