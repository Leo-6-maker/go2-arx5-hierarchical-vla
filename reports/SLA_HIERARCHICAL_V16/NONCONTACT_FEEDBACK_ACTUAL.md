# 手指接触方块后，谁能撤回已经下发的参考？

在六条教师轨迹上回放 #462 的连续 SLA 输出时，新增的无接触执行检查在首次观察到非支撑接触后关闭了该回合的模型查询和发令入口。三个回合在首个查询时就已接触；另三个在参考已经安装后接触。串行调度下，实际送入冻结接收器 CPU 回调的安装数从 **207 降到 37**。此前排到当前参考的三段源运动都尚未开始。这个结果只适用于无接触资格阶段；抓取阶段本来就需要接触。[实验登记](NONCONTACT_FEEDBACK_REGISTRATION.json) · [逐回合原始结果](NONCONTACT_FEEDBACK_ACTUAL.json)

## 高层何时收到接触

输入是原生二进制状态日志的逐 2 ms 接触列表。按冻结场景的几何 ID 识别四个 Go2 足端与地面的支撑接触，以及场景中方块与桌面的支撑接触。其他接触沿用无接触资格卡的原判据，保留法向力的实际值。模型、规划器和接收器均未使用物体真值选动作。

后三行从原回合的首个已登记查询开始审计，不能由此推断接触始于该查询。包内的接触时间戳指向该步起点，比表中的状态包时钟早 2 ms。26–28 ms 衡量第一次记录到接触的状态包与下一次 25 tick 暂停之间的差，不含传感器和消息传输的墙钟延迟。

## 已在途的模型返回和参考

两套时序各保留原 16 个输出、六个回合。串行和允许调用重叠的对照，各有 8 个真实输入在停止前进入查询，5 个返回已交付，3 个仍在途。用封存的两幅相机图、历史、状态和提示逐一复核输入，并交回对应的原始模型结果。T01、T02、T09 在接触停机后交付时，查询入口全部拒绝；已返回但尚未取出的提议也无法再领取。重叠对照的安装数从 191 降到 37。两套时序复用同一批教师轨迹。[查询与原输出回放](../../scripts/sla_hierarchical_v16/noncontact_policy_return.py) · [执行检查](../../scripts/sla_hierarchical_v16/noncontact_owner.py)

每个回合的 CPU 回调均收到一次原生 CANCEL 对应的 HOLD。绑定起点、期限和待处理消息已清空。曾有安装的三个回合仍保留上一条轨迹对象，但执行标志已关闭；随后一次定时发布检查中没有新增目标消息。从同一发令入口尝试提交迟到夹爪指令和下一段积分许可时，均在调用发送函数前被拒绝。这里的接收证据覆盖回调和上层发令入口，先前已交给求解器的预测仍需在整机停机测试中独立核对。

## 冻结夹爪接收器能否在 50 ms 配额中途停下

原 V2 学生夹爪接收器在每次物理步返回时检查实际接触。为了独立验证这个分支，使用与原资格卡哈希一致的二进制，将下一步函数绑定到已验证的记录读取器。固定单红块场景和夹爪指令，只在第 6,439 个记录步替换一次已登记的教师关节位置和速度。按关节名、类型和地址对照共享状态，单红块场景省略蓝块自由关节；用相同场景和替换后的姿态独立复算接触几何。[补充对照登记](NONCONTACT_RECEIVER_REGISTRATION.json) · [逐条件接触与进程终态](NONCONTACT_RECEIVER_ACTUAL.json)

| 输入条件 | 单红块场景中的指垫接触 | 接收器终态 | 最后交付的记录步 |
| --- | --- | --- | ---: |
| 未替换的运动记录 | 无 | 正常达到配额 | 6,453 |
| T14，查询时 18,953 | 无 | 正常达到配额 | 6,453 |
| T14，首次接触包 19,515 | 右指垫／红块 | PROHIBITED_CONTACT_STOP，进程收到 SIGINT | 6,439 |
| T16，已持物查询 21,453 | 指垫／红块 | PROHIBITED_CONTACT_STOP，进程收到 SIGINT | 6,439 |

两项接触条件中，配额都已发到 6,453，停机后交付的记录步均为 **0**。接收器是在接触步结束后检测到接触。两项无接触条件完整交付 6,453 个记录步。另外，用原 V2 独立无接触卡的 4,001 个连续状态包和 160 个真实学生夹爪消费区间复核上层判据，误停为 0。首次二进制工程回放因测试进程创建的命令文件权限与原接收契约不符在 2,503 步退出；已保留记录，修复后四个固定对照全部重跑。

这两层控制分工不同。执行方可在下一个已确认暂停点撤回参考并作废迟到推理；阻止配额剩余步数依赖逐步接收器。本轮使用 CPU 回放，新增物理积分、冻结模型前向和训练更新均为 0。整机运动中 STOP、SLA 自身接触后的恢复和学生抓放成功率仍待原生仿真验证。
