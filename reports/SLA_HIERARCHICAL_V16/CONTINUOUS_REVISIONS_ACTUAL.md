# 连续三次 SLA 提议何时开始影响当前参考？

在六个教师驱动的 TRAIN 回合中，三个回合的初始参考通过了离线接口，只有蓝色 HOLD 回合让三次真实 SLA 提议依次进入参考，并走到最后一条源轨迹终点。即使在这条回合，三次提议从获取图像到各自首次产生源轨迹运动，也分别经过了 **4.55、4.55 和 6.35 秒**。同期教师记录显示，三次拍摄都在下降阶段，而第三次源运动排到当前时刻时，目标相对该次拍摄已上升 20.66 mm。这会影响高层执行器在发送积压提议前需要复核哪些观测。[预登记](CONTINUOUS_REVISIONS_REGISTRATION.json) · [逐次提议、接收回执摘要和原阈值](CONTINUOUS_REVISIONS_ACTUAL.json)

## 一条时间线保留全部拒绝

16 次封存的冻结模型前向来自 6 个回合。每回合从其最早已登记的查询开始，在同一参考管理器及接收器时钟内依次处理同回合后续返回。前一参考的 2.05 s 保护段、双编码 H40、40 mm/s 夹爪门、事件归属和离散场景几何沿用此前检验。初始宽度和上一参考来自该回合教师执行记录；接续使用前一次编译后受保护的边界值。遇到首个拒绝就终止这段回放，后续原始观测仍列在分母。

| 回合 | 查询顺序 | 单工作进程回放结果 | 10 Hz 安装回执数 |
| --- | --- | --- | ---: |
| F2 HOLD 蓝 00 | T13 → T07 → T01 | 三次均通过，最后一条走到源终点 | 192 |
| F1 HOLD 红 03 | T14 → T08 → T02 | T08 已接纳；T02 的接缝会产生模型未提出的闭合，停止 | 10 |
| F1 PLACE 红右 07 | T15 → T09 → T03 | T09 的接缝会产生模型未提出的闭合，T03 未进入 | 5 |
| F1 HOLD 红 02 | T16 → T10 → T04 | 初始已接触或持物，模型要求改变开度，后两次未进入 | 0 |
| F1 HOLD 红 05 | T11 → T05 | 同一初始接触门拒绝，后一次未进入 | 0 |
| F1 PLACE 红右 01 | T12 → T06 | 同一初始接触门拒绝，后一次未进入 | 0 |

合计 6 次提议接纳、3 次起始拒绝、2 次修订拒绝、5 次未进入。6 次接纳中，只有 3 次在拒绝或正常终止前产生了属于各自模型源轨迹的非零平移。T08 有已安装的未来参考，当前结点尚未轮到 T08 就收到终止。T02 和 T09 的接续峰值分别为 23.35 和 15.54 mm/s，均低于原速度上限；拒绝原因是接续凭空跨过闭合阈值。

## 排队与来源归属

主对照设定仿真与墙钟按 1:1 前进，同一工作进程串行处理每次查询，使用各自原先实测的推理耗时。另一对照允许各调用从各自查询时刻独立运行。两套回放的准入结论相同，获得的离线接收回执分别为 207 和 191。两次独立运行完整复现原始调度字段与回调摘要。队列时延来自给定调度；两次超过 2 s 的既有前向分别是独立冷启动后的首调用，这些数值不能估计线上常驻服务的时延。

蓝色回合中，T01 在单工作进程排队 1.528 s，从查询到首次源路径运动耗时 6.35 s；允许调用重叠时为 4.80 s。T13 被接替时只在 49/30 s 的源轨迹中走到 0.007 s。T07 在两套参考中分别走到源时间 0.340 s 和 0.033 s。此处“走到”以 50 ms 时钟的当前参考计，前置对齐和 2 s 预览中的未来点另计。相同三条已封存提议在此前的任务阶段判据上均未通过。[逐窗阶段证据](V4_SLA_SKILL_AND_LONG_HORIZON_DIAGNOSTIC.json)

本轮还修正了第三次返回的来源归属。旧的两次返回逻辑把整段保护前缀都记在紧邻的上一模型输出名下。在允许调用重叠的真实三输出组合中，这会错记第三次安装首个预览里 **28/41 个结点**。现在每个结点回溯到最初生成其位姿、开度和源时钟的模型输出，保护段按原值保留。串行对照该预览的误记数为 0。[连续修订实现](../../scripts/sla_hierarchical_v16/revision_wire.py)

首次 CPU 工程回放在第 23 条安装回执后因时间数组类型不兼容而中断，保留该技术中断记录。修复后两次完整回放使用同一批 16 个封存输出。

本轮使用冻结接收器的 CPU 回调，三个有安装的回合分别核对了终止 HOLD。离散几何沿用初始场景。新增模型前向、MuJoCo 积分、物理消费和训练更新均为 0。V3 原生运动中停机资格与后续学生自主执行仍待独立实测。
