# V2 学生自有夹爪的原生无接触资格卡

在冻结 Go2＋ARX5 仿真中，独立学生夹爪接收器从物理 reset 起独占双指。原生臂在 tick 0 为 HOLD，学生接收器在 tick 0 记录真实双指目标，启动段仅保持。臂切换为 WBC 后，接收器在 tick 2,503 单独开启命令 epoch。所有指令都保留绝对物理时间。旧验证器要求物理 tick 0 已经处于 WBC，这一旧门仍未通过。本次使用已独立登记的双时钟协议。

| 实测项 | 结果 |
|---|---:|
| 登记请求／实际启动仿真／完成的无接触卡 | 2 / 1 / 1 |
| 指令与真实接收 ACK | 160 / 160 |
| 原生积分，含保持初始化及已应用命令 | 6,503 = 2,503 + 4,000 tick |
| 左／右滑动关节闭合行程 | 3.9996 / 4.0004 mm |
| 左／右重新张开行程 | 4.0001 / 3.9999 mm |
| 与初始保持位置之差 | 0.00059 / 0.00052 mm |
| 实际双指目标峰值速度／上限 | 40.0 / 40.0 mm/s |
| 非支撑接触／夹爪接收器 STOP 后积分 | 0 / 0 |

第一项登记在进程创建前中断。启动器漏调了正常的进程启动步骤，随后尝试准备动态执行，未产生物理积分或学生指令。保留原记录并关闭租约。修正后的独立编号执行了唯一一次实际仿真启动，随后也关闭了租约。全程没有新增 GPU 前向、训练或 SLA 任务尝试。

独立读回逐条对照了指令字节、原生 ACK、实际应用序号、两个滑动关节的控制目标、原状态日志中的两指位置和每步接触。仿真主程序、求解器和控制器的已加载哈希与 B2 一致。新库只改动独立夹爪的指令接收与观测，复用了原双指 PD、限速和物理暂停逻辑；对照构建复现了原库的完整二进制哈希。79 项现场 CPU 检查覆盖超速、错 epoch、重复包和终止后重入。

**本卡通过已知指令下的无接触闭合、再张开和耗尽额度时的接收器停机。** 原全系统 trace 记录 `STOP_observed=false`，运动中整机故障 STOP 尚无资格。真正的原生超速拒绝挑战也尚未采样。历史 16 个教师窗的学生接管仍为 0/16；学生抓取成功率仍无定义。
