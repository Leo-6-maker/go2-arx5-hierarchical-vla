# 首张运动中停机卡的执行与评分入口

`V3-STOP-01` 的科学分母为一次独立启动。执行回调从已获得独占租约的现场 owner 接入，使用原 F1 初态筛选、冻结 A0 世界系短轨迹、学生开度通道与原 H40 门。发出至 tick 6,453 的最后一段配额时，开度指令在 6,438.5 过期。启动筛除、提前故障、越过预期停机时刻和缺项各自保留。[单卡条件](V3_NATIVE_STOP_CARD_CANDIDATE.json) · [已登记 owner 的执行回调](../../scripts/sla_hierarchical_v16/moving_stop_card.py)

现场 CPU 验证得到以下结果。

| 核对项 | 结果 |
|---|---:|
| 新卡发令器与已测接收器 ACK 的完整命令字节一致 | 158/158 |
| V2 原调用方式与此前真实原生卡 ACK 的完整命令字节一致 | 160/160 |
| 四条历史 A0 轨迹在拟用时刻生成的参考，与原 ROS 安装回执一致且通过原 H40 | 60/60 |
| 真实运动但缺少登记 STOP 的历史轨迹被评分器拒绝 | 4/4 |

60 个参考均按各自原始实验卡逐条查找对应的 41 点世界系位姿、消息哈希、仿真时刻和求解器回执。158 条对应的是冻结接收器的 CPU 故障回放，160 条来自原 V2 无接触原生资格卡。现场还复核了两份原初态锚点、冻结接收器和原安全依赖，互斥检查后已释放。[逐项预检结果](V3_STOP_CARD_RUNNER_PREFLIGHT.json)

独立评分发生在租约关闭后。它要求原生 WM02 的 STOP、直接物理步账本、夹爪接收记录在 6,439 对齐，之后没有积分和新安装，并核对四组进程退出。零次移动中整机试验意味着该卡仍无成功率。执行器的真实跟踪、整机停机及 SLA 自主操作均保留为待测。[独立评分代码](../../scripts/sla_hierarchical_v16/stop_card_evidence.py)

现场只读入口是 `moving_stop_card.py <实验根目录> --shadow`。独立科学分配落实后，已有现场 owner 可按注册内容在独占锁及新租约内调用 `run_case(root, spec, spec_path)`；租约关闭后用 `--score <本卡的 EXECUTION_SPEC.json>` 读取完整证据。
