# GRASP24 名义轨迹、接收参考和实际 TCP 的逐原子读回

从已封存的 **18/24** 条 HOLD 回读了 **18,341 个确认消费的 50 ms 原子**，对应原 **561,230 tick、1,842 份 H40**。每个原子的名义端点来自原 H40 的下一采样点，经固定变换转到世界坐标，然后按原生起止时钟和 wire 哈希与已接收的参考结点、实测 TCP 对齐。以下为 18 条轨迹各自的中位数范围。

| 同一原子端点上的位置量 | 18 条轨迹的中位数范围 |
| --- | ---: |
| 名义位置至安装参考 | 22.43–31.30 mm |
| 接收参考至实测 TCP | 22.93–31.83 mm |
| 名义位置至实测 TCP | 1.36–2.71 mm |
| 名义 TCP 至目标物体中心 | 86.51–131.64 mm |
| 实测 TCP 至目标物体中心 | 86.21–131.41 mm |

安装参考与接收结点的位置差全体最大 0.049 mm。接收点相对名义点到目标中心的距离增加，每条的中位数为 7.63–29.84 mm。实测 TCP 到目标中心的距离相对名义点变化的中位数为 −0.66 至 +1.09 mm。名义位置和实测位置的偏差在个别端点达到 34.51 mm。

在这些失败轨迹里，多数实测端点接近名义端点，而且二者的典型目标距离都较大。下一次诊断优先查看模型名义接近轨迹和对象选择，特别是靠近和闭合条件。接收端结点与实测 TCP 之间也有明显差异，MPC 实际选中的参考仍为 UNKNOWN。距离使用 TCP 至物体中心，不能替代双垫接触与原 2 ms 任务评分。

读回新增训练、模型生成、原生请求和积分均为 0。
