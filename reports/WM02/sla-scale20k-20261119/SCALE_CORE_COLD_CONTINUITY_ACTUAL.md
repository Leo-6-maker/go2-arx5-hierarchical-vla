# Core 已保存训练段的接续验证

在 Core 用独立 CPU 进程检查原 MIX 第 **0–200 步**的冷态训练段。持久账本完整记录 **200** 次更新，目标、RoboDojo 和 LIBERO 访问分别为 **6,400／9,600／9,600**。逐文件核对 **140** 个完整状态数组与 **3,669** 个原训练源码文件，依据封存检查点生成指向第 500 步的接续草案。草案没有分配期限，生产训练和接续仍由原服务管理。

同一程序尝试读取仍活动的第 500 步训练段时，在构造草案前以实际进程所有权拒绝。新增训练服务、模型加载、优化更新与原生请求均为 0。本地 19 项回归通过，其中有界终态用例验证了非里程碑保存状态仍指向下一个正式里程碑，并能检出不完整的更新账本。

该入口支持从之后的真实冷态存档继续原状态。实际接续须绑定新取得的有限站点时段。
