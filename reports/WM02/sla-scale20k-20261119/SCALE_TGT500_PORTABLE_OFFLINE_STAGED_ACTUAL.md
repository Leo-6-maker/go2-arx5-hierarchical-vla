# VANDA TGT500 端点转移与 Core 三域评价预检

Core CPU 读取 VANDA 现役训练卡，校验两站的三域数据清单、Go2 准入和上一命令时钟、父模型与 tokenizer 哈希。固定面板的身份与各域 **96 条**窗口一致，并实际解码各域的第一条数据，动作张量形状分别为 **40×32、50×32、10×32**。正式评价保留全部 288 条，以及随后独立进程的各域 16 条复验。

VANDA 转移入口已部署并用运行中的真实作业验证，退出前拒绝转移，发送模型字节为 **0**。正式端点封存后需通过 PBS 成功终态、完整 140 个检查点数组、原训练卡和各文件哈希的检查。Core 缓存使用自身已核验路径，端点训练卡按原始字节留档。

当前站点参考 step-zero 约 **5.55 GB**。跨站限制为 8 GiB，正式 TGT500 端点尚未生成。本次新增训练、模型加载和生成、原生请求均为 0。
