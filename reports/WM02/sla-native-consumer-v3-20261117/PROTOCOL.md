Plan: PR394@bcc2c67be723149e38998a36802f218caa666917. Runtime ancestor: PR393@7afbc0bd953c9b87821858bd70738a287ec082fc. No new training or native request is authorized here.

The sole receiver owns episode/generation/sequence/native step, pending query and last emitted-command history. Request identity hashes the ordinary body+wrist RGB/state/frame input file, language, noise, previous reference and fixed source/parent/adapters/codec/statistics bindings. The GPU process only reads receiver state, checks before/between/after branches, and atomically returns one physical H40. It cannot install or emit commands. The receiver checks again before and after the unchanged `compile_proposal` and publishes one bundle plus ACK. The normalized FM tensor is retained only as the original compiler's required container; no normalized gripper columns are spliced. Physical gripper decoding and working-to-mechanical mapping occur once.

The substitute uses original `eef_document` world-frame wire with 41 waypoints and no BASE field. Its ACK identifies both the EEF wire and the complete mechanical EEF+gripper path. There is no independent gripper API. Emission writes one combined mock EEF/gripper receipt before advancing history. Original P10 renews the same suffix at atom7 with a fresh simulated source; without renewal, atom8 would reach the original 0.4s deadline and is rejected. Seven emitted atoms mean 0.35s and never full P10. STOP/cancel/restart invalidate pending requests and installed paths. Historical seeds are labeled recorded native commands; subsequent receipts are explicitly mock emissions.

This is a receiver substitute, not the C++/ROS receiver, WBC or collision certification. Native STOP propagation, hook latency and physical consumption remain unqualified. SIM_PAUSED_ONLY does not count wall inference time as native time. Actual wall read/IPC/compiler/ACK latency is separately compared with 0.35s and 0.4s, without extending either contract. A separate strict-wall request refuses late installation.
