| 判据 | 原始输出经旧 H40/G7 | 连续世界系参考 |

原始对照由封存 50×16 输出重新计算右臂世界系 TCP 和 H40，再调用原门。16 项结果与旧评分逐项一致。第三个对照将完整意图提交给 F2 控制器的适用域判定，16/16 均含时变轨迹，全部登记为 `A1_DYNAMIC_UNQUALIFIED`。这次实际 A1 动态运行数为 0。[逐窗三路结果](O1_ACTUAL.json)

**连续参考的实现选择。** 取旧参考在最后一个已消费 25-tick 区间末端的世界系 EEF 位姿。用一个独立的五次时间函数过渡到 SLA 的首个世界系位姿，之后按已封存 V1.3 时长线性推进源码时间。过渡时长由位移、转角及冻结速度和加速度限值计算，向上对齐 50 ms。夹爪保留首个学生提议，并从上一条实际消费的宽度计接缝。底座保持查询时的实测位姿。教师未来轨迹只用于事后的进展评分。该选择测量一种确定性编译方式。[回放实现](../../scripts/sla_official_pt_transfer/replay_official.py)

- **几何与进展。** 过渡耗时 0.75–0.80 秒，覆盖首个 P10 的 0–0.45 秒。排除过渡位移后，这 10 个点的 SLA 自身进展均为零。全部 50 个源几何结点保持一致；按 50 ms 传输后，在这些结点时刻重建所得的最大误差为 0.202 mm、0.035°。总执行时长为 7.40–19.30 秒，原模型时长为 1.633 秒。
- **动态门。** 10 Hz 产生 1,718 个 41 点世界系预览，每个都通过离线接收回调做字段和滚动时钟核对。原 40 点包络在其中 420 个预览触发，涉及全部 16 个窗口。按预览起点计，103 个起于过渡段，317 个起于 SLA 段；预览可以跨段。每个窗口均出现过平移和旋转加速度越限。16/16 初始位姿接缝加速度合格。夹爪全段含首接缝在 40 mm/s 内的有 4/16，最差首接缝为 343.85 mm/s。[逐次超限的序号、观测值及原门限](O1_REJECTIONS.json)
- **夹爪事件。** 源动作中有 8 次阈值穿越，分布于 8 个窗口，完整回放保留全部 8 次及其顺序。在登记的时间映射下，50 ms 线上插值的事件时间偏差小于 0.30 ms。首个 1.95 秒预览内出现的事件为 0。持物时学生首个提议比已消费夹爪命令更开的窗口为 8/16。事件得到保留只说明动作表示保真，离线回放没有触碰或释放物体。[事件、消费宽度和观测宽度](O1_ACTUAL.json)

## 复核与分母

在有封存输入的 Corelab 项目根目录，先用系统 Python 和 `v12/CPU_LIB` 运行 `audit_sealed.py ROOT O0.json`。再运行 `replay_official.py ROOT O0.json NEW_DIRECTORY`，它读取冻结执行版本指定的 Python 环境，以离线回调检验已安装参考的字段。两步均要求新的输出位置。每个窗口的 `FULL40_ENVELOPE.private.json` 含全部超限，逐窗哈希见 `O1_ACTUAL.json`。

CPU 调试共使用五个独立回放目录。第一次在加载旧评分模块时中断；第二次在首窗的旋转插值端点中断；第三次已处理 16 窗，写汇总时遇到浮点标量序列化错误。第四次和第五次均完整返回，16 窗逐一比对传输字段和超限记录的哈希全部相同。最终结果采用第五次；科学分母始终是同一批 16 窗。F1／F2 的 18 次原生启动另记。
