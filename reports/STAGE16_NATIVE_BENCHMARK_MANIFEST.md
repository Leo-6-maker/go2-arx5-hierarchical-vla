# Stage16 Native Benchmark Manifest

## Contract

The Git-tracked manifest composes `TrajectoryShapeV1`, `PlacementProfileV1`, and `EpisodeReferenceBindingV1`. Each case records a trajectory ID/hash, shape and placement IDs, episode binding, seed, reference interval/mode, simulator, asset, runtime, and immutable input hashes. Per-step output records continuous desired EEF, native preview, achieved EEF, base state, arm/dog state and actions, all nine internal plan channels, margins, flags, progress, and termination code.

The full manifest is generated by `src/go2arx5_vla/benchmark/native_suite.py` and prepared by `scripts/stage16_prepare.py`. Node-local copies are:

- `/var/cache/users/liuyu-nfs/go2-arx5-wbc-stage16/benchmark/native_suite_manifest.json`
- `/var/cache/users/liuyu-nfs/go2-arx5-wbc-stage16/benchmark/first_eight_manifest.json`

## Capacity note

The delivered native config has `max_tl_points=512`. Derived E2 references have 562 timestamped samples. The harness increased only the storage capacity used to preserve the supplied input length (`reference_capacity_points=562`, configured capacity 512); it did not change time-law/controller/physics/termination semantics. The corrected E2 cases were rerun and verified to run to their full reference duration.
