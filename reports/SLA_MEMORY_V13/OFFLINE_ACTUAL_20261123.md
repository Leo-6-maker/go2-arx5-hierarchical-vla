# 冻结 SLA 单臂执行适配 V1.3 · 离线结果

V1.2 的 16 个目标 TRAIN 窗口来自六个已用于研发的 episode。现场重新执行原 H40 编译器和 G7，逐窗复现了教师 16/16、学生 0/16。原始动作、指令、门限与 V1.2 分母保持封存。[V1.3 协议](../../docs/protocols/SLA_MEMORY_V13_ABI_RETIME_HANDOVER_AUTONOMY_PLAN_20261123.md)

原 30 Hz 学生路径的内部线、角加速度已经在全部 16 窗超限。按窗口取内部峰值，中位数分别为目标阈值的 9.34 与 7.92 倍；V1.2 重采样后的中位数为 3.31 与 3.03 倍。使用真实上一条已消费参考的速度诊断，首段仍有 15/16 超限。原 H40 门保留自身的静止端点差分，实际已消费的前速用于独立边界归因与 C1 时间编译。

在登记的边界感知时标族与 50 ms 离散网格内，整条源路径的最短可行总时长为 6.65–18.55 秒，中位数 9.375 秒。C1 的 1.95 秒预览覆盖原 TCP 平移弧长的中位数为 17.38%。同时通过 H40＋G7 的两个窗口，其 P10 参考弧长分别为 0.168 和 0.226 mm，均低于这两窗的 1 mm 进度门槛。8 条含开合事件的路径仍有同向事件，但相对路径进度均偏出预登记容差。均匀时标诊断也没有窗口同时满足全部条件。

8/16 窗口在接管点已有原生接触和抓持。全部 16 窗均有教师原命令及其已消费区间，缺少学生接管 ACK。学生从 reset 拥有夹爪的独立 episode 为 0。C2、C3 在交接前停止，因此没有可统计的新夹爪指令或新的物理轨迹。

原生 Gamma/TimeLaw 在 CPU 上回读，并以同一冻结编译器重新检查。目标 C1 仍为 2/16 通过 H40＋G7，规范化后的参考相对候选最大位置偏差为 1.38 mm。一个源域专家均匀伸缩对照的角速度归因辅助计算数值不一致，已保留原编译器拒绝和异常记录。目标域全部窗口的原门回放完成。

S4 封存于研发面板。独立新场景、S5 原生请求、物理积分、GPU 模型前向与训练更新均为零，尚无学生闭环物体操作结果。CPU 复算对 S0–S3 数值及 78 组动作包逐一核对，动作包哈希全部一致。只读摘要 SHA256 为 `bc867cc408a70f050b449f138a6273e94bb8ec295cc6e01036d00b8fc7527409`。受控执行站保留完整来源、逐窗阈值、源/目标时钟、原生规范化及命令账本。[固定配方](../../scripts/sla_transfer_v13/registration.json)
