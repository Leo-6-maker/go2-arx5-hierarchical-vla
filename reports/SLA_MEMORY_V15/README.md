## 证据复核

D1 启动时所用的四个脚本与现场 owner 封存的 SHA-256 一致。独立重新读取接收器的 installed 回执、原生 journal、PD trace 和暂停回执，D1 第一／第二波、效应与 D2 四份 JSON 逐字节复现。B3 最终复核另对 80 点滚动窗口做插值对照。前置 CPU 诊断曾把旧 M0 的夹爪元数据对象读成标量；复核改用与预登记相同的已安装 EEF10 第十个分量，保留了原诊断目录。所有这些回读均为零新增积分。

继续检验参考交接之前，首先要在固定的 2 ms 时钟上解释为何相同的启动程序落入两种可重复的底座轨迹。时间线给出了 WBC 启动、首批手臂请求、腿部目标改变和底座偏离的观察区间。若需获知 MRT 真正选择的策略，需有可识别控制器构建的消费证据。新建诊断与原 D1 的登记和分母应独立。[启动轨迹图与逐步回读](D1_PREFIX_AUDIT_ACTUAL.md)

## 冻结启动与低层归因的后续回读

新 OO 和 7 个未匹配的 M0 边界都出现三个连续动态步态周期。原信号从 WBC 底座消息到腿部策略输入再到原生 PD 目标均可追溯；对 OO 的第三个周期，当前帧步态输入对腿关节目标的最大影响为 15.69°。本轮使用 355 次冻结腿部策略 CPU 前向，新增 SLA 前向及物理积分均为 0。[启动步态回读](D1_GAIT_INPUT_REPLAY_ACTUAL.md)

低层 TCP 高度间隙主要来自第 3、4 轴。按消费边界区分传感器采样时刻后，1,005/1,005 个 PD 回调的六轴电机输入可完整复现。严格依照请求头时间，578/580 条机械臂请求的六轴位置和速度均能在既有求解器记录中找到唯一吻合的策略内容。[低层完整归因](D2_POLICY_AND_PD_CLOSURE.md)

夹爪复核覆盖 6,038 条教师命令和 150,950 个原生 tick，双指驱动均可逐步复现。16 个学生窗口中 8 个在抓持时请求张开；误用实测开度将使这 8 个窗口错误通过速度检查。实际学生控制权移交仍为 0/16。[夹爪回放与接管证据](B3_GRIPPER_REPLAY.md)
