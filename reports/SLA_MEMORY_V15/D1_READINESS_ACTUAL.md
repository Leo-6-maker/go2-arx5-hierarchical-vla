# D1 准备 · 2 个历史初态，8 组离线检查

T0 和 T1 均由最后一个安装包、求解器精确回显和第 5,703 tick 实测状态恢复 old／measured 目标。四个固定组合逐一送入现场接收器的进程内回调。每个组合发 10 次新序号，检查每包 41 个点，并验证重复序号被拒绝。全套 80 次有效安装、3,280 个新鲜参考点。这里的安装时间由离线驱动提供。

每组在原 MuJoCo 模型上检查完整路径的离散几何见证、腿臂关节余量、四脚支撑及禁止接触。最小剩余关节余量约 0.479 rad。原 full40 块内门在八组均通过；原固定底座历史接缝诊断在 MO/MM 上仍拒绝。归档移动全身后端保留该项作为影子诊断，动态安全须由原生 guard 执行。
