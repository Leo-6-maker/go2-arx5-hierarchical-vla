# D1 启动偏离 · 从 WBC 底座命令到实际腿部位置目标

这次 OO 在第 2,601–2,630 tick 连续 60 ms 使用了动态步态输入。冻结腿部策略的输入、输出和实际进入原生 PD 的十二腿关节目标均可核对。这个转换发生在 D1 参考处理前超过 6 s。它提供了启动轨迹分化的一项机制，无法单凭这些数据确定第 5,703 tick 的底座最终会偏离多少。

### 原信号与时间

冻结腿部 SDK 对前进、横向和偏航三个命令分量计算欧氏范数，以原代码数值 0.1 判断站立。它同时改变输入中的步频和四个步态时钟通道。前两项和偏航使用不同物理单位，所以这里将 0.1 称作程序门限。检查采用现场链接到仿真二进制的腿部 SDK 源码、关节顺序、配置及同一 TorchScript 权重。原门限和增益均保存在现场冻结版本。

### 分母与排除项

- B2 的两张历史卡各触发 2 次、0 次步态切换输入。D1 OO 触发 3 个连续周期。
- M0 原登记 12 张，9 张到达匹配边界。在这 9 张中，7 张未匹配者都出现 3 个连续周期。2 张匹配者分别出现 1 次、2 次不连续触发。另 1 张技术中断只回放已产生的历史，2 张原隔离卡没有输出。这是事后发现的分组关系，样本不能证明可用它预测其他冷启动，也不能用它替换原初态门。
- 13 份实际轨迹在预设回放时间段内共提供 268 个完整的 30×88 输入。逐帧独立重建的历史与现场快照一致；自然输入的 12 维动作最大复现误差小于 7.2×10⁻⁷。29 个激活周期再各做 3 次分量干预。共 **355 次冻结腿部策略 CPU 前向，SLA 前向 0 次**。
- 29/29 个激活输入的三个命令分量在各自现场 WBC 底座消息中找到唯一的逐值匹配。其真实腿部输出经原动作缩放后，与 290 个原生积分 tick 所消费的腿部 PD 目标吻合，最大误差小于 6×10⁻⁸ rad。底座消息没有源时间戳，观察者接收时刻不能当作策略选择或执行的 ACK。旧 M0 中一张合格卡有 13 条越过门限的底座消息，却只在两个不连续腿部周期采到了该状态，仅数发布消息不足以解释结局。[发送、策略输入及应用回读](D1_BASE_COMMAND_ORIGIN_ACTUAL.json)

本诊断没有发出新的原生请求，没有修改 WBC，也没有实施闭环步态干预。原 D1 的四格响应和交互效应仍然缺失。

### 原容差的全量两两复核

使用原登记的全部特征和数值界限，对有第 5,703 tick 边界的 12 个启动两两比较。两张 B2 锚点与两张匹配的 M0 组成一组，组内 6/6 对相容。新 OO 与另七张 M0 组成另一组，组内 28/28 对相容，跨组 0/32 对相容。这说明两类边界在这组封存数据中可区分，不能把两组混在同一个未分层的因子对比中。原 D1 只承认与两张 B2 锚点都匹配的初态。若另立启动样本或研究第二类初态，需要在新的处理结果产生前登记所研究人群、分配方法和完整分母。[所有 66 对逐项回读](D1_INITIAL_PAIRING_ACTUAL.json)
