# B3 · 16 个封存意图的参考传输

每个意图保留官方 50 点、30 Hz 源时钟的双臂原始输出，固定选右臂。逐点核对归档的世界系 TCP 位姿、时间、夹爪和相机输入哈希。实验选择把源进度线性映射到该窗归档的 V1.3 诊断时长（6.65–18.55 s）。该时标仅用于考察消息传输，尚缺少 D3 的动态可行性证据。

| CPU 回读 | 实测 |
|---|---:|
| 一次确定意图 / 每 0.5 s 修订相同未来段 | 各 16 个源意图 |
| 每种方式每 100 ms 刷新的有效安装 | 各 1,594 |
| 对应窗口的时间、状态、输入字段相同 | 16/16 对 |
| 每种方式的 41 点新包 / 安装后 90 ms 的 80 点滚动窗口 | 各 1,594 / 1,594 |
| P10 未来修订 | 309 次 |

| 缺学生夹爪接管证据 | 16/16 个意图 |

39 点截短输入被新适配器拒绝。旧 H40 的 40 个点跨 39 段；新 41 点安装包包含 2 s 两端；滚动输出中保留内部节点。测试涵盖真实修改未来末端、拒绝覆写当前段、回退或重复时钟、400 ms TTL、伪接收回执和最终一次 HOLD。源路径相同的情况下，两种上层更新方式得到相同的消息字段；差异化未来修订只在独立边界用例中验证。

被拒窗口的最坏平移加速度为 0.553 m/s²（原限 0.25），最坏角加速度为 2.403 rad/s²（原限 1.0）。逐窗同时留下观测值与原门限的现场证据哈希。上述传输均发生在进程内，原生消费、学生夹爪命令、物理 tick、模型前向和训练均为 0。缺少后端精度和夹爪控制权，无法据此评判抓持。[每窗来源、回调与拒绝证据](B3_REFERENCE_MANAGER_SHADOW_ACTUAL.json)

所有新鲜 41 点窗口中的平移字段误差小于 0.00003 mm。在每次安装后 90 ms，将实际 80 点输出与该包的分段平移插值、四元数插值和末段保持逐项对照，平移最大误差小于 0.00005 mm。上述误差均是消息字段误差。原 full40 包络使用新窗口首位姿作锚点，另需独立的实际消费接缝、接触与动力学检查才有物理准入意义。
