# Stage35 — Motion API authority and semantic closure

Stage35 is a CPU-only, zero-model qualification stage.  It does not alter the
production V1/H40 action ABI, construct GR00T, call a sampler, run a WBC, or
submit PBS work.

## Frozen order

1. Audit the exact Stage16 native corpus and delivered WBC/support inputs in
   the already-referenced project/lab roots, read-only.
2. Evaluate `MotionIntentV2` as independent geometry `Gamma(u)` plus timing
   `u(t)`.  Runtime materialization must evaluate `u(t)` first and then
   `Gamma(u)` using linear XYZ and quaternion SLERP.
   Full-density T0 reproduces the source chunk, and the materialized chunk is
   accepted by the existing `GR00TToWBCAdapter` without WBC-specific V2 code.
3. Generate a new deterministic 32-case candidate corpus: eight cases each
   for nominal reaching (`N`), timing variation (`T`), progressive relocation
   (`P`), and hidden-witness continuous-base coordination (`C`).
4. Compare K=4/6/9/12 at common normalized geometry progress and T1/T3/T5/T9
   at fixed geometry, with no outcome-dependent knot choice.
5. Run no oracle WBC campaign unless native Stage16 authority, exact WBC
   inputs, support proof, selected K/T, and all live-HEAD predicates pass.

The generated corpus is explicitly marked `candidate` rather than
authoritative.  Its continuous-base support witness is analytic and is not a
replacement for the native reach table.  Missing native inputs therefore
produces `INFRASTRUCTURE_PROVENANCE_BLOCKER`; no sentinel snapshot is promoted.

## Scientific boundary

The only permitted Stage35 conclusion is about the tested, provenance-bound
motion contract.  No result authorizes a GR00T representation change or
training.  The mandatory next boundary is
`GPT_PI_REVIEW_BEFORE_STRUCTURED_GR00T_TRAINING`.
