**状态离散化确实合并了部分连续值**

逐份核验固定 A93＋Recovery3 全部 96 个归档的散列，再按原坐标 codec 恢复 8,031 个七维状态，使用部署实际统计和 tokenizer 分箱规则。归一化浮点数组保持越界值，离散状态 token 的首尾箱会合并范围外的数值。

| 状态来源 | 窗口 | X 超出原分位数范围 | Y 低于原分位数下界 |
| --- | ---: | ---: | ---: |
| 旧 52 回合 | 4,450 | 84 | 241 |
| 后增 41 回合 | 3,466 | 131 | 208 |
| Recovery3 | 115 | 64 | 79 |

Recovery 的 79 个 Y 坐标全部进入数值 -1 的下界 token，占 68.70%。X 的上界 token 共覆盖 78 个 Recovery 状态，其中 64 个已超过原上分位数。这里的上界箱还包含正常范围内的最后一个 bin，不能把 78 个都算作超界。新增数据的两个旋转通道最大归一化幅度分别达到约 24.90 与 13.20。

现役 Pi0Config 使用 pi05=True。Pi0.embed_suffix 在该分支通过离散状态文本引入状态，连续 obs.state 没有经过 Pi0 分支的 state_proj。因而这种分箱会损失相应连续坐标的分辨率。RGB 和其他 token 仍然不同，这一结果没有证明完整模型输入相同，也没有证明它造成了多少成功率损失。

高比例夹爪上界箱的物理开度范围仅约 41.97–42.04 mm，多数对应维持张开。仅凭这项计数无法推断存在严重的夹爪信息损失。应优先检验有较大物理跨度的平移、旋转和参考残差。[全量状态范围及输入回读](V7_PREPROCESSING_NORMALIZATION_ACTUAL.json)

**训练目标的解释范围**
