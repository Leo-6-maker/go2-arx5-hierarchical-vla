# SEA-1 观测入口的 CPU 验收

将原始观测、同视角换色和仅左腕 Mask 接到同一传感器入口。每个输入绑定回合、查询、当前采样索引和历史索引。源域沿用 30 Hz 录像索引，Go2 沿用原生 2 ms tick。有效观测只包含 RGB、16D 状态和原任务指令。Go2 传感器入口将缺失左腕记为缺测，原输入分支仍向官方处理器递交原有空占位。 [观测入口](../../../scripts/sla_go2_v19/sea_observation.py) · [固定名册](../SEA0/SEA0_PAIRED_ROSTER.json)

在 Corelab CPU 上，用固定版本的官方输入变换、JAX 批处理和 `Observation.from_dict` 走到采样器的观测预处理边界。对三路当前图像、九帧因果 Memory、归一化状态、指令词元及其掩码逐项比较。 [复现入口](../../../scripts/sla_go2_v19/sea1_observation_preflight.py) · [逐状态指纹](OBSERVATION_INGRESS_ACTUAL.json)

| 输入 | 观测数 | 验收结果 |
| --- | ---: | --- |
| 官方源域旁路 | 4 | 原始输入哈希和采样器观测张量与官方直通一致，三路相机原掩码有效 |
| Go2 原始输入 | 4 | 原始请求哈希与封存一致，采样器观测张量与官方直通一致 |
| Go2 仅左腕 Mask | 4 | 保持原请求哈希，采样器输入只有左腕注意力位变为无效 |
| Go2 同视角换色 | 4 | 当前机身、右腕及九帧 Memory 改变，16D 原状态、归一化状态、指令词元及注意力位保持原值 |

每个 Go2 状态执行八个拒绝对照，覆盖未来帧、跨回合帧、历史乱序、相机键错误、携带真值的非传感器输入、跨帧换色、支持掩码外改色及混用两个对照条件。32 个全部在官方处理器前被拒。两个早期源锚点额外验证了同一复位帧带有冲突像素时会被拒。本轮回放读取已封存的换色候选，逐帧核对原始图像指纹和采样索引，以及掩码外像素是否逐字节保持。 [换色与遮挡审计](TARGET_BRIDGE.md)

G00 后继观测通过 CPU 输入复核，原回合的采样返回仍保留为缺失。观测入口尚未在新的原生回合中执行。源实机相机、共同工具点标定和匹配渲染仍待核验。本轮新合格正式配对、GPU 模型前向、MuJoCo 积分和训练更新均为 0。 [源腕部标定复核](../SEA0/SOURCE_WRIST_CALIBRATION.md)
