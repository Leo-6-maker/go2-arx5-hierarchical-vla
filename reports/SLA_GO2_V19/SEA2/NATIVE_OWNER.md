# SEA-2 原生执行入口与独立评分的冷验收

四张无接触候选已接入原站立执行链。入口复用原独占世界锁、逐卡租约、暂停观测、固定底座、开爪、H40 验收、接收安装、实际消费和停机。候选只读取暂停时的实测 TCP，从固定世界轴构造已登记意图。两种布局、四张卡顺序和原上限保持固定。迟到的入口如果无法在 20,000 tick 内完成 9 秒窗口，会在发出新参考前给出可审计的拒绝。 [入口](../../../scripts/sla_go2_v19/sea2_native_owner.py) · [固定候选](NATIVE_PROFILE_REQUEST.json)

独立评分器按原发布哈希、41 点安装回显和每个 50 ms 消费起止点识别参考，再与实际的 2 ms TCP 日志对齐。它分别计分意图、安装参考及实测结果，保留世界轴 Q、有符号增益、绝对误差、4 mm／2° 范围内的比例、末秒保持、最小净空和通道运动证据。按原 2 ms 时钟直接对齐，保留时间和位移偏差，末级 MRT 选中 ID 保持未知。原站立驱动附带的 Reach 任务结论只是历史字段，校准以独立评分为准。混合运动要独立验证平移和旋转两个通道。 [评分器](../../../scripts/sla_go2_v19/sea2_native_score.py)

| 冷验收 | 回读结果 |
| --- | --- |
| 两布局原站立教师档案 | 每条 2,251 个 2 ms TCP 样本、90 个实际消费区间 |
| 受损记录对照 | 两布局的改动发布报文及缺求解器回显的消费区间均被拒 |
| 四条注册轨迹的理想跟随对照 | 四条均通过独立评分回调 |
| 动态轨迹的静止与反向对照 | 三条动态轨迹的静止对照均判失败，静止和反向响应均无运动证据 |
| 源意图指纹 | 四条回调的改动指纹均被拒 |
| 终止处理 | 未验证消费、时钟错位与接触／STOP 均终止面板，超出计划时长的参考保留为该卡拒绝 |
| 授权对照 | 无签发、过期及名册不符均被拒；无有效授权的执行入口未进入现场回调 |

原生教师档案只用于验证读取与接收语义。新 SEA 动态行为的对照为 CPU 构造样本。原 G00 运动中 STOP 的第 7,214 步回执再次通过读回，后续积分和安装为零。验收绑定了原场景、接收器、冻结执行器与当前代码指纹，启动时还需核对独立科学分配、现场状态和新的独占租约。 [机器可读验收](NATIVE_OWNER_COLD.json)

本轮新增原生启动、物理积分、冻结模型前向和训练更新各为 0。四条新参考的实际动态能力仍待正式原生样本验证。
