# SEA-0 原始镜头栅格与换色支持域

在同一相机位姿下，把已校正的 Twin RGB 和机器人掩码映射到原始录像栅格。映射使用显式的原始内参和校正内参，允许两张栅格尺寸不同。支持 OpenCV 顺序的 4、5、8 系数 Brown 畸变，分别包含径向、切向与可选的高阶有理项。原始观测 RGB 保留在原栅格。 [镜头映射](../../../scripts/sla_go2_v19/lens_remap.py) · [换色入口](../../../scripts/sla_go2_v19/crosspaint.py) · [OpenCV 畸变约定](https://legacy-docs.opencv.org/4.x/d9/d0c/group__calib3d.html)

每个原始像素反求校正栅格上的采样位置，核对反解后重新投影的误差。越界、反解无效或双线性采样混有轮廓内外像素的位置记为未决。只有双方 Twin 均有机器人支持、且目标 Twin 与观察 RGB 相符时才换色。场景分割只用于独立评分。 [CPU 验收入口](../../../scripts/sla_go2_v19/sea0_lens_preflight.py)

| 对照 | 结果 |
| --- | --- |
| 4、5、8 系数分别对照 OpenCV，校正图 640×480、原始栅格 352×272 | 每种 95,744 个点，最大回投差小于 2×10⁻¹³ px |
| 人为构造的折叠和越界对照 | 680 个点无支持，验证其原始 RGB 保留 |
| Go2 四个封存状态的机身和右腕，共八张图 | 零畸变时换色 RGB、支持掩码和未决掩码逐字节一致 |
| 对这八张封存图施加同一已知测试畸变 | 共编辑 38,995 个有支持的像素，独立分割中机器人之外及含任务物体采样点的改动均为 0 |

测试畸变下，每视角有 15,951 个像素缺校正栅格支持，另有 721–916 个混合轮廓像素。八张图的候选输入来自原封存 MuJoCo RGB；先复现原 RGB，再施加已知的测试畸变。此处采用固定测试系数。其精度和覆盖度读数限于这组 CPU 验收。 [逐视角证据](RAW_LENS_REMAP_ACTUAL.json)

正式源匹配仍需原设备的实际畸变模型、导出裁切、三路相机位姿和工具标定。本轮新增真实源相机标定、模型前向、物理积分和训练更新均为 0。 [源录像标定缺项](SOURCE_CAPTURE_CALIBRATION.md)
