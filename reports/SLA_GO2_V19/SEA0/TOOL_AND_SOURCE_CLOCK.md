# 共同工具点、夹爪间距和源录像动作时钟

用冻结 MuJoCo 场景及 V2 封存状态计算双指碰撞垫的内侧间距，并核对两段 ARX X5 源录像的动作字段与状态时钟。Go2 使用运动学回读，源录像使用原 HDF5 字节。 [Go2 逐区间读数](GO2_TOOL_GEOMETRY_ACTUAL.json) · [源录像字段读数](SOURCE_TOOL_CLOCK_ACTUAL.json) · [复现入口](../../../scripts/sla_go2_v19/sea_tool_geometry.py)

## Go2 内侧指垫间距

冻结场景的两个指垫是盒体，各随一个直线关节运动。两滑动轴方向相反，指垫内侧平面与滑动轴垂直。该模型中的几何间距是 **1.048 mm 加左右滑块行程之和**。原 H40 `width` 参数分别下发给两侧滑块。

| 两指对称时的单指滑块指令，mm | 指垫间距，mm |
| ---: | ---: |
| 0 | 1.048 |
| 2 | 5.048 |
| 38 | 77.048 |
| 42 | 85.048 |
| 44 | 89.048 |

V2 的 6,503 个归档状态与 160 个指令区间全部回读。两个滑块的实测起止位置与原接收回执一致。开爪保持、收紧后保持、再次张开后的指垫间距分别为 **85.049、77.048、85.048 mm**。原控制目标上限仍为单指 **40 mm/s**。本卡历史实测总间距的最大变化速率为 **35.345 mm/s**，以 2 ms 相邻状态计算。几何换算只覆盖原场景的指垫模型。 [V2 原生回执](../../SLA_HIERARCHICAL_V16/V2_STUDENT_GRIPPER_OWNER_ACTUAL.md)

G00／G01 的四个开发观测均恢复约 **85.048 mm** 的指垫间距。原策略的右夹爪状态逐字节匹配双滑块均值除以 44 mm。已登记的 Go2 TCP 在 `link6` 的 `[142.400, 0, 0.1057] mm`，方向轴相同。四个观测的内侧指垫面中心中点比该 TCP 沿局部 +Y 偏 **1.696–1.736 mm**。工具点和指垫中点分别记账，执行器继续使用原 TCP。 [Go2 开发状态](GO2_TOOL_GEOMETRY_ACTUAL.json)

## 源动作字段的实际时间

两段真实源录像合计 **1,955 个非末行状态转移**。每段的左右臂关节、EEF 位姿和夹爪共六个字段，都满足 `action[t] == state[t+1]`，逐字节相等。每个字段的最后一个动作行与本段最后状态相等。源域旧报告中的 `action` 标签由这一后继状态关系具体定义，原录像缺少独立执行器命令回执。

以 30 Hz 的记录帧号计，标签第 0 行对应查询后 **33.3 ms** 的记录状态。原 P10 和 50 点读数继续在原动作行索引上计算，其模型行末时刻为 **0.300 s** 和 **1.633 s**，对应的后继状态帧时刻分别为 **0.333 s** 和 **1.667 s**。这些是归档索引关系，Go2 的 2 ms 物理和 50 ms 参考时钟沿用原约定。 [原模型对照](../SEA1/ARCHIVE_READBACK.md)

两段 HDF5 的每个夹爪字段均为 `[0,1]` 内的单标量，`additional_info` 只有帧率。源真实指垫间距及 `link6` 到共同工具点的变换仍缺标定。跨本体指标可使用记录时钟与原归一化量，物理开度仍标为未知。 [官方归一化夹爪接口](https://github.com/XPolicyLab/XPolicyLab/blob/main/policy/Q0_Preview/docs/OBSERVATION_INTERFACE.md)

新增原生启动、物理积分、冻结模型前向和训练更新均为 0。
