# SEA-0 源录像标定接入验收

新增逐帧接入入口，把外部标定关联到两份冻结 HDF5 及四个 O0 源观测。先核对录像 SHA-256、30 Hz 时钟、原 RGB 栅格、O0 读回指纹及历史索引，再输出每帧实际观测对应的相机和工具变换。相机使用 OpenCV 光学轴输入，输出同时保留转换后的 MuJoCo 渲染轴。夹爪换算使用实测代码与指垫间距表，在表内插值。表外值与缺失工具信息均保持未知。 [接入入口](../../../scripts/sla_go2_v19/source_calibration.py) · [原录像核验](SOURCE_CAPTURE_CALIBRATION.md)

项目内部将收到的标定资料规范化为 `SEA_SOURCE_RECORDING_CALIBRATION_V1`。每段录像携带对应的 `archive_sha256`、`fps`、两臂和三路相机参数。两臂需提供记录参考系、物理底座及 EEF 到 `link6` 的对应关系，工具和开度测量可为空。每路相机携带原栅格和校正栅格内参、Brown 参数，以及固定头相机、腕部手眼安装或逐帧世界外参。接入结果中的 `world_from_renderer`、基座变换与内参供 Twin 使用，光学输出和原像素指纹可用于独立重投影核验。 [针孔渲染](PINHOLE_CAMERA.md) · [原始镜头映射](RAW_LENS_REMAP.md)

| CPU 验收 | 结果 |
| --- | --- |
| 真实录像与人工构造的已知标定 | 4 个冻结观测、48 个相机帧引用，含原有重复的复位帧 |
| 独立复算手眼与工具变换 | 最大矩阵元素差 5.6×10⁻¹⁷，三种外参路径均覆盖 |
| 原始栅格与镜头接入 | 三种视角各得到 307,200 个有效测试采样点 |
| 负对照 | 错录像、未来历史、错栅格、错侧腕、缺逐帧外参及反射矩阵均被拒绝 |
| 缺工具或夹爪测量 | 相机帧仍可对应，工具和间距输出未知 |

正常 JSON 命令行入口复现了验收中的 48 个帧引用。试验中的录像字节和时钟来自真机封存，内外参与工具几何由测试构造。真实源设备标定、合格配对、GPU 前向、MuJoCo 积分和训练更新均为 **0**。 [验收回执](SOURCE_CALIBRATION_INTAKE_ACTUAL.json) · [复现脚本](../../../scripts/sla_go2_v19/sea0_calibration_preflight.py)
