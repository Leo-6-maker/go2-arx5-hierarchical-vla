# SEA1B 固定源域消融冷验收

**32/32 个固定格通过 CPU 冷验收，0 次冻结模型前向。** 四源锚点的实际历史、三路像素、右臂和语言已与归档核对。固定虚拟左臂由源 episode 0 的帧 0 恢复，在四个锚点均逐项匹配历史 A1 的状态干预回执。 [固定规格](../../../docs/protocols/SLA_GO2_V192_SEA_REGISTRY_20261124.json) · [场地冷验收与输入指纹](REGISTRATION.json)

关闭左腕注意力只改变相应布尔 mask，真实左腕图仍在输入。替换左臂只改变该臂的归一化状态及其在官方输入中的离散状态编码。SentencePiece 下左臂数值变化可使有效 token 数减 1–2，冷验收现已验证完整反解文本、右臂数字、语言和末尾 Action 标记。首次 CPU 检查对 token 长度要求过严，已修正，无实际采样进入。

历史归档缺实际初始噪声，本轮精确复用为 0。正式入口按固定顺序保存两份实际噪声，并逐格记录解码、原采样和处理器边界。入口已核验缺少科学分配时拒绝执行。 [冻结执行入口](../../../scripts/sla_go2_v19/sea1b_run.py) · [后继状态评分](../../../scripts/sla_go2_v19/sea1b_score.py)
